title: LocaleProperties
description: Codes, display names, and an emoji flag that describe a locale. API reference for LocaleProperties.

---

[`useLocaleProperties()`](/docs/svelte/reference/functions/use-locale-properties) returns this object in its `current` property. Fields without a `native` prefix are in the default locale's language; fields with it are in the described locale's own language.

## Overview [#overview]

The examples describe `de-AT` in an app whose default locale is `en`.

| Field | Description | Type | Example |
| --- | --- | --- | --- |
| `code` | The locale code. | `string` | `de-AT` |
| `name` | Display name. | `string` | `Austrian German` |
| `nativeName` | Display name in the locale itself. | `string` | `Österreichisches Deutsch` |
| `languageCode` | Language subtag. | `string` | `de` |
| `languageName` | Language name. | `string` | `German` |
| `nativeLanguageName` | Language name in the locale itself. | `string` | `Deutsch` |
| `nameWithRegionCode` | Language name with the region code. | `string` | `German (AT)` |
| `nativeNameWithRegionCode` | Native language name with the region code. | `string` | `Deutsch (AT)` |
| `regionCode` | Region subtag, or the most likely region. | `string` | `AT` |
| `regionName` | Region name. | `string` | `Austria` |
| `nativeRegionName` | Region name in the locale itself. | `string` | `Österreich` |
| `scriptCode` | Script subtag, or the most likely script. | `string` | `Latn` |
| `scriptName` | Script name. | `string` | `Latin` |
| `nativeScriptName` | Script name in the locale itself. | `string` | `Lateinisch` |
| `maximizedCode` | Code with the most likely script and region added. | `string` | `de-Latn-AT` |
| `maximizedName` | Name of the maximized code. | `string` | `German (Latin, Austria)` |
| `nativeMaximizedName` | Native name of the maximized code. | `string` | `Deutsch (Lateinisch, Österreich)` |
| `minimizedCode` | Shortest equivalent code. | `string` | `de-AT` |
| `minimizedName` | Name of the minimized code. | `string` | `Austrian German` |
| `nativeMinimizedName` | Native name of the minimized code. | `string` | `Österreichisches Deutsch` |
| `emoji` | Flag emoji for the region. | `string` | `🇦🇹` |

## How it works [#how-it-works]

- **Display names** come from `Intl.DisplayNames`, so exact wording depends on the runtime's locale data. When a name is unavailable, the locale code is used.
- **Likely subtags.** `regionCode` and `scriptCode` fall back to the most likely region and script, so `fr` reports `FR` and `Latn`.
- **Minimized codes** drop subtags that are implied, so `de-DE` minimizes to `de`.
- **Custom names.** Names set through [`customMapping`](/docs/svelte/reference/types/gt-svelte-config#custom-mapping) override the computed ones.

## Example [#example]

```svelte
<script lang="ts">
  import { useLocaleProperties } from 'gt-svelte';

  const properties = useLocaleProperties();
</script>

<p>{properties.current.emoji} {properties.current.nativeName}</p>
```
