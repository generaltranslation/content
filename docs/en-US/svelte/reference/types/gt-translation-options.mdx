title: GTTranslationOptions
description: Variables and translation options for useGT, msg, and useMessages. API reference for GTTranslationOptions.

---

Pass this object as the second argument to the function from [`useGT()`](/docs/svelte/reference/functions/use-gt), to [`msg()`](/docs/svelte/reference/functions/msg), and to the function from [`useMessages()`](/docs/svelte/reference/functions/use-messages). Keys that start with `$` are options; every other key is a variable for the message.

## Overview [#overview]

```ts
type GTTranslationOptions = Record<string, unknown> & {
  $context?: string;
  $id?: string;
  $format?: 'ICU' | 'STRING' | 'I18NEXT';
  $locale?: string;
  $maxChars?: number;
  $requiresReview?: boolean;
};
```

| Option | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| [Variables](#variables) | Values for placeholders in the message. | `unknown` | Yes | — |
| [`$context`](#context) | Disambiguates identical messages. | `string` | Yes | — |
| [`$id`](#id) | Stable identifier for the entry. | `string` | Yes | — |
| [`$format`](#format) | Message syntax. | `'ICU' \| 'STRING' \| 'I18NEXT'` | Yes | `'ICU'` |
| [`$locale`](#locale) | Locale to render in instead of the active one. | `string` | Yes | Active locale |
| [`$maxChars`](#max-chars) | Maximum translation length. | `number` | Yes | — |
| [`$requiresReview`](#requires-review) | Marks the translation as needing approval. | `boolean` | Yes | `false` |

Write `$context`, `$id`, `$format`, `$maxChars`, and `$requiresReview` as static values in an inline object literal. The CLI reads them from your source, and reports an error for a value it cannot evaluate.

## Variables [#variables]

**Type** `unknown` · **Optional**

Any key without a `$` prefix fills the placeholder of the same name. In ICU messages, variables also drive `plural`, `select`, and number and date formatting:

```ts
gt('Hello, {name}!', { name: user.name });
gt('{count, plural, one {# result} other {# results}}', { count });
```

Variables are not part of the translation's identity, so changing a value does not need a new translation.

## `$context` [#context]

**Type** `string` · **Optional**

Text that tells translators how the message is used, and gives identical messages separate translations:

```ts
gt('Open', { $context: 'Verb: open the settings panel' });
gt('Open', { $context: 'Adjective: the store is open' });
```

Changing it changes the translation's identity.

## `$id` [#id]

**Type** `string` · **Optional**

A stable identifier stored with the entry. For an array passed to [`msg()`](/docs/svelte/reference/functions/msg), each entry gets `<id>.<index>`.

## `$format` [#format]

**Type** `'ICU' | 'STRING' | 'I18NEXT'` · **Optional** · **Default** `'ICU'`

How the message is parsed. `'ICU'` supports ICU MessageFormat and fills variables. `'STRING'` and `'I18NEXT'` render the message as written, without filling variables, so braces stay literal. Changing it changes the translation's identity.

## `$locale` [#locale]

**Type** `string` · **Optional** · **Default** Active locale

Renders this call in a specific locale, for example to show a phrase in two languages at once. The locale's translations must already be loaded, or the source message is returned.

## `$maxChars` [#max-chars]

**Type** `number` · **Optional**

Asks translation to keep the result within this many characters, and truncates the rendered string to that length with an ellipsis. A negative value keeps the end of the string instead, as in `…ful world`. Write it as a static integer. Changing it changes the translation's identity.

```ts
gt('Hello wonderful world', { $maxChars: 10 }); // 'Hello won…'
```

## `$requiresReview` [#requires-review]

**Type** `boolean` · **Optional** · **Default** `false`

Marks the translation as requiring human approval before use. Write it as the literal `true` or `false`. Setting it to `true` changes the translation's identity.
