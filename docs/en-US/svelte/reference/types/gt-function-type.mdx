title: GTFunctionType

[`useGT()`](/docs/svelte/reference/functions/use-gt) returns a function of this type. Use the type to annotate a function you pass to helpers or child components.

## Overview [#overview]

```ts
type GTFunctionType = (
  message: string,
  options?: GTTranslationOptions
) => string;
```

| Parameter | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| [`message`](#message) | Source message. | `string` | No | — |
| [`options`](#options) | Variables and translation options. | [`GTTranslationOptions`](/docs/svelte/reference/types/gt-translation-options) | Yes | `{}` |

The function returns the translated, interpolated string, or the source message formatted for the default locale when no translation is loaded.

## `message` [#message]

**Type** `string` · **Required**

The source message in the default locale. Write it as a string literal at the call site so the CLI can extract it.

## `options` [#options]

**Type** [`GTTranslationOptions`](/docs/svelte/reference/types/gt-translation-options) · **Optional** · **Default** `{}`

Variables for the message and `$`-prefixed options such as `$context`.

## Example [#example]

Type a prop that receives the function, while keeping each message at an extracted call site in the component that called [`useGT()`](/docs/svelte/reference/functions/use-gt):

```svelte title="src/lib/Pager.svelte"
<script lang="ts">
  import { useGT, type GTFunctionType } from 'gt-svelte';

  let { page, pages }: { page: number; pages: number } = $props();
  const gt: GTFunctionType = useGT();
</script>

<nav aria-label={gt('Pagination')}>
  {gt('Page {page} of {pages}', { page, pages })}
</nav>
```

The CLI extracts only calls made through a variable assigned from [`useGT()`](/docs/svelte/reference/functions/use-gt). Calls through a function received as a parameter or prop are not extracted, so their messages render untranslated unless the same message is also extracted elsewhere.
