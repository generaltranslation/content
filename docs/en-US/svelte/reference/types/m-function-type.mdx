[`useMessages()`](/docs/svelte/reference/functions/use-messages) returns a function of this type. It translates values created by [`msg()`](/docs/svelte/reference/functions/msg) and passes `null` and `undefined` through.

## Overview [#overview]

```ts
type MFunctionType = <T extends string | null | undefined>(
  encodedMsg: T,
  options?: GTTranslationOptions
) => T extends string ? string : T;
```

| Parameter | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| [`encodedMsg`](#encoded-msg) | Value returned by [`msg()`](/docs/svelte/reference/functions/msg), or `null` or `undefined`. | `string \| null \| undefined` | No | — |
| [`options`](#options) | Variables and options for messages without encoded options. | [`GTTranslationOptions`](/docs/svelte/reference/types/gt-translation-options) | Yes | `{}` |

The return type follows the input: a `string` returns the translated `string`, and `null` or `undefined` returns the same value.

## `encodedMsg` [#encoded-msg]

**Type** `string | null | undefined` · **Required**

A value from [`msg()`](/docs/svelte/reference/functions/msg). When it carries encoded options, those are used and call-site `options` are ignored.

## `options` [#options]

**Type** [`GTTranslationOptions`](/docs/svelte/reference/types/gt-translation-options) · **Optional** · **Default** `{}`

Variables and options applied when `encodedMsg` has no encoded options.

## Example [#example]

```svelte
<script lang="ts">
  import { msg, useMessages, type MFunctionType } from 'gt-svelte';

  let { note }: { note?: string } = $props();
  const m: MFunctionType = useMessages();
  const fallback = msg('No note');
</script>

<!-- m(undefined) returns undefined, so ?? picks the fallback -->
<p>{m(note) ?? m(fallback)}</p>
```
