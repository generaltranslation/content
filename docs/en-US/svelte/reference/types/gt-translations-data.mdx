title: GTTranslationsData
description: The resolved locale and its translations, as returned by loadTranslations. API reference for GTTranslationsData.

---

[`loadTranslations()`](/docs/svelte/reference/functions/load-translations) resolves with this object, and [`<GTProvider>`](/docs/svelte/reference/components/gt-provider) takes its two fields as props. Both fields are plain, serializable data, so a server `load` function can return the object.

## Overview [#overview]

```ts
type GTTranslationsData = {
  locale: string;
  translations: Record<string, Content>;
};
```

| Field | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| [`locale`](#locale) | The resolved locale. | `string` | No | — |
| [`translations`](#translations) | That locale's translations, keyed by hash. | `Record<string, Content>` | No | — |

## `locale` [#locale]

**Type** `string` · **Required**

The supported locale that [`resolveLocale()`](/docs/svelte/reference/functions/resolve-locale) chose for the request. It can differ from the locale you passed, for example `fr` for a request of `fr-CA`. Pass it to the `locale` prop of [`<GTProvider>`](/docs/svelte/reference/components/gt-provider).

## `translations` [#translations]

**Type** `Record<string, Content>` · **Required**

The translations for `locale`, keyed by translation hash, in the format the CLI writes to `files.gt.output`. Values are strings for [`useGT()`](/docs/svelte/reference/functions/use-gt) and [`msg()`](/docs/svelte/reference/functions/msg) messages and structured content for [`<T>`](/docs/svelte/reference/components/t). For the default locale, it is `{}`. Pass it to the `translations` prop of [`<GTProvider>`](/docs/svelte/reference/components/gt-provider) without modifying it.

## Example [#example]

```ts title="src/routes/+layout.server.ts"
import '#lib/gt.ts';
import { loadTranslations } from 'gt-svelte';
import type { LayoutServerLoad } from './$types';

export const load: LayoutServerLoad = async ({ locals }) => ({
  // { locale: 'fr', translations: { '9683fd40e0ecd2ee': 'Ajouter un message', ... } }
  gt: await loadTranslations(locals.locale),
});
```
