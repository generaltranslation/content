title: useLocaleProperties
description: Read display names, codes, and other properties of the active locale or another locale. API reference for useLocaleProperties.

---

`useLocaleProperties` returns an object whose `current` property is a [`LocaleProperties`](/docs/svelte/reference/types/locale-properties) object, such as `{ name: 'French', nativeName: 'français', ... }`. Use it to label languages in a switcher.

## Overview [#overview]

```ts
function useLocaleProperties(locale?: string): {
  readonly current: LocaleProperties;
};
```

```svelte
<script lang="ts">
  import { useLocaleProperties } from 'gt-svelte';

  const properties = useLocaleProperties();
</script>

<p>{properties.current.nativeName}</p>
```

## How it works [#how-it-works]

- **Reactive getter.** Without `locale`, `current` follows the nearest [`<GTProvider>`](/docs/svelte/reference/components/gt-provider)'s active locale. Read it in the template or `$derived`; do not destructure it.
- **Stable object.** `current` returns the same object until the locale it describes changes, so reading it repeatedly does not recompute the properties.
- **Display languages.** Names such as `name` and `languageName` are in the default locale's language. Names prefixed with `native` are in the described locale's own language. Names from [`customMapping`](/docs/svelte/reference/types/gt-svelte-config#custom-mapping) take precedence.
- **Context.** Call it during component initialization, including once per option when building a list. Outside a provider, it describes the default locale.

## Parameters [#parameters]

| Parameter | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| [`locale`](#locale) | Locale to describe instead of the active locale. | `string` | Yes | Active locale |

### `locale`

**Type** `string` · **Optional** · **Default** Active locale

A fixed locale code. When set, `current` always describes that locale.

## Returns [#returns]

**Type** `{ readonly current: `[`LocaleProperties`](/docs/svelte/reference/types/locale-properties)` }`

## Example [#example]

Label each option in its own language:

```svelte
<script lang="ts">
  import { useLocale, useLocaleProperties, useLocales } from 'gt-svelte';

  const locale = useLocale();
  // One call per locale, during initialization
  const options = useLocales().map((code) => ({
    code,
    properties: useLocaleProperties(code),
  }));
</script>

<select value={locale.current}>
  {#each options as { code, properties } (code)}
    <option value={code}>
      {properties.current.emoji} {properties.current.nativeName}
    </option>
  {/each}
</select>
```
