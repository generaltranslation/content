---

title: useLocaleDirection
description: Read whether the active locale, or another locale, is written left to right or right to left. API reference for useLocaleDirection.

---

`useLocaleDirection` returns an object whose `current` property is `'ltr'` or `'rtl'`. Without an argument it follows the active locale, so it updates when [`useSetLocale()`](/docs/svelte/reference/functions/use-set-locale) switches languages.

## Overview [#overview]

```ts
function useLocaleDirection(locale?: string): {
  readonly current: 'ltr' | 'rtl';
};
```

```svelte
<script lang="ts">
  import { useLocaleDirection } from 'gt-svelte';

  const dir = useLocaleDirection();
</script>

<article dir={dir.current}>...</article>
```

## How it works [#how-it-works]

- **Reactive getter.** `current` computes the direction each time it is read, from `locale` or from the nearest [`<GTProvider>`](/docs/svelte/reference/components/gt-provider)'s active locale. Read it in the template or `$derived`; do not destructure it.
- **Same rules as** [`getLocaleDirection()`](/docs/svelte/reference/functions/get-locale-direction), which works outside components, such as in `hooks.server.ts`.
- **Context.** Call it during component initialization. Outside a provider, it follows the default locale.

## Parameters [#parameters]

| Parameter | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| [`locale`](#locale) | Locale to check instead of the active locale. | `string` | Yes | Active locale |

### `locale`

**Type** `string` · **Optional** · **Default** Active locale

A fixed locale code. When set, `current` no longer follows the active locale.

## Returns [#returns]

**Type** `{ readonly current: 'ltr' | 'rtl' }`

## Example [#example]

Mirror an icon for right-to-left languages:

```svelte
<script lang="ts">
  import { useLocaleDirection } from 'gt-svelte';

  const dir = useLocaleDirection();
</script>

<span class:flip={dir.current === 'rtl'}>→</span>

<style>
  .flip {
    display: inline-block;
    transform: scaleX(-1);
  }
</style>
```
