`useLocales` returns the supported locales configured with [`initializeGT()`](/docs/svelte/reference/functions/initialize-gt), including the default locale. Use it to build a language selector.

## Overview [#overview]

```ts
function useLocales(): readonly string[];
```

```svelte
<script lang="ts">
  import { useLocales } from 'gt-svelte';

  const locales = useLocales();
</script>

<ul>
  {#each locales as locale (locale)}
    <li>{locale}</li>
  {/each}
</ul>
```

## How it works [#how-it-works]

- **Order.** The default locale comes first, followed by the other configured locales in the order you passed them, without duplicates.
- **Static.** The list does not change after [`initializeGT()`](/docs/svelte/reference/functions/initialize-gt), so the result is a plain array, not a reactive object.
- **No component needed.** It does not read Svelte context, so you can call it anywhere after [`initializeGT()`](/docs/svelte/reference/functions/initialize-gt) has run, including on the server.

## Parameters [#parameters]

`useLocales` takes no parameters.

## Returns [#returns]

**Type** `readonly string[]`

The supported locale codes, including the default locale.

## Example [#example]

Show each locale by its own name with [`useLocaleProperties()`](/docs/svelte/reference/functions/use-locale-properties):

```svelte
<script lang="ts">
  import { useLocaleProperties, useLocales } from 'gt-svelte';

  const options = useLocales().map((code) => ({
    code,
    properties: useLocaleProperties(code),
  }));
</script>

<select>
  {#each options as { code, properties } (code)}
    <option value={code}>{properties.current.nativeName}</option>
  {/each}
</select>
```
