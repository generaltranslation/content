title: useDefaultLocale
description: Get the locale your source content is written in. API reference for useDefaultLocale.

---

`useDefaultLocale` returns the `defaultLocale` configured with [`initializeGT()`](/docs/svelte/reference/functions/initialize-gt). Content in this locale renders from source without a translation lookup.

## Overview [#overview]

```ts
function useDefaultLocale(): string;
```

```ts
import { useDefaultLocale } from 'gt-svelte';

const defaultLocale = useDefaultLocale(); // 'en'
```

## How it works [#how-it-works]

The default locale does not change after [`initializeGT()`](/docs/svelte/reference/functions/initialize-gt), so the result is a plain string. It does not read Svelte context, so you can call it anywhere after [`initializeGT()`](/docs/svelte/reference/functions/initialize-gt) has run, including in server hooks and `load` functions. When no `defaultLocale` was configured, it returns `'en'`.

## Parameters [#parameters]

`useDefaultLocale` takes no parameters.

## Returns [#returns]

**Type** `string`

The default locale code.

## Example [#example]

Show a notice when the page is not in the source language:

```svelte
<script lang="ts">
  import { T, useDefaultLocale, useLocale } from 'gt-svelte';

  const locale = useLocale();
  const defaultLocale = useDefaultLocale();
</script>

{#if locale.current !== defaultLocale}
  <T><p>This page was translated automatically.</p></T>
{/if}
```
