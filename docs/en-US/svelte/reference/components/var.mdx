`<Var>` marks content inside [`<T>`](/docs/svelte/reference/components/t) as a variable. The translation decides where it goes, and its children render there unchanged.

## Overview [#overview]

```svelte
<T>Hello, <Var>{name}</Var>!</T>
```

The extracted source records a placeholder instead of the variable's content, so names, IDs, and other runtime values are never sent for translation. Use [`<Num>`](/docs/svelte/reference/components/num), [`<Currency>`](/docs/svelte/reference/components/currency), [`<DateTime>`](/docs/svelte/reference/components/datetime), or [`<RelativeTime>`](/docs/svelte/reference/components/relative-time) instead when a value should be formatted for the locale.

## How it works [#how-it-works]

- **Opaque content.** The children can be an expression, text, elements, or components. Everything inside `<Var>` is one placeholder in the translation.
- **Rendering.** `<Var>` renders its children as they are, wherever the translation places the placeholder. It adds no HTML element.
- **Outside [`<T>`](/docs/svelte/reference/components/t).** `<Var>` simply renders its children.
- **Variable name.** Each variable gets a key in the translation. By default the key is generated; set [`name`](#name) to give it a readable one.

`<Var>` has no `value` prop. Pass the content as children.

## Props [#props]

| Name | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| [`children`](#children) | Content to render unchanged. | `Snippet` | Yes | — |
| [`name`](#name) | Variable key used in translations. | `string` | Yes | Generated |

### `children`

**Type** `Snippet` · **Optional**

The dynamic content. Logic blocks such as `{#if}` and `{#each}` are allowed here, because the whole subtree is one variable.

```svelte
<T>
  Signed in as
  <Var>
    {#if user.admin}<b>{user.name}</b>{:else}{user.name}{/if}
  </Var>
</T>
```

### `name`

**Type** `string` · **Optional** · **Default** Generated

The key the variable uses in the translation. Inside [`<T>`](/docs/svelte/reference/components/t), it must be a static string.

```svelte
<T>Hello, <Var name="userName">{user.name}</Var>!</T>
```

## Example [#example]

```svelte title="src/lib/AccountSummary.svelte"
<script lang="ts">
  import { T, Var } from 'gt-svelte';

  let { accountName, apiKey }: { accountName: string; apiKey: string } = $props();
</script>

<T>
  Account: <Var>{accountName}</Var>
  <br />
  API key: <Var><code>{apiKey}</code></Var>
</T>
```
