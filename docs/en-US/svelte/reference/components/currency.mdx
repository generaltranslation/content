---

title: "<Currency>"
description: Format an amount of money for the active locale. API reference for the <Currency> component.

---

`<Currency>` formats an amount in a given currency with the active locale's conventions for symbols, separators, and placement. Inside [`<T>`](/docs/svelte/reference/components/t), it is a variable: the translation places it, and the amount is never sent for translation.

## Overview [#overview]

Pass the amount as `value`, or as the only child:

```svelte
<Currency value={1234.5} currency="EUR" />
<!-- en: €1,234.50 · fr: 1 234,50 € -->

<Currency currency="EUR">{total}</Currency>
```

## How it works [#how-it-works]

- **Value.** A number is formatted directly. A string is converted with `parseFloat()`. `null` and `undefined` render nothing.
- **Children.** The children must be a single `{expression}`, and a component cannot have both `value` and children. Either mistake fails the build.
- **Currency.** The currency code is not converted; only its display changes by locale.
- **No wrapper.** The formatted text renders without an HTML element.

The formatting locale follows the same rules as [`<Num>`](/docs/svelte/reference/components/num#formatting-locales): the default locale only while content renders in the default locale or inside an untranslated [`<T>`](/docs/svelte/reference/components/t); otherwise `locales`, then the active locale, then the default locale.

## Props [#props]

| Name | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| [`value`](#value) | The amount to format. | `number \| string \| null \| undefined` | Yes | — |
| [`children`](#children) | The amount as a single `{expression}` child. | `Snippet` | Yes | — |
| [`currency`](#currency) | ISO 4217 currency code. | `string` | Yes | `'USD'` |
| [`options`](#options) | Options passed to `Intl.NumberFormat`. | `Intl.NumberFormatOptions` | Yes | `{}` |
| [`locales`](#locales) | Locales to try before the active locale. | `string[]` | Yes | `[]` |
| [`name`](#name) | Variable key used in translations. | `string` | Yes | Generated |

### `value`

**Type** `number | string | null | undefined` · **Optional**

The amount to format. Strings are parsed with `parseFloat()`. A missing or `null` value renders nothing.

### `children`

**Type** `Snippet` · **Optional**

The amount written as the only child, `<Currency>{total}</Currency>`. It must be a single `{expression}`, and it cannot be combined with `value`.

### `currency`

**Type** `string` · **Optional** · **Default** `'USD'`

The ISO 4217 code of the currency, such as `EUR` or `JPY`.

### `options`

**Type** `Intl.NumberFormatOptions` · **Optional** · **Default** `{}`

Options for `Intl.NumberFormat`, applied on top of currency formatting. Commonly used fields:

| Option | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| `currencyDisplay` | How the currency is shown. | `'symbol' \| 'narrowSymbol' \| 'code' \| 'name'` | Yes | `'symbol'` |
| `currencySign` | Standard or accounting notation for negative amounts. | `'standard' \| 'accounting'` | Yes | `'standard'` |
| `minimumFractionDigits` | Minimum fraction digits. | `number` | Yes | Currency-dependent |
| `maximumFractionDigits` | Maximum fraction digits. | `number` | Yes | Currency-dependent |
| `notation` | Number notation, such as `compact`. | `'standard' \| 'scientific' \| 'engineering' \| 'compact'` | Yes | `'standard'` |
| `signDisplay` | When to show a sign. | `'auto' \| 'always' \| 'exceptZero' \| 'negative' \| 'never'` | Yes | `'auto'` |

(See [`Intl.NumberFormat` options](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/NumberFormat/NumberFormat#options) for the full list).

```svelte
<Currency value={-42} currency="USD" options={{ currencySign: 'accounting' }} />
```

### `locales`

**Type** `string[]` · **Optional** · **Default** `[]`

Locales to try before the active locale. They are ignored while content renders in the default locale.

### `name`

**Type** `string` · **Optional** · **Default** Generated

The key the variable uses in the translation. Inside [`<T>`](/docs/svelte/reference/components/t), it must be a static string.

## Example [#example]

```svelte title="src/lib/OrderTotal.svelte"
<script lang="ts">
  import { Currency, T } from 'gt-svelte';

  let { total, currency }: { total: number; currency: string } = $props();
</script>

<T>Your total is <Currency value={total} {currency} />.</T>
```
