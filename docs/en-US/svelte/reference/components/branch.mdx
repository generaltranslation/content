`<Branch>` renders the alternative named by its `branch` prop. Inside [`<T>`](/docs/svelte/reference/components/t), every alternative is part of the translation, which replaces `{#if}` blocks that [`<T>`](/docs/svelte/reference/components/t) does not allow.

## Overview [#overview]

Pass the selecting value as `branch`. Give each alternative as a string prop or as a `{#snippet}` with the same name, and the fallback as children:

```svelte
<Branch branch={status} inactive="Inactive">
  {#snippet active()}<b>Active</b>{/snippet}
  Unknown
</Branch>
```

## How it works [#how-it-works]

- **Selection.** `branch` is converted to a string and matched against the alternative names. `status="active"` selects `active`; `branch={true}` selects `true`.
- **Fallback.** When `branch` is `null`, `undefined`, or an empty string, or no alternative has its name, the children render.
- **Alternatives.** A string prop renders as text; a snippet renders its markup.
- **No wrapper.** `<Branch>` adds no HTML element.
- **Inside [`<T>`](/docs/svelte/reference/components/t).** The extractor records every alternative. Alternatives must be static strings or snippets without parameters, an alternative cannot be declared twice, `__proto__` cannot be a name, and spread props are not allowed. Any of these mistakes fails the build.

## Props [#props]

| Name | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| [`branch`](#branch) | The name of the alternative to render. | `string \| number \| boolean \| null` | Yes | — |
| [`[name]`](#alternatives) | Content for one alternative. | `string \| Snippet` | Yes | — |
| [`children`](#children) | Fallback when no alternative matches. | `Snippet` | Yes | — |

### `branch`

**Type** `string | number | boolean | null` · **Optional**

The value that selects an alternative. It is compared as a string.

### Alternatives

**Type** `string | Snippet` · **Optional**

Any other prop or snippet is an alternative named after it. The names `branch` and `children`, and names starting with `data-`, are not alternatives.

```svelte
<Branch branch={plan} free="Free plan">
  {#snippet pro()}<b>Pro</b> plan{/snippet}
  Unknown plan
</Branch>
```

### `children`

**Type** `Snippet` · **Optional**

Rendered when `branch` is empty or matches no alternative.

## Example [#example]

```svelte title="src/lib/OrderStatus.svelte"
<script lang="ts">
  import { Branch, T } from 'gt-svelte';

  let { status }: { status: 'pending' | 'shipped' | 'delivered' } = $props();
</script>

<T>
  Your order is
  <Branch branch={status} pending="being prepared">
    {#snippet shipped()}<b>on its way</b>{/snippet}
    {#snippet delivered()}<b>delivered</b>{/snippet}
    being processed
  </Branch>.
</T>
```

(See [Handling plurals and branches](/docs/svelte/guides/handling-plurals-and-branches)).
