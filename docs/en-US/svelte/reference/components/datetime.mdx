title: "<DateTime>"
description: Format a date and time for the active locale. API reference for the <DateTime> component.

---

`<DateTime>` formats a `Date` with `Intl.DateTimeFormat` rules for the active locale. Inside [`<T>`](/docs/svelte/reference/components/t), it is a variable: the translation places it, and the date is never sent for translation.

## Overview [#overview]

Pass the date as `value`, or as the only child:

```svelte
<DateTime value={new Date('2026-10-29')} />
<!-- en: 10/29/2026 · de: 29.10.2026 -->

<DateTime>{updatedAt}</DateTime>
```

## How it works [#how-it-works]

- **Value.** The value must be a `Date`. `null` and `undefined` render nothing.
- **Children.** The children must be a single `{expression}`, and a component cannot have both `value` and children. Either mistake fails the build.
- **Direction marks.** Right-to-left marks that some locales insert into formatted dates are removed from the output.
- **No wrapper.** The formatted text renders without an HTML element.

The formatting locale follows the same rules as [`<Num>`](/docs/svelte/reference/components/num#formatting-locales): the default locale only while content renders in the default locale or inside an untranslated [`<T>`](/docs/svelte/reference/components/t); otherwise `locales`, then the active locale, then the default locale.

When a page is rendered on the server and hydrated in the browser, both must produce the same text. Set `options.timeZone` if your server and visitors can be in different time zones.

## Props [#props]

| Name | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| [`value`](#value) | The date to format. | `Date \| null \| undefined` | Yes | — |
| [`children`](#children) | The date as a single `{expression}` child. | `Snippet` | Yes | — |
| [`options`](#options) | Options passed to `Intl.DateTimeFormat`. | `Intl.DateTimeFormatOptions` | Yes | `{}` |
| [`locales`](#locales) | Locales to try before the active locale. | `string[]` | Yes | `[]` |
| [`name`](#name) | Variable key used in translations. | `string` | Yes | Generated |

### `value`

**Type** `Date | null | undefined` · **Optional**

The date to format. A missing or `null` value renders nothing.

### `children`

**Type** `Snippet` · **Optional**

The date written as the only child, `<DateTime>{date}</DateTime>`. It must be a single `{expression}`, and it cannot be combined with `value`.

### `options`

**Type** `Intl.DateTimeFormatOptions` · **Optional** · **Default** `{}`

Options for `Intl.DateTimeFormat`. Commonly used fields:

| Option | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| `dateStyle` | Preset date format. | `'full' \| 'long' \| 'medium' \| 'short'` | Yes | — |
| `timeStyle` | Preset time format. | `'full' \| 'long' \| 'medium' \| 'short'` | Yes | — |
| `timeZone` | IANA time zone, such as `UTC` or `Europe/Paris`. | `string` | Yes | Runtime time zone |
| `hour12` | Whether to use a 12-hour clock. | `boolean` | Yes | Locale-dependent |
| `weekday` | Weekday representation. | `'long' \| 'short' \| 'narrow'` | Yes | — |
| `year` | Year representation. | `'numeric' \| '2-digit'` | Yes | — |
| `month` | Month representation. | `'numeric' \| '2-digit' \| 'long' \| 'short' \| 'narrow'` | Yes | — |
| `day` | Day representation. | `'numeric' \| '2-digit'` | Yes | — |
| `hour` | Hour representation. | `'numeric' \| '2-digit'` | Yes | — |
| `minute` | Minute representation. | `'numeric' \| '2-digit'` | Yes | — |
| `second` | Second representation. | `'numeric' \| '2-digit'` | Yes | — |
| `timeZoneName` | Time zone label. | `'long' \| 'short' \| 'shortOffset' \| 'longOffset' \| 'shortGeneric' \| 'longGeneric'` | Yes | — |

`dateStyle` and `timeStyle` cannot be combined with the individual component fields. (See [`Intl.DateTimeFormat` options](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/DateTimeFormat/DateTimeFormat#options) for the full list).

```svelte
<DateTime value={updatedAt} options={{ dateStyle: 'long', timeZone: 'UTC' }} />
```

### `locales`

**Type** `string[]` · **Optional** · **Default** `[]`

Locales to try before the active locale. They are ignored while content renders in the default locale.

### `name`

**Type** `string` · **Optional** · **Default** Generated

The key the variable uses in the translation. Inside [`<T>`](/docs/svelte/reference/components/t), it must be a static string.

## Example [#example]

```svelte title="src/lib/LastUpdated.svelte"
<script lang="ts">
  import { DateTime, T } from 'gt-svelte';

  let { updatedAt }: { updatedAt: Date } = $props();
</script>

<T>
  Last updated <DateTime value={updatedAt} options={{ dateStyle: 'medium', timeZone: 'UTC' }} />.
</T>
```
