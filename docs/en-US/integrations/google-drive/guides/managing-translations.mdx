After the first translation, you can update the same translated copies whenever a source changes. You can also start over with a fresh translation or remove a file from the integration.

## Apply source changes [#apply-changes]

1. Open **Project > Integrations > Connected**, then select the Google Drive integration.
2. Select each source file that changed.
3. Choose the languages to update.
4. Click **Apply changes**.

The integration reuses translations where it can, translates the new or changed content, and updates the existing copies.

Review the result when you change slides, tables, or other parts of the file's structure.

<Callout type="info">
  **Large presentations:** If Google Drive cannot update a presentation in place, the integration creates a replacement, updates the managed link, and moves the previous copy to Drive trash. If moving the old copy fails, both copies may remain.
</Callout>

## Force retranslation [#force]

Use **Force retranslation** when you want a completely new translation instead of reusing previous work.

1. Select at least one file that has a translated version.
2. Check **Force retranslation**.
3. Click **Retranslate**.
4. Review the warning, then confirm.

The warning opens when you click **Retranslate**, not when you select the checkbox, and it always asks for confirmation — there is no way to turn it off.

<Callout type="warn">
  Force retranslation overwrites the existing translations **and any layout changes in the translated copy**, including edits you made by hand, and it uses additional translation credits. The checkbox clears after the forced run, and whenever you change which files are selected.
</Callout>

## Reconnect Google Drive [#drive-access]

If the integration can no longer open or update a file, reconnect the account that provides access:

- For a personal account, click **Connect account** and sign in again.
- For an Organization shared drive, ask an Organization admin to check **Organization > Connections**.

The account or Organization connection must be able to edit the existing translated copy. If it cannot, the integration stops that file and language instead of creating an unrelated duplicate.

## Unlink a source file [#unlink]

Open the file's menu and choose **Remove**. This only removes the file from the integration; it does not delete the source or any translated copies from Google Drive.
