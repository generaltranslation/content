Use the Google Drive integration to translate one or more files at a time. The integration leaves each source file unchanged and creates a separate copy for every language.

## Add and select files [#select-files]

1. Open **Project > Integrations > Connected**.
2. Select the Google Drive integration.
3. Click **Add files** if the source is not listed yet.
4. Select the Google Docs or Google Slides files you want to translate.

Check the **Source** column for each file and change it if the selected language does not match the file.

When selected files use different source languages, the Dashboard starts a separate translation batch for each source language. A file's source language is excluded from its target languages.

## Choose target languages [#select-locales]

Under **Translate into**, choose one or more languages. A file's source language cannot also be one of its target languages.

If the Project does not have the language you need, click **Select locales** and add it without leaving the integration.

## Start translation [#start]

Click **Translate**. The Dashboard shows progress for every file and language, and you can leave the page while translation continues.

<Callout type="info">
  The action changes to **Apply changes** when a selected file already has a translated copy. Select **Force retranslation** to use **Retranslate** and start over instead.
</Callout>

Google Slides presentations may show a formatting step after translation while the integration adjusts the layout for the new text. This appears as **Layout Processing** in Usage and adds a separate per-slide charge; see the [usage rates](https://generaltranslation.com/pricing/usage).

If some files or languages cannot start, the others continue and the Dashboard reports which ones failed.

## Find translated copies [#copies]

The first translation creates one Drive copy for every source file and target language. Open a copy from the integration, or find it next to the source in Google Drive. See [Using translated content](/docs/integrations/google-drive/guides/using-translated-content) for how copies are named and what to check before sharing one.

The integration reuses that copy when you apply source changes later. See [Managing translations](/docs/integrations/google-drive/guides/managing-translations).
