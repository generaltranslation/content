Use the Google Drive integration to translate one or more files at a time. General Translation leaves each source file unchanged and creates a separate copy for every language.

## Add and select files [#select-files]

1. Open **Project > Integrations > Connected**.
2. Select the Google Drive integration.
3. Click **Add files** if the source is not listed yet.
4. Select the Google Docs or Google Slides files you want to translate.

Check the **Source** column for each file and change it if the selected language does not match the file.

## Choose target languages [#select-locales]

Under **Translate into**, choose one or more languages. A file's source language cannot also be one of its target languages.

If the Project does not have the language you need, click **Select locales** and add it without leaving the integration.

## Start translation [#start]

Click **Translate**. The Dashboard shows progress for every file and language, and you can leave the page while translation continues.

Google Slides presentations may show a formatting step after translation while General Translation adjusts the layout for the new text.

## Find translated copies [#copies]

The first translation creates one Drive copy for every source file and target language. Open a copy from the integration, or find it next to the source in Google Drive.

By default, each copy is named:

```text
<source file name> [<target language in the source language>]
```

For example, translating an English file named `Launch plan` into French creates `Launch plan [French]`.

General Translation reuses that copy when you apply source changes later. See [Managing translations](/docs/integrations/google-drive/guides/managing-translations).
