The Google Drive integration translates Google Docs and Google Slides. It keeps each source unchanged and creates one translated copy for every target language.

## Supported file types [#file-types]

- Google Docs
- Google Slides

Google Sheets, PDFs, Microsoft Office files, images, and folders are not supported.

General Translation preserves the structure of Google Docs. For Google Slides, it also adjusts the translated presentation's layout for the new text.

## Ways to connect [#access-modes]

- **Personal account:** each person signs in with Google and chooses the files they want to translate. General Translation can access those files and the translated copies it creates.
- **Organization shared drive:** everyone with Project access uses a shared connection set up by an Organization admin.

To set up an Organization shared drive:

1. Open **Organization > Connections**.
2. Click **Add connection**, then **Set up** for Google Drive.
3. Add the displayed email to the shared drive as a **Content manager**.
4. Return to the Dashboard and click **Verify access**.

## Translated copies [#translated-copies]

The integration creates one copy for every source file and target language. By default, the copy sits next to the source and is named `<source file name> [<target language>]`.

For example, an English file named `Launch plan` becomes `Launch plan [French]` when translated into French.

Later runs update the same copy. If that copy was deleted or moved to trash, General Translation creates a new one the next time it translates the file.

## Updating translations [#update-behavior]

- **Apply changes** reuses existing translations where possible and updates the translated copy.
- **Force retranslation** translates from scratch and replaces translated text and layout changes in the copy.

Review the translated copy when you add, remove, or rearrange slides, tables, or other structural content.
