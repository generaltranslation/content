Each linked file carries its own source language, and the integration creates one translated Drive copy per target language. Files with different source languages are translated in separate batches.

## Overview [#overview]

| Setting | Description | Optional | Default |
| --- | --- | --- | --- |
| [Source language](#source) | The language of a linked file, shown in the **Source** column. | No | The Project's default locale |
| [Target languages](#targets) | The languages chosen under **Translate into**. | No | — |

## Source language [#source]

**Required** · **Default** the Project's default locale

A file takes the Project's default locale as its source language when you link it. The **Source** column on the management page shows that value, and you can change it per file when the detected language is wrong.

Getting this right matters because the source language is excluded from the file's target languages and decides the language used in [translated copy names](/docs/integrations/google-drive/guides/using-translated-content#names).

When the selected files do not all share one source language, the Dashboard starts a separate translation batch for each source language.

## Target languages [#targets]

**Required**

The **Translate into** menu offers the Project's configured locales, minus the source language of each selected file.

At least one target language is required. When the Project has no other locales configured, the primary action reads **Select locales** and opens the locale menu instead of starting a translation; add locales there from the [supported locales](/docs/platform/dashboard/reference/supported-locales) without leaving the integration.

When a linked file already has translations, the languages already used on the integration are preselected.
