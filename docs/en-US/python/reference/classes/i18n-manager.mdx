title: I18nManager

The central object that holds locale configuration, loads and caches translations, and tracks the current request locale. [`initialize_gt`](/docs/python/reference/functions/initialize-gt) builds one for you; in the core `gt-i18n` library you construct it directly and register it with [`set_i18n_manager`](/docs/python/reference/functions/set-i18n-manager).

## Overview [#overview]

Construct an `I18nManager` with keyword-only arguments, then register it as the active manager. Every translation function reads from the registered manager.

```python
from gt_i18n import I18nManager, set_i18n_manager

manager = I18nManager(default_locale="en", locales=["es", "fr"])
set_i18n_manager(manager)
```

Signature:

```python
I18nManager(
    *,
    default_locale: str = "en",
    locales: list[str] | None = None,
    project_id: str | None = None,
    cache_url: str | None = None,
    custom_mapping: CustomMapping | None = None,
    store_adapter: StorageAdapter | None = None,
    load_translations: TranslationsLoader | None = None,
    cache_expiry_time: int = 60_000,
    version_id: str | None = None,
    branch_id: str | None = None,
)
```

Import `I18nManager` from `gt_i18n`. It is not re-exported by the framework packages.

## How it works [#how-it-works]

- **Locale set.** The default locale is always merged into `locales`, so the manager's locale set always contains it.
- **Loader selection.** If `load_translations` is given it is used; otherwise, if `project_id` is set and `cache_url` is not an empty string, a CDN loader for `{cache_url}/{project_id}/{locale}` is created (followed by `/{version_id}` and `?branchId={branch_id}` when they are set); otherwise a no-op loader returns an empty dict.
- **Caching.** Loaded translations are cached per locale and expire after `cache_expiry_time` milliseconds. `get_translations` (async) and `get_translations_blocking` (sync) load a locale on first use and reload an expired one in the background; `get_translations_sync` only reads the cache and never blocks.
- **Locale storage.** The current locale is stored through `store_adapter` (a [`ContextVarStorageAdapter`](/docs/python/reference/classes/context-var-storage-adapter) by default), which isolates the value per request in both threaded and async contexts.

### `default_locale` [#default-locale]

**Type** `str` · **Optional** · **Default** `"en"`

The source and fallback locale. Defaults to the library default `"en"` (`LIBRARY_DEFAULT_LOCALE`).

### `locales` [#locales]

**Type** `list[str]` · **Optional** · **Default** `None`

Target locales the application supports. The default locale is always added to the set.

### `project_id` [#project-id]

**Type** `str` · **Optional** · **Default** `None`

The General Translation project ID. When set and no `load_translations` is provided, the manager builds a CDN loader.

### `cache_url` [#cache-url]

**Type** `str` · **Optional** · **Default** `None`

The CDN base URL used by the remote loader. `None` uses the General Translation CDN, `https://cdn.gtx.dev`; an empty string turns CDN loading off.

### `custom_mapping` [#custom-mapping]

**Type** [`CustomMapping`](/docs/platform/core/reference/types/custom-mapping) · **Optional** · **Default** `None`

Custom locale codes and property overrides, forwarded to the underlying [`GT`](/docs/platform/core/reference/gt-class/constructor) instance.

### `store_adapter` [#store-adapter]

**Type** [`StorageAdapter`](/docs/python/reference/classes/storage-adapter) · **Optional** · **Default** [`ContextVarStorageAdapter`](/docs/python/reference/classes/context-var-storage-adapter)

The storage adapter for per-request locale state. Defaults to [`ContextVarStorageAdapter`](/docs/python/reference/classes/context-var-storage-adapter).

### `load_translations` [#load-translations]

**Type** [`TranslationsLoader`](/docs/python/reference/classes/translations-loader) · **Optional** · **Default** `None`

A custom loader returning translations for a locale. Overrides the CDN loader when provided.

### `cache_expiry_time` [#cache-expiry]

**Type** `int` · **Optional** · **Default** `60000`

Cache lifetime in milliseconds (default 60000, i.e. 60 seconds). Once an entry is older than this, the next call to `get_translations` or `get_translations_blocking` returns it at once and starts one reload in the background. The Flask and FastAPI integrations make that call before each request for a configured locale that needs translation. Until a reload succeeds, `get_translations_sync` (what [`t`](/docs/python/reference/functions/t) reads) returns the previous translations. [`initialize_gt`](/docs/python/reference/functions/initialize-gt) does not expose this parameter.

### `version_id` [#version-id]

**Type** `str` · **Optional** · **Default** `None`

A pinned translation version, returned by [`get_version_id`](/docs/python/reference/functions/get-version-id). CDN requests add `/{version_id}` after the locale.

### `branch_id` [#branch-id]

**Type** `str` · **Optional** · **Default** `None`

The General Translation branch of the pinned version (the `_branchId` config key). CDN requests add `?branchId={branch_id}`.

### `default_locale` [#member-default-locale]

A read-only property returning the source/default locale.

### `get_locale()` [#member-get-locale]

Returns the current request locale from the storage adapter, falling back to the default locale.

### `set_locale(locale)` [#member-set-locale]

Writes the current request locale to the storage adapter.

### `get_locales()` [#member-get-locales]

Returns a copy of the supported locale list (always including the default locale).

### `get_version_id()` [#member-version-id]

Returns the configured version id, or `None`.

### `requires_translation(locale=None)` [#member-requires]

Returns whether `locale` (or the current locale) needs translation from the default, checked against the configured locales.

### `get_translations(locale=None)` [#member-get-translations]

An async method that returns translations for `locale` (or the current locale). The first call for a locale waits for its load, and concurrent callers share that load. After expiry it returns the cached translations at once and reloads them in the background. When a load fails, the previous translations are kept, or an empty dict is returned if there are none. A synchronous `load_translations` callback runs on a worker thread, off the event loop.

### `get_translations_blocking(locale=None)` [#member-get-blocking]

The synchronous counterpart of `get_translations`, for synchronous frameworks such as Flask. The first call for a locale blocks until its load finishes, and other threads asking for the same locale wait for that one load. After expiry it returns the cached translations at once while one background thread reloads them.

### `get_translations_sync(locale=None)` [#member-get-sync]

Returns the last loaded translations for `locale` (or the current locale) without blocking, even after they expire, or an empty dict when the locale has never loaded. This is what [`t`](/docs/python/reference/functions/t) reads.

### `load_all_translations()` [#member-load-all]

An async method that eagerly loads translations for every configured locale.

### `load_all_translations_blocking()` [#member-load-all-blocking]

The synchronous counterpart of `load_all_translations`. It works whether or not an event loop is already running in the calling thread, which is how the Flask integration loads translations at startup.

### `get_gt_instance()` [#member-gt-instance]

Returns a `GT` instance configured with the manager's project id, source locale, current target locale, locales, and custom mapping.

## Example [#example]

```python
import asyncio
from gt_i18n import I18nManager, set_i18n_manager, t

def load_translations(locale: str) -> dict[str, str]:
    return {}  # load from your own source

manager = I18nManager(default_locale="en", locales=["es"], load_translations=load_translations)
set_i18n_manager(manager)

asyncio.run(manager.load_all_translations())  # preload
manager.set_locale("es")
t("Hello, world!")
```
