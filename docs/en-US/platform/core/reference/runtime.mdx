Import `GTRuntime` from `generaltranslation/runtime` when your application does not need file or project management. The supported [`GT`](/docs/platform/core/reference/gt-class/constructor) class extends it and adds those management methods.

| Export | Description |
| --- | --- |
| [`GTRuntime`](#runtime) | Runtime translation, formatting, and locale methods. |
| [`GTConstructorParams`](#configuration) | Shared constructor and reconfiguration options. |

## `GTRuntime` [#runtime]

**Type** class · **Constructor** `new GTRuntime(params?: GTConstructorParams)`

The runtime entry excludes the file/project-management client. It retains [`translate`](/docs/platform/core/reference/gt-class-methods/translation/translate), [`translateMany`](/docs/platform/core/reference/gt-class-methods/translation/translate-many), formatting, locale helpers, and [`setConfig`](/docs/platform/core/reference/gt-class/set-config). Their runtime contracts match the inherited methods on [`GT`](/docs/platform/core/reference/gt-class/constructor).

```ts title="format.ts"
import { GTRuntime } from 'generaltranslation/runtime';

const runtime = new GTRuntime({ sourceLocale: 'en', targetLocale: 'en-US' });
console.log(runtime.formatNum(1234.5)); // 1,234.5
```

Formatting and locale helpers need no API credentials. Runtime translation requires a project ID and an API key or application-owned [token provider](/docs/platform/core/reference/api-client#usertokenprovider). Its numeric third timeout argument uses 60000 ms when omitted or zero; it does not accept `false`.

This is a bundle boundary, not a security boundary. Do not embed API keys in deployed browser or mobile bundles. Use the root class for trusted server tooling and the [API client](/docs/platform/core/reference/api-client) for generated endpoint-level access.

## `GTConstructorParams` [#configuration]

**Type** object · **Optional** · **Default** `{}`

Import the type from `generaltranslation/runtime`. It is the same [constructor configuration](/docs/platform/core/reference/types/gt-constructor-params) used by the root class: credentials, provider, project ID, base URL, locales, and custom mapping. It does not accept `fetch`, `timeoutMs`, `retryPolicy`, or `apiVersion`.

```ts
import { GTRuntime, type GTConstructorParams } from 'generaltranslation/runtime';

const config: GTConstructorParams = {
  sourceLocale: 'en-us',
  locales: ['en-us', 'cn'],
  customMapping: { cn: { code: 'zh' } },
};
const runtime = new GTRuntime(config);
console.log(runtime.sourceLocale); // en-us
console.log(runtime.locales); // ['en-us', 'cn']
```

Configured identities are preserved; service requests canonicalize them. Use [`setConfig`](/docs/platform/core/reference/gt-class/set-config) to reconfigure an instance. Updates are not atomic, do not re-read environment variables, and cannot clear credentials or providers with empty strings or `undefined`.
