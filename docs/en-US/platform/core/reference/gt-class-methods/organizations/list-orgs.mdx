Lists the Organizations the configured API key can access. Use it to find the Organization ID to pass to [`account.org()`](/docs/platform/core/reference/gt-class/org).

## Overview [#overview]

```typescript
const account = new GT({ apiKey: 'your-org-api-key' });

const orgs = await account.listOrgs();
const org = account.org(orgs[0].id);
```

Signature:

```typescript
listOrgs(): Promise<{ id: string; name: string }[]>
```

*Note: `listOrgs` is a method of an account-scoped [`GT`](/docs/platform/core/reference/gt-class/constructor) instance (constructed without `projectId`). It calls `GET /v2/orgs`, which needs no permission. Use an Organization API key: with a project API key, the constructor throws and asks for `projectId`.*

## How it works [#how-it-works]

- **API key's Organization.** An API key returns the Organization it belongs to.
- **Every page.** The method requests page after page until the list ends and resolves with every Organization, ordered by ID.
- **No creation permission.** Listing an Organization does not mean the key can create projects in it; [`createProject`](/docs/platform/core/reference/gt-class-methods/organizations/create-project) needs `org:projects:create`.
- **Errors.** A failed request throws an [`ApiError`](/docs/platform/core/reference/api-client#api-error) with the HTTP status as `code`.

## Parameters [#parameters]

`listOrgs` takes no parameters.

## Returns [#returns]

**Type** `Promise<{ id: string; name: string }[]>`

| Field | Description | Type |
| --- | --- | --- |
| `id` | Organization ID. | `string` |
| `name` | Organization name. | `string` |

## Examples [#examples]

```typescript title="index.ts"
import { GT } from 'generaltranslation';

const account = new GT({ apiKey: process.env.GT_ORG_API_KEY! });

const [first] = await account.listOrgs();
if (first) {
  const { project } = await account.org(first.id).createProject({
    name: 'Marketing site',
    defaultLocale: 'en',
  });
  console.log(project.id);
}
```

(See the [List Organizations](/docs/platform/openapi/reference/organizations/list-orgs) endpoint for the HTTP contract).
