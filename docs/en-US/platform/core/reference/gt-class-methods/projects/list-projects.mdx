Lists the projects the configured API key can access. Use it to find the project ID to pass as `projectId` to the [`GT`](/docs/platform/core/reference/gt-class/constructor) constructor or to [`account.project()`](/docs/platform/core/reference/gt-class/project).

## Overview [#overview]

```typescript
const account = new GT({ apiKey: 'your-org-api-key' });

const projects = await account.listProjects();
const project = account.project(projects[0].id);
```

Signature:

```typescript
listProjects(): Promise<{ id: string; name: string; orgId: string; orgName: string }[]>
```

*Note: `listProjects` is a method of an account-scoped [`GT`](/docs/platform/core/reference/gt-class/constructor) instance (constructed without `projectId`). It calls `GET /v2/projects`, which needs no permission.*

## How it works [#how-it-works]

- **Selected by the API key.** An Organization API key returns the projects in its Organization. A project API key cannot construct an account-scoped `GT` instance: the constructor throws and asks for `projectId`.
- **Every page.** The method requests page after page until the list ends and resolves with every project, ordered by ID.
- **Errors.** A failed request throws an [`ApiError`](/docs/platform/core/reference/api-client#api-error) with the HTTP status as `code`.

## Parameters [#parameters]

`listProjects` takes no parameters.

## Returns [#returns]

**Type** `Promise<{ id: string; name: string; orgId: string; orgName: string }[]>`

| Field | Description | Type |
| --- | --- | --- |
| `id` | Project ID. | `string` |
| `name` | Project name. | `string` |
| `orgId` | ID of the Organization that owns the project. | `string` |
| `orgName` | Name of the Organization that owns the project. | `string` |

## Examples [#examples]

```typescript title="index.ts"
import { GT } from 'generaltranslation';

const account = new GT({ apiKey: process.env.GT_ORG_API_KEY! });

for (const { id, name } of await account.listProjects()) {
  const { currentLocales } = await account.project(id).get();
  console.log(name, currentLocales);
}
```

(See the [List Projects](/docs/platform/openapi/reference/projects/list-projects) endpoint for the HTTP contract).
