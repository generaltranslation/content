title: gt.update
description: Change a project's default locale or CDN delivery setting. API reference for gt.update.

---

Updates settings of the [`GT`](/docs/platform/core/reference/gt-class/constructor) instance's project and returns the updated project. Omitted settings stay unchanged.

## Overview [#overview]

```typescript
const gt = new GT({ apiKey: 'your-api-key', projectId: 'your-project-id' });

const updated = await gt.update({ defaultLocale: 'en' });
```

Signature:

```typescript
update(
  body: { defaultLocale?: string; cdnEnabled?: boolean },
  options?: { timeout?: number }
): Promise<UpdateProjectResponse>
```

*Note: `update` is a method of a project-scoped [`GT`](/docs/platform/core/reference/gt-class/constructor) instance (a [`ProjectHandle`](/docs/platform/core/reference/types/project-handle)) and requires an API key with the `project:write` permission.*

## How it works [#how-it-works]

- **Partial update.** Only the fields you pass change.
- **Locale spelling.** `defaultLocale` is sent in its canonical form, and the returned locales follow the [constructor rules](/docs/platform/core/reference/gt-class/constructor#how-it-works).
- **Source uploads do not change it.** Uploading source files with [`uploadSourceFiles`](/docs/platform/core/reference/gt-class-methods/files/upload-source-files) never changes the project's default locale. Call `update` when your source locale changes.
- **Errors.** A key without `project:write` receives a `403` [`ApiError`](/docs/platform/core/reference/api-client#api-error).

## Parameters [#parameters]

| Parameter | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| [`body`](#body) | Settings to change. | `{ defaultLocale?: string; cdnEnabled?: boolean }` | No | — |
| [`options`](#options) | Request settings. | `{ timeout?: number }` | Yes | `{}` |

### `body`

**Type** `{ defaultLocale?: string; cdnEnabled?: boolean }` · **Required**

| Field | Description | Type | Optional |
| --- | --- | --- | --- |
| `defaultLocale` | The project's source locale. | `string` | Yes |
| `cdnEnabled` | Enable or disable CDN delivery. | `boolean` | Yes |

### `options`

**Type** `{ timeout?: number }` · **Optional** · **Default** `{}`

`timeout` sets the request timeout in milliseconds.

## Returns [#returns]

**Type** `Promise<UpdateProjectResponse>`

The updated project, with the same fields as [`gt.get`](/docs/platform/core/reference/gt-class-methods/projects/get-project#returns): `id`, `name`, `orgId`, `defaultLocale`, `currentLocales`, `autoApprove`, and `cdnEnabled`.

## Examples [#examples]

```typescript title="index.ts"
import { GT } from 'generaltranslation';

const gt = new GT({
  apiKey: process.env.GT_API_KEY!,
  projectId: process.env.GT_PROJECT_ID!,
});

// Turn on CDN delivery so published translations are served from the CDN.
const updated = await gt.update({ cdnEnabled: true });
console.log(updated.cdnEnabled); // true
```

(See the [Update a project](/docs/platform/openapi/reference/projects/update-project) endpoint for the HTTP contract).
