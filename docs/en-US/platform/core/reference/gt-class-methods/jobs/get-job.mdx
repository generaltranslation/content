title: getJob
description: Read the status and subject of one translation or context generation job. API reference for getJob.

---

Reads one job in the project set by `projectId` on the [GT](/docs/platform/core/reference/gt-class/constructor) instance. Use [`queryJobs`](/docs/platform/core/reference/gt-class-methods/jobs/query-jobs) to read several jobs in one call.

## Overview [#overview]

```typescript
const gt = new GT({ apiKey: 'your-api-key', projectId: 'your-project-id' });

const job = await gt.getJob('job-123');
```

Signature:

```typescript
getJob(jobId: string, options?: { timeout?: number }): Promise<GetJobResponse>
```

*Note: `getJob` requires `apiKey` and `projectId` on the GT instance, and an API key with the `project:files:read` permission.*

## How it works [#how-it-works]

- **Unknown jobs.** A job the project does not have fails with `404` and throws an [`ApiError`](/docs/platform/core/reference/api-client#api-error). [`queryJobs`](/docs/platform/core/reference/gt-class-methods/jobs/query-jobs) returns `not_found` instead.

## Parameters [#parameters]

| Parameter | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| [`jobId`](#job-id) | The job to read. | `string` | No | — |
| [`options`](#options) | Request settings. | `{ timeout?: number }` | Yes | `{}` |

### `jobId` [#job-id]

**Type** `string` · **Required**

Job ID returned when the job was queued.

### `options`

**Type** `{ timeout?: number }` · **Optional** · **Default** `{}`

`timeout` sets the request timeout in milliseconds.

## Returns [#returns]

**Type** `Promise<GetJobResponse>`

```typescript
type GetJobResponse = {
  id: string;
  status: 'queued' | 'processing' | 'completed' | 'failed';
  subject: JobSubject;
  error: string | null; // failure reason of a failed job
};
```

`JobSubject` and the status values are described in [`queryJobs`](/docs/platform/core/reference/gt-class-methods/jobs/query-jobs#returns).

## Examples [#examples]

```typescript title="index.ts"
import { GT } from 'generaltranslation';

const gt = new GT({
  apiKey: process.env.GT_API_KEY,
  projectId: process.env.GT_PROJECT_ID,
});

const { job } = await gt.generateProjectContext(files);
if (job) {
  const current = await gt.getJob(job.id);
  console.log(current.status);
}
```
