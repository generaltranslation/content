`OrgHandle` is the object returned by [`account.org()`](/docs/platform/core/reference/gt-class/org) on an account-scoped [`GT`](/docs/platform/core/reference/gt-class/constructor) instance. It carries the methods that work on one Organization, and uses the API key, base URL, and `localeConfig` of the instance that created it.

## Overview [#overview]

Import the type from `generaltranslation`. It is a type-only export: create handles with [`account.org()`](/docs/platform/core/reference/gt-class/org), not a constructor.

```typescript
import { GT, type OrgHandle } from 'generaltranslation';

const account = new GT({ apiKey: process.env.GT_ORG_API_KEY! });
const org: OrgHandle = account.org('your-org-id');
```

The handle is frozen and has no properties besides its methods.

## Methods [#methods]

Each method calls one [API](/docs/platform/core/reference/api-client) operation for the handle's Organization. Both need an Organization API key.

| Method | Description |
| --- | --- |
| [`createProject`](/docs/platform/core/reference/gt-class-methods/organizations/create-project) | Create a project in the Organization. |
| [`upsertAssets`](/docs/platform/core/reference/gt-class-methods/organizations/upsert-assets) | Upload fonts used by Lottie translations. |

## Example [#example]

```typescript title="index.ts"
import { GT } from 'generaltranslation';

const account = new GT({ apiKey: process.env.GT_ORG_API_KEY! });
const [first] = await account.listOrgs();
const org = account.org(first.id);

const { project } = await org.createProject({ name: 'Storefront', defaultLocale: 'en' });
```

## Notes [#notes]

- Find the Organization ID with [`listOrgs`](/docs/platform/core/reference/gt-class-methods/organizations/list-orgs), or read `orgId` from a project with [`gt.get`](/docs/platform/core/reference/gt-class-methods/projects/get-project).
- Project methods are on [`ProjectHandle`](/docs/platform/core/reference/types/project-handle).
