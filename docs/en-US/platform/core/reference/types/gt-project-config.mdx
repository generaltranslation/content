title: GTProjectConfig

`GTProjectConfig` is the object passed to a project-scoped [`GT`](/docs/platform/core/reference/gt-class/constructor) and to [`GTRuntime`](/docs/platform/core/reference/runtime): the API key, the project, its locales, and the endpoint.

## Overview [#overview]

`apiKey` and `projectId` are required, and nothing is read from environment variables. For an account-scoped `GT` without a project, use [`GTAccountConfig`](/docs/platform/core/reference/types/gt-account-config).

```typescript
type GTProjectConfig = {
  apiKey: string;
  projectId: string;
  localeConfig?: LocaleConfig;
  baseUrl?: string;
};
```

Import the type from `generaltranslation` or `generaltranslation/runtime`.

## Properties [#properties]

| Property | Description | Type | Optional |
| --- | --- | --- | --- |
| [`apiKey`](#api-key) | API key for the General Translation API. | `string` | No |
| [`projectId`](#project-id) | Project to work on. | `string` | No |
| [`localeConfig`](#locale-config) | Default locale, supported locales, and custom mapping. | [`LocaleConfig`](/docs/platform/core/reference/types/locale-config) | Yes |
| [`baseUrl`](#base-url) | API endpoint. Defaults to `https://api.gtx.dev`. | `string` | Yes |

### `apiKey` [#api-key]

**Type** `string` · **Required**

API key for the General Translation API. Pass it explicitly, for example `process.env.GT_API_KEY!`; the constructors do not read `GT_API_KEY`.

### `projectId` [#project-id]

**Type** `string` · **Required**

ID of the project to work on. An empty or blank string throws. The constructors do not read `GT_PROJECT_ID`. A value typed `string | undefined` matches neither `GTProjectConfig` nor [`GTAccountConfig`](/docs/platform/core/reference/types/gt-account-config); check it first, or pass `?? ''` to get the empty-ID error at construction.

### `localeConfig` [#locale-config]

**Type** [`LocaleConfig`](/docs/platform/core/reference/types/locale-config) · **Optional** · **Default** `{}`

`{ defaultLocale?, locales?, customMapping? }`. `defaultLocale` is the default source locale for runtime translation, and `customMapping` resolves locale aliases before requests. Returned locale codes follow the [constructor rules](/docs/platform/core/reference/gt-class/constructor#how-it-works).

### `baseUrl` [#base-url]

**Type** `string` · **Optional** · **Default** `https://api.gtx.dev`

API endpoint. Override it only when your deployment uses a different endpoint.

## Example [#example]

```typescript
import { GT, type GTProjectConfig } from 'generaltranslation';

const projectId = process.env.GT_PROJECT_ID;
if (!projectId) throw new Error('Set GT_PROJECT_ID');

const config: GTProjectConfig = {
  apiKey: process.env.GT_API_KEY!,
  projectId,
  localeConfig: {
    defaultLocale: 'en',
    locales: ['en', 'es', 'fr'],
  },
};

const gt = new GT(config);
```
