`LocaleConfig` is a plain object that describes the locales your application uses. Pass the same object to [`GTIntl`](/docs/platform/core/reference/gt-intl/constructor) for formatting and to [`GT`](/docs/platform/core/reference/gt-class/constructor) or [`GTRuntime`](/docs/platform/core/reference/runtime) as `localeConfig`.

## Overview [#overview]

Import the type from `generaltranslation`, `generaltranslation/runtime`, or `@generaltranslation/format`. It is a type, not a class: it has no methods.

```typescript
type LocaleConfig = {
  defaultLocale?: string;
  locales?: readonly string[];
  customMapping?: CustomMapping;
};
```

```typescript
import { GT, GTIntl, type LocaleConfig } from 'generaltranslation';

const localeConfig: LocaleConfig = {
  defaultLocale: 'en',
  locales: ['en', 'es', 'fr'],
};

const intl = new GTIntl(localeConfig, { locale: 'es' });
const gt = new GT({
  apiKey: process.env.GT_API_KEY!,
  projectId: process.env.GT_PROJECT_ID!,
  localeConfig,
});
```

## Properties [#properties]

| Property | Description | Type | Optional |
| --- | --- | --- | --- |
| [`defaultLocale`](#default-locale) | The application's default locale. | `string` | Yes |
| [`locales`](#locales) | The locales the application supports. | `readonly string[]` | Yes |
| [`customMapping`](#custom-mapping) | Locale aliases and locale property overrides. | [`CustomMapping`](/docs/platform/core/reference/types/custom-mapping) | Yes |

### `defaultLocale` [#default-locale]

**Type** `string` · **Optional** · **Default** `en`

The application's default locale. [`GTIntl`](/docs/platform/core/reference/gt-intl/constructor) falls back to it when no target locale is set, so it is also the language locales are named in. `GT` and `GTRuntime` use it as the default source locale for runtime translation.

### `locales` [#locales]

**Type** `readonly string[]` · **Optional** · **Default** `[]`

The locales the application supports. [`GTIntl`](/docs/platform/core/reference/gt-intl/constructor) uses them as the approved locales of [`determineLocale`](/docs/platform/core/reference/gt-intl-methods/locales/determine-locale) and [`requiresTranslation`](/docs/platform/core/reference/gt-intl-methods/locales/requires-translation); for [`requiresTranslation`](/docs/platform/core/reference/gt-intl-methods/locales/requires-translation), omitted `locales` mean no restriction, and an empty list approves none. `GT` restores returned locale codes to these spellings where possible.

### `customMapping` [#custom-mapping]

**Type** [`CustomMapping`](/docs/platform/core/reference/types/custom-mapping) · **Optional**

Locale aliases and overrides of locale properties such as names and emojis. Aliases are resolved before formatting and before a locale is sent to the API.

## Notes [#notes]

- `GT`, `GTRuntime`, their handles, and [`GTIntl`](/docs/platform/core/reference/gt-intl/constructor) keep a frozen copy of the object from construction, including the `locales` array and each `customMapping` entry. Later changes to your object have no effect on them, and the configuration they expose is read-only.
- `locales` accepts a readonly array, so an instance's `localeConfig` can configure another instance.
- Locale codes are not validated when an instance is constructed.
