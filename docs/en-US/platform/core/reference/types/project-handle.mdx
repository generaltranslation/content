`ProjectHandle` is the type of a project-scoped [`GT`](/docs/platform/core/reference/gt-class/constructor) instance, `new GT({ apiKey, projectId })`, and of the handles returned by [`account.project()`](/docs/platform/core/reference/gt-class/project). It carries every method that works on one project, with the API key, base URL, and `localeConfig` it was created with.

## Overview [#overview]

Import the type from `generaltranslation`. It is a type-only export: create one with the [`GT`](/docs/platform/core/reference/gt-class/constructor) constructor or [`account.project()`](/docs/platform/core/reference/gt-class/project).

```typescript
import { GT, type ProjectHandle } from 'generaltranslation';

const gt: ProjectHandle = new GT({ apiKey: 'your-api-key', projectId: 'your-project-id' });

async function defaultLocaleOf(project: ProjectHandle) {
  return (await project.get()).defaultLocale;
}
```

`ProjectHandle` extends [`GTRuntime`](/docs/platform/core/reference/runtime), so code typed for runtime translation also accepts a `ProjectHandle`.

## Properties [#properties]

| Property | Description | Type | Optional |
| --- | --- | --- | --- |
| [`projectId`](#project-id) | ID of the project the handle works on. | `string` | No |

### `projectId` [#project-id]

**Type** `string` · **Required** · **Read-only**

The ID passed as `projectId` to the [`GT`](/docs/platform/core/reference/gt-class/constructor) constructor or to [`account.project()`](/docs/platform/core/reference/gt-class/project). The handle is frozen, so the ID cannot change.

## Example [#example]

```typescript title="index.ts"
import { GT } from 'generaltranslation';

const gt = new GT({
  apiKey: process.env.GT_API_KEY!,
  projectId: process.env.GT_PROJECT_ID!,
});

const { items: branches } = await gt.listBranches();
const result = await gt.translate('Hello, world!', 'es');
```

## Notes [#notes]

- Organization methods are on [`OrgHandle`](/docs/platform/core/reference/types/org-handle), from an account-scoped `GT` instance. The `orgId` returned by [`get`](/docs/platform/core/reference/gt-class-methods/projects/get-project) identifies the project's Organization.
- A `ProjectHandle` keeps the configuration it was created with. For a different API key or base URL, construct a new `GT` instance.
- API failures throw an [`ApiError`](/docs/platform/core/reference/api-client#api-error).
