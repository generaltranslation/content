---

title: Translation configuration
description: Distinguish translation metadata from request transport configuration. API reference for TranslateOptions, TranslationRequestConfig, and TranslateConfig.

---

Import these public types from `generaltranslation/types`. They describe distinct boundaries; request configuration is not interchangeable with constructor configuration ([`GTProjectConfig`](/docs/platform/core/reference/types/gt-project-config), [`GTAccountConfig`](/docs/platform/core/reference/types/gt-account-config)).

| Type | Description |
| --- | --- |
| [`TranslateOptions`](#translate-options) | Required target locale and optional translation metadata. |
| [`TranslationRequestConfig`](#request-config) | Shared request credentials, project ID, and transport settings. |
| [`TranslateConfig`](#translate-config) | Request configuration with a custom mapping. |

## `TranslateOptions` [#translate-options]

**Type** object · **Required** as the object-form second argument to class translation methods

| Field | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| `targetLocale` | Locale to translate into. | `string` | No | — |
| `sourceLocale` | Source locale override. | `string` | Yes | `localeConfig.defaultLocale`, then `en` |
| `modelProvider` | Provider selection, validated before fetch. | `string` | Yes | — |

The request sends only `modelProvider` as translation metadata. Transport settings such as `fetch` and `timeoutMs` belong to [`TranslationRequestConfig`](#request-config). Class translation methods always require an explicit target locale.

A provided `modelProvider` must be `ANTHROPIC`, `OPENAI`, `XAI`, `GOOGLE`, or `HYPERCLOVA`; other values reject locally before fetch. Omission or `undefined` is allowed. [Service entitlements](/docs/platform/core/reference/gt-class-methods/translation/translate-files#model-provider) apply separately.

```ts
import { GT } from 'generaltranslation';
import type { TranslateOptions } from 'generaltranslation/types';

const gt = new GT({
  apiKey: process.env.GT_API_KEY!,
  projectId: process.env.GT_PROJECT_ID!,
});
const options: TranslateOptions = { targetLocale: 'es', sourceLocale: 'en' };
const result = await gt.translate('Hello', options, 30000);
if (result.success) console.log(result.translation);
```

## `TranslationRequestConfig` [#request-config]

**Type** object · **Required field** `projectId`

This shared request type uses transport settings from [`ApiClientConfig`](/docs/platform/core/reference/api-client#client-config). For example, configure an API-key request with a 30-second timeout:

```ts
import type { TranslationRequestConfig } from 'generaltranslation/types';

const config: TranslationRequestConfig = {
  apiKey: 'your-api-key',
  projectId: 'your-project-id',
  timeoutMs: 30000,
};
```

| Field | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| `projectId` | Project identifier. | `string` | No | — |
| `apiKey` | Explicit API key. | `string` | Yes | — |
| `apiVersion` | API contract version. | `ApiVersion` | Yes | `API_VERSION` |
| `baseUrl` | Runtime API origin. | `string` | Yes | `https://api.gtx.dev` |
| `fetch` | Fetch implementation wrapped by timeout and error handling. | `typeof fetch` | Yes | `globalThis.fetch` |
| `timeoutMs` | Runtime-owned timer in milliseconds. | `number \| false` | Yes | `60000` |

These explicit configurations do not read environment variables. `GT` and `GTRuntime` take the API key and project ID as constructor options and read no environment variables either.

For this type, `0` is literal zero and `false` disables only the runtime-owned timer, not custom-fetch cancellation.

This is a public type, not a public standalone `translate(config)` function. Class translation methods instead accept a numeric [timeout argument](/docs/platform/core/reference/gt-class-methods/translation/translate#timeout).

## `TranslateConfig` [#translate-config]

**Type** object · **Required field** `projectId`

```ts
import type { CustomMapping, TranslationRequestConfig } from 'generaltranslation/types';

type TranslateConfig = TranslationRequestConfig & {
  customMapping?: CustomMapping;
};
```

All request fields retain the behavior above, including the required `projectId`. `customMapping` is optional with no default and resolves locale aliases before requests. It does not restore aliases in runtime translation results.
