title: GTAccountConfig
description: Configuration for an account-scoped GT instance, which has no project. API reference for the GTAccountConfig type.

`GTAccountConfig` is the object passed to an account-scoped [`GT`](/docs/platform/core/reference/gt-class/constructor), which lists Organizations and projects and scopes work with [`account.project()`](/docs/platform/core/reference/gt-class/project) and [`account.org()`](/docs/platform/core/reference/gt-class/org).

## Overview [#overview]

`apiKey` is required, and `projectId` must be absent. With a project, use [`GTProjectConfig`](/docs/platform/core/reference/types/gt-project-config).

```typescript
type GTAccountConfig = {
  apiKey: string;
  projectId?: never;
  localeConfig?: LocaleConfig;
  baseUrl?: string;
};
```

Import the type from `generaltranslation`.

## Properties [#properties]

| Property | Description | Type | Optional |
| --- | --- | --- | --- |
| [`apiKey`](#api-key) | Organization API key. | `string` | No |
| [`localeConfig`](#locale-config) | Default locale, supported locales, and custom mapping. | [`LocaleConfig`](/docs/platform/core/reference/types/locale-config) | Yes |
| [`baseUrl`](#base-url) | API endpoint. Defaults to `https://api.gtx.dev`. | `string` | Yes |

### `apiKey` [#api-key]

**Type** `string` · **Required**

An Organization API key. A project API key (starting with `gtx-api-`) throws at construction, because it needs a `projectId`. The constructor does not read `GT_API_KEY`.

### `localeConfig` [#locale-config]

**Type** [`LocaleConfig`](/docs/platform/core/reference/types/locale-config) · **Optional** · **Default** `{}`

`{ defaultLocale?, locales?, customMapping? }`. Handles from [`account.project()`](/docs/platform/core/reference/gt-class/project) and [`account.org()`](/docs/platform/core/reference/gt-class/org) use it: `customMapping` resolves locale aliases before requests, and returned locale codes follow the [constructor rules](/docs/platform/core/reference/gt-class/constructor#how-it-works).

### `baseUrl` [#base-url]

**Type** `string` · **Optional** · **Default** `https://api.gtx.dev`

API endpoint. Override it only when your deployment uses a different endpoint.

## Example [#example]

```typescript
import { GT, type GTAccountConfig } from 'generaltranslation';

const config: GTAccountConfig = { apiKey: process.env.GT_ORG_API_KEY! };
const account = new GT(config);

const projects = await account.listProjects();
```

## Notes [#notes]

- Passing a `projectId` to `GTAccountConfig` is a type error. A `projectId` typed `string | undefined` matches neither configuration; check it before constructing `GT`.
