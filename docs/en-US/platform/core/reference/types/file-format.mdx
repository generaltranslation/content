Import the file-format type and binary helper from `generaltranslation/types`. Use them when building upload and download pipelines around the Core file methods.

## Overview [#overview]

| Export | Description |
| --- | --- |
| [`FileFormat`](#file-format) | Union of supported file-format identifiers. |
| [`isBinaryFileFormat`](#is-binary-file-format) | Checks whether a format uses the binary data path. |

## `FileFormat` [#file-format]

**Type** `string` union

```typescript
type FileFormat =
  | 'GTJSON'
  | 'MDX'
  | 'JSON'
  | 'YAML'
  | 'MD'
  | 'TS'
  | 'JS'
  | 'HTML'
  | 'TXT'
  | 'PO'
  | 'POT'
  | 'TWILIO_CONTENT_JSON'
  | 'LOTTIE'
  | 'SVG'
  | 'DOT_STRINGS'
  | 'DOT_STRINGSDICT'
  | 'ANDROID_STRINGS'
  | 'XCSTRINGS'
  | 'SRT'
  | 'RESX';
```

Pass these identifiers to methods such as [`uploadSourceFiles`](/docs/platform/core/reference/gt-class-methods/files/upload-source-files) and [`translateFiles`](/docs/platform/core/reference/gt-class-methods/translation/translate-files).

## `isBinaryFileFormat` [#is-binary-file-format]

**Type** `(fileFormat: FileFormat) => boolean`

Returns whether the format is binary. `LOTTIE` is the only binary format. Binary formats are already base64-encoded when uploaded and remain base64-encoded when returned by [`queryFilesContent`](/docs/platform/core/reference/gt-class-methods/files/query-files-content).

```typescript
import { writeFile } from 'node:fs/promises';
import {
  isBinaryFileFormat,
  type FileFormat,
} from 'generaltranslation/types';

async function saveDownloadedFile(
  file: { data: string; fileFormat: FileFormat },
  outputPath: string
) {
  if (isBinaryFileFormat(file.fileFormat)) {
    await writeFile(outputPath, Buffer.from(file.data, 'base64'));
  } else {
    await writeFile(outputPath, file.data, 'utf8');
  }
}
```
