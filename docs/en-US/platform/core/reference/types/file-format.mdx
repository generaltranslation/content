Import the file-format type and binary helpers from `generaltranslation/types`. Use them when building upload and download pipelines around the Core file methods.

## Overview [#overview]

| Export | Description |
| --- | --- |
| [`FileFormat`](#file-format) | Union of supported file-format identifiers. |
| [`BINARY_FILE_FORMATS`](#binary-file-formats) | Read-only set of formats carried as base64 binary data. |
| [`isBinaryFileFormat`](#is-binary-file-format) | Checks whether a format uses the binary data path. |

## `FileFormat` [#file-format]

**Type** `string` union

```typescript
type FileFormat =
  | 'GTJSON'
  | 'JSON'
  | 'PO'
  | 'POT'
  | 'YAML'
  | 'MDX'
  | 'MD'
  | 'TS'
  | 'JS'
  | 'HTML'
  | 'TXT'
  | 'TWILIO_CONTENT_JSON'
  | 'LOTTIE'
  | 'SVG'
  | 'XCSTRINGS'
  | 'DOT_STRINGS'
  | 'DOT_STRINGSDICT'
  | 'ANDROID_STRINGS';
```

Pass these identifiers to methods such as [`uploadSourceFiles`](/docs/platform/core/reference/gt-class-methods/translation/upload-source-files) and [`enqueueFiles`](/docs/platform/core/reference/gt-class-methods/translation/enqueue-files).

*Note: `XCSTRINGS` is present in the public contract, but `.xcstrings` upload and translation are not yet supported. The API rejects valid catalogs after validation.*

## `BINARY_FILE_FORMATS` [#binary-file-formats]

**Type** `ReadonlySet<FileFormat>`

The set contains `LOTTIE`. Binary formats are already base64-encoded when uploaded and remain base64-encoded when returned by [`downloadFileBatch`](/docs/platform/core/reference/gt-class-methods/translation/download-file-batch).

```typescript
import { BINARY_FILE_FORMATS } from 'generaltranslation/types';

BINARY_FILE_FORMATS.has('LOTTIE'); // true
BINARY_FILE_FORMATS.has('JSON'); // false
```

## `isBinaryFileFormat` [#is-binary-file-format]

**Type** `(fileFormat: FileFormat) => boolean`

Returns whether the format belongs to `BINARY_FILE_FORMATS`.

```typescript
import { writeFile } from 'node:fs/promises';
import {
  isBinaryFileFormat,
  type FileFormat,
} from 'generaltranslation/types';

async function saveDownloadedFile(
  file: { data: string; fileFormat: FileFormat },
  outputPath: string
) {
  if (isBinaryFileFormat(file.fileFormat)) {
    await writeFile(outputPath, Buffer.from(file.data, 'base64'));
  } else {
    await writeFile(outputPath, file.data, 'utf8');
  }
}
```
