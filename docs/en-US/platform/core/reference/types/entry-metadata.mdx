title: EntryMetadata
description: Add context and processing controls to runtime translation entries. API reference for EntryMetadata and RuntimeFileFormat.

`EntryMetadata` provides optional configuration for a [`TranslateManyEntry`](/docs/platform/core/reference/types/translate-many-entry) object, adding context and controls that customize how General Translation translates the entry.

## Overview [#overview]

`EntryMetadata` is the `metadata` field on an object-form translation entry. Every field is optional.

```typescript
type EntryMetadata = {
  id?: string;
  hash?: string;
  context?: string;
  maxChars?: number;
  dataFormat?: DataFormat;
  fileFormat?: RuntimeFileFormat;
  actionType?: ActionType;
};
```

The related `ActionType` is a string union:

```typescript
type ActionType = 'fast';
```

## Properties [#properties]

| Property | Description | Type | Optional |
| --- | --- | --- | --- |
| [`id`](#id) | Unique identifier for the entry. | `string` | Yes |
| [`hash`](#hash) | Content hash for caching and deduplication. | `string` | Yes |
| [`context`](#context) | Context hint for translators. | `string` | Yes |
| [`maxChars`](#max-chars) | Requested maximum length for generated translations. | `number` | Yes |
| [`dataFormat`](#data-format) | Content format specification. | [`DataFormat`](/docs/platform/core/reference/types/data-format) | Yes |
| [`fileFormat`](#file-format) | Marks a whole Markdown or MDX document for format-aware translation. | [`RuntimeFileFormat`](#runtime-file-format) | Yes |
| [`actionType`](#action-type) | Translation model preference. | `ActionType` | Yes |

### `id` [#id]

**Type** `string` · **Optional**

Unique identifier for the entry.

### `hash` [#hash]

**Type** `string` · **Optional**

Content hash used for caching and deduplication.

### `context` [#context]

**Type** `string` · **Optional**

Context hint for translators, such as `"Button text"` or `"Navigation menu"`.

### `maxChars` [#max-chars]

**Type** `number` · **Optional**

Requests a positive-integer maximum character count from the translation service. Other numeric values do not apply a limit. The Core library does not truncate the returned translation.

### `dataFormat` [#data-format]

**Type** [`DataFormat`](/docs/platform/core/reference/types/data-format) · **Optional**

Content format specification: `'JSX'`, `'ICU'`, `'I18NEXT'`, or `'STRING'`. (See [`DataFormat`](/docs/platform/core/reference/types/data-format)).

### `fileFormat` [#file-format]

**Type** `RuntimeFileFormat` · **Optional**

Set this to `'MD'` or `'MDX'` when `source` contains a whole Markdown or MDX document. Document entries must use the `STRING` data format and cannot set `maxChars`.

The service parses the document into chunks and adds the entry's `context` to each chunk. It returns one structure-preserving string. If any chunk fails or the final document is invalid, the entry fails instead of returning partial output.

`fileFormat` is part of the request identity, so otherwise identical plain text, Markdown, and MDX entries use separate cached translations.

### `actionType` [#action-type]

**Type** `ActionType` · **Optional**

Translation model preference. Currently the only accepted value is `'fast'`, which selects the mini model.

## `RuntimeFileFormat` [#runtime-file-format]

**Type** `'MD' | 'MDX'`

Import this type from `generaltranslation/types`. It contains only the document formats accepted by runtime [`translate`](/docs/platform/core/reference/gt-class-methods/translation/translate) and [`translateMany`](/docs/platform/core/reference/gt-class-methods/translation/translate-many) calls.

## Example [#example]

```typescript
import { GT } from 'generaltranslation';
import type { TranslateManyEntry } from 'generaltranslation/types';

const entry: TranslateManyEntry = {
  source: 'Save',
  metadata: {
    context: 'Button text',
    actionType: 'fast'
  }
};

const gt = new GT({ apiKey: 'your-api-key', projectId: 'your-project-id' });
const result = await gt.translate(entry, 'es');
```

```typescript
// With ICU format
const entry: TranslateManyEntry = {
  source: '{count, plural, other {{count} items}}',
  metadata: {
    dataFormat: 'ICU',
    context: 'Item count'
  }
};
```

```typescript
// Translate a complete Markdown document while preserving its structure.
const document: TranslateManyEntry = {
  source: '# Welcome\n\nRead the [guide](/guide).',
  metadata: {
    fileFormat: 'MD',
  },
};

const [result] = await gt.translateMany([document], {
  sourceLocale: 'en',
  targetLocale: 'es',
});
```
