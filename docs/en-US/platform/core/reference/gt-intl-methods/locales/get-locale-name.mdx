title: getLocaleName

Retrieves the display name of a locale code on a [`GTIntl`](/docs/platform/core/reference/gt-intl/constructor) instance, using the `Intl.DisplayNames` API. General Translation names the locale in the target locale, and names the target locale itself when you omit the code.

## Overview [#overview]

Call `getLocaleName` on a [`GTIntl`](/docs/platform/core/reference/gt-intl/constructor) instance with an optional locale code and options object.

```typescript
const intl = new GTIntl({ defaultLocale: 'en' }, { locale: 'es' });

console.log(intl.getLocaleName('fr-CA')); // "francés canadiense"
console.log(intl.getLocaleName()); // "español"
console.log(intl.getLocaleName('fr-CA', { locale: 'en' })); // "Canadian French"
```

Signature:

```typescript
getLocaleName(locale?: string, options?: { locale?: string }): string
```

*Note: `getLocaleName` runs locally using `Intl.DisplayNames` and does not require an API key. For lookups without a [`GTIntl`](/docs/platform/core/reference/gt-intl/constructor) instance, import the standalone `getLocaleName` function from `@generaltranslation/format`.*

## How it works [#how-it-works]

### Target locale

The target locale is `options.locale`, then the instance `locale`, then `defaultLocale`. It is both the default locale to name and the display language. Aliases in the instance [`customMapping`](/docs/platform/core/reference/types/custom-mapping) are resolved before naming.

The display name falls back to the named locale's own language, then the library default locale (`en`).

### Custom mapping integration

- Custom locale mappings are checked first.
- If a custom name is defined, it takes precedence.
- Otherwise falls back to `Intl.DisplayNames` for standard BCP-47 codes.

### Missing name

Returns an empty string if no name is found for a valid locale.

## Parameters [#parameters]

| Parameter | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| [`locale`](#locale) | Locale code to get the display name for. | `string` | Yes | The target locale |
| [`options`](#options) | Target locale for this call. | `object` | Yes | `{}` |

### `locale` [#locale]

**Type** `string` · **Optional** · **Default** The target locale

BCP-47 locale code or `customMapping` alias to get the display name for.

### `options` [#options]

**Type** `{ locale?: string }` · **Optional** · **Default** `{}`

| Name | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| `locale` | The target locale: the display language, and the locale named when `locale` is omitted. | `string` | Yes | instance `locale` → `defaultLocale` |

## Returns [#returns]

**Type** `string`

The localized display name of the locale.

## Examples [#examples]

```typescript
const intl = new GTIntl({ defaultLocale: 'en' }, { locale: 'fr' });

// Name the user's locale, in that locale
console.log(intl.getLocaleName()); // "français"

// Name other locales, in the user's locale
console.log(intl.getLocaleName('es')); // "espagnol"
console.log(intl.getLocaleName('de')); // "allemand"

// Name a locale in English for one call
console.log(intl.getLocaleName('ja', { locale: 'en' })); // "Japanese"

// Without an instance locale, names are in the default locale
console.log(new GTIntl({ defaultLocale: 'en' }).getLocaleName('fr')); // "French"
```

## Notes [#notes]

- Names are in the target locale. To name locales in the default locale, pass `{ locale: defaultLocale }` or create the instance without a `locale`.
- Custom mapping names take precedence over standard `Intl.DisplayNames`.
