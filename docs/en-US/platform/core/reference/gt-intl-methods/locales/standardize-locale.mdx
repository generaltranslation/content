Standardizes a BCP-47 locale code to ensure correct formatting and casing on a [`GTIntl`](/docs/platform/core/reference/gt-intl/constructor) instance. General Translation converts locale codes to their canonical form, making them consistent across your application and suitable for use with internationalization APIs.

## Overview [#overview]

Call `standardizeLocale` on a [`GTIntl`](/docs/platform/core/reference/gt-intl/constructor) instance with a locale code.

```typescript
const intl = new GTIntl({ defaultLocale: 'en' }, { locale: 'es-ES' });

console.log(intl.standardizeLocale('en-us')); // "en-US"
```

Signature:

```typescript
standardizeLocale(locale: string): string
```

*Note: `standardizeLocale` runs locally and does not require an API key. For normalization without a [`GTIntl`](/docs/platform/core/reference/gt-intl/constructor) instance, see the standalone [`standardizeLocale`](/docs/platform/core/reference/utility-functions/locales/standardize-locale).*

## How it works [#how-it-works]

- **Canonicalization.** Delegates to `Intl.getCanonicalLocales`, which normalizes casing: language subtags become lowercase and region subtags become uppercase.
- **Passthrough on failure.** Returns the input string unchanged if it cannot be standardized.
- **No alias resolution.** Unlike the other locale methods, `standardizeLocale` does not apply the instance [`customMapping`](/docs/platform/core/reference/types/custom-mapping). To standardize an alias's code, resolve it first: `intl.standardizeLocale(intl.resolveCanonicalLocale('cn'))`.

Common casing corrections applied to hyphenated codes:

- `en-us` → `en-US` (region uppercased)
- `EN-gb` → `en-GB` (language lowercased, region uppercased)
- `fr-ca` → `fr-CA` (proper casing throughout)

## Returns [#returns]

**Type** `string`

## Examples [#examples]

```typescript
const intl = new GTIntl({ defaultLocale: 'en' }, { locale: 'es-ES' });

// Casing is normalized for hyphenated codes
console.log(intl.standardizeLocale('en-us')); // "en-US"
console.log(intl.standardizeLocale('EN-gb')); // "en-GB"
console.log(intl.standardizeLocale('fr-ca')); // "fr-CA"

// Already standardized locales pass through unchanged
console.log(intl.standardizeLocale('es-ES')); // "es-ES"
console.log(intl.standardizeLocale('ja-JP')); // "ja-JP"
```

## Notes [#notes]

- Normalizes casing: language codes become lowercase, region codes become uppercase.
- Returns the input string unchanged when the code cannot be standardized.
- Does not resolve `customMapping` aliases; use [`resolveCanonicalLocale`](/docs/platform/core/reference/gt-intl-methods/locales/resolve-canonical-locale) first.
- Preserves locale extensions and variants when present.
