Retrieves comprehensive properties for a locale code on a [`GTIntl`](/docs/platform/core/reference/gt-intl/constructor) instance, including display names, language, script, and region information, and an emoji flag. Without a code, it describes the target locale. General Translation returns a complete [`LocaleProperties`](/docs/platform/core/reference/types/locale-properties) object with the data needed to build rich internationalized user interfaces.

## Overview [#overview]

Call `getLocaleProperties` on a [`GTIntl`](/docs/platform/core/reference/gt-intl/constructor) instance with an optional locale code and options object.

```typescript
const intl = new GTIntl({ defaultLocale: 'en' }, { locale: 'es' });

const props = intl.getLocaleProperties('fr-CA');
console.log(props.name); // "francés canadiense"
console.log(props.nativeName); // "français canadien"
console.log(props.emoji); // "🇨🇦"

console.log(intl.getLocaleProperties('fr-CA', { locale: 'en' }).name); // "Canadian French"
```

Signature:

```typescript
getLocaleProperties(locale?: string, options?: { locale?: string }): LocaleProperties
```

*Note: `getLocaleProperties` runs locally and does not require an API key. Display names are in the target locale. For lookups without a [`GTIntl`](/docs/platform/core/reference/gt-intl/constructor) instance, see the standalone [`getLocaleProperties`](/docs/platform/core/reference/utility-functions/locales/get-locale-properties).*

## How it works [#how-it-works]

- **Maximized and minimized forms.** The method derives both a maximized form (with likely script and region added) and a minimized form of the locale code.
- **Target locale.** The target locale is `options.locale`, then the instance `locale`, then `defaultLocale`. It is the display language of every name, and the locale described when you omit `locale`. Aliases in the instance [`customMapping`](/docs/platform/core/reference/types/custom-mapping) are resolved first.
- **Custom mapping priority.** Properties defined in a [`CustomMapping`](/docs/platform/core/reference/types/custom-mapping) take precedence over the standard `Intl` APIs.

## Parameters [#parameters]

| Parameter | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| [`locale`](#locale) | Locale code to get properties for. | `string` | Yes | The target locale |
| [`options`](#options) | Target locale for this call. | `object` | Yes | `{}` |

### `locale` [#locale]

**Type** `string` · **Optional** · **Default** The target locale

BCP-47 locale code or `customMapping` alias to get properties for (for example, `"de-AT"`).

### `options` [#options]

**Type** `{ locale?: string }` · **Optional** · **Default** `{}`

| Name | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| `locale` | The target locale: the display language, and the locale described when `locale` is omitted. | `string` | Yes | instance `locale` → `defaultLocale` |

## Returns [#returns]

**Type** [`LocaleProperties`](/docs/platform/core/reference/types/locale-properties)

A comprehensive object describing the locale:

- `code`: the full locale code (for example, `"de-AT"`).
- `name`: language name in the display language (for example, `"Austrian German"`).
- `nativeName`: language name in the locale's native language (for example, `"Österreichisches Deutsch"`).
- `languageCode`, `languageName`, `nativeLanguageName`: base language information.
- `nameWithRegionCode`, `nativeNameWithRegionCode`: language name with region code (for example, `"German (AT)"`).
- `regionCode`, `regionName`, `nativeRegionName`: region information.
- `scriptCode`, `scriptName`, `nativeScriptName`: script information.
- `maximizedCode`, `maximizedName`, `nativeMaximizedName`: maximized forms with likely script and region.
- `minimizedCode`, `minimizedName`, `nativeMinimizedName`: minimized forms.
- `emoji`: the flag or representative emoji for the locale's region.

## Examples [#examples]

```typescript
// Basic usage
const intl = new GTIntl({ defaultLocale: 'en' }, { locale: 'fr' });

// Get properties for the user's locale, named in that locale
const props = intl.getLocaleProperties();
console.log(props.name); // "français"
console.log(props.nativeName); // "français"
console.log(props.languageCode); // "fr"
console.log(props.regionCode); // "FR"
console.log(props.emoji); // "🇫🇷"

// Get properties for other locales, named in the user's locale
const germanProps = intl.getLocaleProperties('de-AT');
console.log(germanProps.name); // "allemand autrichien"
console.log(germanProps.nativeName); // "Österreichisches Deutsch"
console.log(germanProps.regionName); // "Autriche"
console.log(germanProps.nativeRegionName); // "Österreich"

// Name them in English for one call
console.log(intl.getLocaleProperties('de-AT', { locale: 'en' }).name); // "Austrian German"
```

## Notes [#notes]

- Display names are in the target locale. To name locales in the default locale, pass `{ locale: defaultLocale }` or create the instance without a `locale`.
- Custom mapping properties take precedence over standard `Intl` APIs.
