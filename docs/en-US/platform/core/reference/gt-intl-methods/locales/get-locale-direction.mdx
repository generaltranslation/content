---

title: getLocaleDirection
description: Return the text direction for a locale. API reference for getLocaleDirection.

---

General Translation returns `'ltr'` for left-to-right languages or `'rtl'` for right-to-left languages.

## Overview [#overview]

Call `getLocaleDirection` on a [`GTIntl`](/docs/platform/core/reference/gt-intl/constructor) instance with an optional locale code and options object. Without a code, it returns the target locale's direction: `options.locale`, then the instance `locale`, then `defaultLocale`.

```typescript
const intl = new GTIntl({ defaultLocale: 'en' }, { locale: 'ar' });

const direction = intl.getLocaleDirection();
console.log(direction); // "rtl"

const englishDirection = intl.getLocaleDirection('en-US');
console.log(englishDirection); // "ltr"
```

Signature:

```typescript
getLocaleDirection(locale?: string, options?: { locale?: string }): 'ltr' | 'rtl'
```

*Note: `getLocaleDirection` runs locally using `Intl.Locale` and does not require an API key. For lookups without a [`GTIntl`](/docs/platform/core/reference/gt-intl/constructor) instance, see the standalone [`getLocaleDirection`](/docs/platform/core/reference/utility-functions/locales/get-locale-direction).*

## How it works [#how-it-works]

- **Direction detection.** Returns `'ltr'` for left-to-right languages (most languages worldwide) and `'rtl'` for right-to-left languages (Arabic, Hebrew, Persian, Urdu, and others).
- **Custom mapping.** Aliases in the instance [`customMapping`](/docs/platform/core/reference/types/custom-mapping) are resolved before the direction is read.

## Parameters [#parameters]

| Parameter | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| [`locale`](#locale) | Locale code to check text direction for. | `string` | Yes | The target locale |
| [`options`](#options) | Target locale for this call. | `object` | Yes | `{}` |

### `locale` [#locale]

**Type** `string` · **Optional** · **Default** The target locale

BCP-47 locale code or `customMapping` alias to check text direction for.

### `options` [#options]

**Type** `{ locale?: string }` · **Optional** · **Default** `{}`

| Name | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| `locale` | The target locale, used when `locale` is omitted. | `string` | Yes | instance `locale` → `defaultLocale` |

## Returns [#returns]

**Type** `'ltr' | 'rtl'`

The text direction for the locale:

- `'ltr'`: left-to-right (most languages).
- `'rtl'`: right-to-left (Arabic, Hebrew, Persian, Urdu, etc.).

## Examples [#examples]

```typescript
const intl = new GTIntl({ defaultLocale: 'en' }, { locale: 'ar' });

// The user's locale
console.log(intl.getLocaleDirection()); // "rtl"

// Check different language directions
console.log(intl.getLocaleDirection('en')); // "ltr"
console.log(intl.getLocaleDirection('ar')); // "rtl"
console.log(intl.getLocaleDirection('he')); // "rtl"
console.log(intl.getLocaleDirection('fa')); // "rtl"
console.log(intl.getLocaleDirection('fr')); // "ltr"
```

## Notes [#notes]

- Returns `'ltr'` for all left-to-right languages (most languages worldwide).
- Returns `'rtl'` for right-to-left languages (Arabic, Hebrew, Persian, etc.).
