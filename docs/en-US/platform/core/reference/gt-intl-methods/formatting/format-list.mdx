General Translation uses the built-in `Intl.ListFormat` API to join items with the correct separators and conjunction ("and") or disjunction ("or") wording for each locale.

## Overview [#overview]

Call `formatList` on a [`GTIntl`](/docs/platform/core/reference/gt-intl/constructor) instance with an array and an optional options object. It returns a flat string with the items joined for the resolved locale.

```typescript
const intl = new GTIntl({ defaultLocale: 'en' }, { locale: 'en' });

const list = intl.formatList(['apple', 'banana', 'orange']);
// "apple, banana, and orange"
```

Signature:

```typescript
formatList(
  array: Array<string | number>,
  options?: { locale?: string; locales?: string | string[] } & Intl.ListFormatOptions
): string
```

*Note: `formatList` returns a flat `string`. To keep the original item types (for mixed-type or JSX arrays), use [`formatListToParts`](/docs/platform/core/reference/gt-intl-methods/formatting/format-list-to-parts) instead. It runs locally using `Intl.ListFormat`, does not require an API key, and formats for `options.locale`, then the instance `locale`, falling back to `defaultLocale` and then `en`. For formatting without a [`GTIntl`](/docs/platform/core/reference/gt-intl/constructor) instance, import the standalone `formatList` function from `@generaltranslation/format`.*

## How it works [#how-it-works]

- **Intl-backed.** Formatting is delegated to [`Intl.ListFormat`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/ListFormat).
- **Locale resolution.** The method formats for `options.locale`, then the instance `locale`, falling back to `defaultLocale` and then the library default (`en`). The `locales` array of the [`LocaleConfig`](/docs/platform/core/reference/types/locale-config) is not used. Pass `locale` to change the target for one call, or `locales` to replace the whole fallback list.
- **List type.** `type: 'conjunction'` produces "and" lists, `'disjunction'` produces "or" lists, and `'unit'` produces unit-style lists.

## Parameters [#parameters]

| Parameter | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| [`array`](#array) | The list of items to format. | `Array<string \| number>` | No | — |
| [`options`](#options) | Formatting configuration, extending `Intl.ListFormatOptions` with `locale` and `locales` overrides. | `object` | Yes | — |

### `array` [#array]

**Type** `Array<string | number>` · **Required**

The list of items to join into a single string.

### `options` [#options]

**Type** `{ locale?: string; locales?: string | string[] } & Intl.ListFormatOptions` · **Optional**

Formatting configuration. The table lists common options exposed by the published Core types and their effective Core defaults. (See the [`Intl.ListFormat` constructor options](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/ListFormat/ListFormat#options) for supplemental standard and runtime-specific details).

| Name | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| `locale` | Target locale for this call. | `string` | Yes | instance `locale` → `defaultLocale` |
| `locales` | Replaces the whole fallback list for this call. | `string \| string[]` | Yes | `[locale, defaultLocale, 'en']` |
| `localeMatcher` | Locale matching algorithm. | `'lookup' \| 'best fit'` | Yes | `'best fit'` |
| `type` | List formatting type. | `'conjunction' \| 'disjunction' \| 'unit'` | Yes | `'conjunction'` |
| `style` | List formatting style. | `'long' \| 'short' \| 'narrow'` | Yes | `'long'` |

## Returns [#returns]

**Type** `string`

The items joined into a single locale-aware list string.

## Examples [#examples]

```typescript
import { GTIntl } from 'generaltranslation';

const intl = new GTIntl({ defaultLocale: 'en' }, { locale: 'en' });

// Conjunction (default) — "and" list
console.log(intl.formatList(['A', 'B', 'C']));
// Output: "A, B, and C"

// Disjunction — "or" list
console.log(intl.formatList(['A', 'B', 'C'], { type: 'disjunction' }));
// Output: "A, B, or C"

// Spanish disjunction
console.log(intl.formatList(['red', 'green', 'blue'], {
  locale: 'es',
  type: 'disjunction',
}));
// Output: "red, green o blue"
```

## Notes [#notes]

- Returns a flat `string`; use [`formatListToParts`](/docs/platform/core/reference/gt-intl-methods/formatting/format-list-to-parts) when you need to preserve non-string item types.
- The method uses browser-native `Intl.ListFormat` under the hood.
