Locadex chat runs an on-demand agent session across the repositories you select. Use it for a specific localization task that does not need a saved automation and trigger.

<Callout type="info">
  Locadex chat appears only for Organizations where the feature is enabled. You also need the Organization-level **Manage Locadex secrets** permission.
</Callout>

## Before you start [#before]

- Connect at least one active GitHub repository to a project in the Organization.
- Confirm that **Organization > Locadex > Chat** appears in the Dashboard.
- Prepare a specific task that names the outcome you want.

## Start a session [#start]

1. Open your Organization in the Dashboard.
2. Go to **Organization > Locadex > Chat**.
3. Select one or more repositories. You can select up to 100 repositories in one session.
4. Enter your task in **What should Locadex do?** The message can contain up to 20,000 characters.
5. Click **Start session**.

The session opens immediately and shows Locadex's progress, tool activity, and response. Its status moves between **Working**, **Ready**, **Failed**, and **Stopped**.

## Continue or stop a session [#continue]

Enter a follow-up message and click **Send** when you want Locadex to refine or continue its work. Press **Enter** to send it, or **Shift+Enter** for a new line.

Click **Stop** while the status is **Working** to cancel the current work. The session status changes to **Stopped**.

## Review earlier sessions [#history]

Open **Organization > Locadex > Chat** to see sessions and their current status. Select a session to reopen its transcript.

Long transcripts provide **Older messages** and **Latest messages** links. Use them to move through the session history without starting a new session.
