Use languages to tell Locadex what your source content is written in and what languages it should translate into.

## Open language settings [#open-language-settings]

On the Dashboard, open **Project > Automations**. Choose **Keep locales in sync**, creating it from the template if it is not configured yet. Click **Run now** to open the locale editor.

## Choose a source locale [#choose-source-locale]

Choose or edit the language your source content is written in. Most English Projects use `English` as the source locale.

## Choose target languages [#choose-target-languages]

Choose the languages Locadex should translate into. You can select target languages from all 120 General Translation supported locales. Read more about locales at [Understanding locale codes](/docs/platform/core/guides/locale-codes) and [General Translation supported locales](/docs/platform/dashboard/reference/supported-locales).

## Save changes [#save-changes]

Click **Run now** in the confirmation dialog. Locadex starts an automation that updates the locale configuration in your repository and opens a pull request.

Review and merge the pull request to apply the language change.

## When to update languages [#update-languages]

Update languages when you need to:

- Add a new target language.
- Remove a target language.
- Change the source locale.
- Sync locale configuration after changing Project requirements.
