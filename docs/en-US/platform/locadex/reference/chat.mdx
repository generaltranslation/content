Locadex chat is an Organization-level interface for assigning an agent a task across one or more connected GitHub repositories. It is separate from project automations and their saved triggers.

## Overview [#overview]

| Area | Description |
| --- | --- |
| [Access](#access) | Feature availability and required Organization permission. |
| [Repositories](#repositories) | Active GitHub connections available to a session. |
| [Messages](#messages) | Initial tasks, follow-ups, and length limits. |
| [Sessions](#sessions) | Status, live updates, cancellation, and history. |

## Access [#access]

The **Chat** page appears under **Organization > Locadex** only when Locadex chat is enabled for that Organization. Members also need `locadex:manage`, shown as **Manage Locadex secrets** in Organization roles. The default **Admin** and **Developer** roles include this permission.

Without the feature, the route is unavailable. Without permission, the Dashboard shows an access-denied page.

## Repositories [#repositories]

The repository picker lists active GitHub connections across the Organization and identifies each connection's project. A session requires at least one repository and accepts up to 100.

When an Organization has 100 or fewer active repositories, they are selected by default. When it has more than 100, select the repositories you want before starting the session.

## Messages [#messages]

The initial task and each follow-up must contain 1–20,000 characters after surrounding whitespace is removed. Empty messages and messages over the limit are rejected.

The transcript shows:

- User messages
- Locadex responses and optional thinking details
- Tool names and their completed, failed, or interrupted status
- Session errors and cancellation events

Tool inputs and outputs are not displayed in the transcript.

## Sessions [#sessions]

| Status | Meaning |
| --- | --- |
| **Working** | Locadex is processing the current request. |
| **Ready** | The session is idle and can accept a follow-up. |
| **Failed** | The current work ended with an error. |
| **Stopped** | A user stopped the session. |

The open session receives live transcript and status updates. Use **Stop** while it is working to request cancellation.

The **Chat** page lists previous sessions with pagination and their current status. A long transcript can be opened at an older page of messages and returned to the latest messages.
