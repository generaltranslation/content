Each project in the Dashboard has its own settings, separate from Organization-wide settings. Use them to rename the project, change its source locale, enable CDN delivery or AI Context, copy the project ID, require approval, assign reviewers, and delete the project.

## General settings [#general-settings]

- Update the project **display name**. This changes how the project appears in the Dashboard.
- Update the project **source locale**. This changes the language your content is authored in, but does not update existing translations.
- Enable the **CDN setting** to serve translations from a global CDN for faster load times.
- Enable **AI Context**, which uses contextual information to improve AI translation quality

## Project ID [#project-id]

The project ID is read-only and can be copied from Settings. 

Use it in SDK, CLI, and CI configuration when a workflow needs to target a specific project.

```bash
GT_PROJECT_ID=...
```

## Review [#review]

Translation approval requires an Enterprise plan. Open **Project > Settings > Review**. On that plan, anyone in the project can open the page. Only members who can update the project (`project:write`) can change it.

**Auto approve translations** approves future translations as they complete. It is on for a new project. Turning it on or off does not change approvals that already exist. The deadline, the branch list, reviewer groups, and **Assign automatically** appear only while it is off.

**Assign automatically** is off until you turn it on. Click **Save** after changing it. When it is on, each new open review goes to the reviewer with the fewest open reviews they can still review on that branch. Members who can update the project are never assigned this way. If no reviewer qualifies, the review stays unassigned. When a finished review opens again, a reviewer who can still review that translation keeps it.

Open reviews are listed on **Project > Reviews**. Members who can update the project choose the **Assignee** there, including **Unassigned**. (See [Assign open reviews](/docs/platform/dashboard/guides/reviewing-translations#assign-reviews)).

## Danger zone [#danger-zone]

Permanently delete a project, all its translations, API keys, and data. This cannot be undone.
