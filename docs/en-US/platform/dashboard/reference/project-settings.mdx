Each project in the Dashboard has its own settings, separate from Organization-wide settings. Use them to rename the project, change its source locale, enable CDN delivery or AI Context, copy the project ID, and delete the project.

## General settings [#general-settings]

- Update the project **display name**. This changes how the project appears in the Dashboard.
- Update the project **source locale**. This changes the language your content is authored in, but does not update existing translations.
- Enable the **CDN setting** to serve translations from a global CDN for faster load times.
- Enable **AI Context**, which uses contextual information to improve AI translation quality

## Project ID [#project-id]

The project ID is read-only and can be copied from Settings. 

Use it in SDK, CLI, and CI configuration when a workflow needs to target a specific project.

```bash
GT_PROJECT_ID=...
```

## Review [#review]

Translation approval requires an Enterprise plan. Open **Project > Settings > Review**. On that plan, anyone in the project can open the page. Only members who can update the project (`project:write`) can change it.

**Auto approve translations** approves future translations as they complete. It is on for a new project. Turning it on or off does not change existing approvals, and tasks that are already open stay until they are finished. The other settings appear only while it is off.

- **Deadline** is how many hours reviewers have after a translation is ready. Leave it empty for no deadline. Use a whole number from 1 to 8760.
- **Branches** lists the branches whose translations need review. Separate names with commas, and use `*` to match several, such as `main, release/*`. Leave it empty to review only the default branch. The pattern can be up to 255 characters.
- **Reviewer groups** assign reviewers to languages, integrations, or file formats. Choose **Add group** to create one. Open a group's actions and choose **Edit** to change it, or **Remove** to delete it. Leave languages or content empty to cover all of them. Until the project has a group, every reviewer can review any translation. After a group exists, reviewers can review only what their groups cover, and members who can update the project can still review anything. A project can have up to 50 groups, and each name can be up to 255 characters.

Open tasks for matching branches appear on **Project > Reviews**. (See [Reviewing and editing translations](/docs/platform/dashboard/guides/reviewing-translations#approve-translations)).

## Danger zone [#danger-zone]

Permanently delete a project, all its translations, API keys, and data. This cannot be undone.
