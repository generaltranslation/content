Ask AI is a Beta, read-only assistant available from authenticated Dashboard pages. It uses the current General Translation documentation and your Dashboard location to answer questions without changing your data or settings.

## Ask a question [#ask-question]

1. Click **Ask AI** in the bottom-right corner of the Dashboard.
2. Choose a suggested question or enter your own.
3. Open cited documentation links to verify details or follow a suggested Dashboard link.

Ask AI can explain General Translation, search the docs, list Projects in the current Organization, and help you find Dashboard pages. It cannot edit settings, create resources, or run workflows.

## Use page context [#page-context]

Suggested questions change with the page you are viewing. Ask AI also uses the current workspace and setup progress to make its answers more relevant.

On desktop, the page remains available beside the assistant while you chat. On mobile, the assistant fills the screen and closes when you follow a suggested Dashboard link.

## Revisit chats [#recent-chats]

Click **Recent chats** in the panel header to open a saved conversation. Use **New chat** when you want to start a separate conversation.

Chats are scoped to your user and current workspace. Switching Organizations starts a different workspace conversation.

## Usage and billing [#usage-billing]

Ask AI is available on every plan and uses Organization credits. Each response is charged at 10% of the underlying model token cost. An Organization without a billing account uses the same free monthly allowance as free translations.

Message and daily usage limits vary by plan. The panel explains whether you need to wait for a limit to reset, add credits, or review billing.

AI responses may be inaccurate. Confirm important instructions against the cited documentation before making changes.
