Record one Dashboard walkthrough and capture published text for the selected locales. The finished recording downloads to your device as a JSON file.

## Before you start [#before-start]

Open the Dashboard in the language you want to record as the source. The source is always included, and you can add up to two target languages.

<Callout type="warn">
  Typed input values are masked, but visible Dashboard content and your interactions may be captured. Avoid opening pages or records that contain information you do not want in the recording file.
</Callout>

## Recording a walkthrough [#recording]

1. Open the user menu in the Dashboard header.
2. Choose **Record demo**.
3. Keep the current source language and select up to two target languages.
4. Choose **Start recording**.
5. Navigate and interact with the Dashboard inside the recording frame.
6. Choose **Stop recording** in the recording controls or user menu.

The Dashboard records navigation, clicks, scrolls, visible content, and the fonts needed for consistent playback. High-volume cursor movement is omitted; playback reconstructs a cursor from recorded click positions.

## Saving the recording [#saving]

After recording stops, the Dashboard reads each target locale's published translations and prepares the localized text overlays. The browser then downloads a file named like `gt-demo-recording-<timestamp>.json`.

The recording stays on your device; the Dashboard does not upload the recording file. Store and share it according to the sensitivity of the captured content.

If a target catalog is unavailable, a translation is missing, or translated structure no longer matches the recorded content, that part of the replay falls back to the source text instead of applying a mismatched translation.
