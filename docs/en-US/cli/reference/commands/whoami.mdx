---

title: gt whoami
description: Show the account associated with the current CLI login. API reference for the gt whoami command.

---

Use `gt whoami` to verify which account the CLI will use for authenticated requests.

## Overview [#overview]

```bash
npx gt whoami
```

## How it works [#how-it-works]

- Loads the current stored login and refreshes it when needed.
- Validates the account with the authorization server.
- Prints the account email, name, or subject identifier, using the first available value in that order.

The command fails when no valid login exists.

## Example [#example]

```bash
npx gt whoami
```

## Other notes [#notes]

- `gt whoami` reports the signed-in account, not the owner of an API key supplied through `GT_API_KEY`.
- Run [`gt login`](/docs/cli/reference/commands/login) to authenticate and [`gt logout`](/docs/cli/reference/commands/logout) to remove the stored login.
- `gt whoami` is available in `gt` 2.22.0 and later.
