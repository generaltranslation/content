title: gt whoami
description: Display the account used by the current General Translation CLI login. API reference for the gt whoami command.

---

Use `whoami` to confirm which user session the CLI will use when no API key is set.

## Overview [#overview]

```bash
npx gt whoami
```

## How it works [#how-it-works]

The command refreshes an expired access token when possible, validates the account with the authorization server, and prints the first available identity value: email address, display name, or subject ID.

It exits with an error when no valid login is stored. Run [`gt login`](/docs/cli/reference/commands/login) and try again.

## Example [#example]

```bash
npx gt whoami
```

## Other notes [#notes]

- `whoami` inspects the stored user login. It does not identify the owner of `GT_API_KEY`.
- `gt whoami` is available in `gt` 2.22.0 and later.
