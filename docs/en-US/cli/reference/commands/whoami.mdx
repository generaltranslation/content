Use this command to check the account selected by [`gt login`](/docs/cli/reference/commands/login). It checks a user session, not an API key's identity.

## Overview [#overview]

```bash
npx gt whoami
```

| Option | Description |
| --- | --- |
| [Global options](#flags) | Output, compatibility checks, and help; no command-specific flags. |

## How it works [#how-it-works]

The command shows your signed-in account and requires network access. It prints your email or, if unavailable, your name or account identifier.

Missing or invalid sessions and failed identity requests fail the command. Use [`gt login`](/docs/cli/reference/commands/login) to sign in again.

## Flags [#flags]

There are no command-specific flags. The [global options](/docs/cli/reference/global-options) apply.

To remove that session, use [`gt logout`](/docs/cli/reference/commands/logout).
