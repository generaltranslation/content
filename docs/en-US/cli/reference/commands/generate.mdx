title: gt generate
description: The gt generate command was removed from the CLI; use gt translate instead. Reference for the removed gt generate command.

---

`gt generate` is not a command in the current `gt` CLI. It wrote source-language template files for projects that handled translation outside the General Translation API. As of `gt` 2.23.1 the command is not registered: `npx gt generate` prints the top-level help and exits with status 0, so a script or agent that probes for it sees a success exit code and no files are written.

## Replacement [#replacement]

Use [`gt translate`](/docs/cli/reference/commands/translate) to create translation files. It scans the same sources the removed command did, translates them through the API, and writes one file per locale to the `files.gt.output` path in `gt.config.json`. It requires a project ID and a [saved login or tooling key](/docs/cli/guides/configuring#credentials).

```bash
npx gt translate
```

To check which content the CLI would translate without calling the API, pass `--dry-run`:

```bash
npx gt translate --dry-run
```

## Other notes [#notes]

- **Running an app before its files exist:** create an empty JSON object (`{}`) at each configured output path, for example `public/_gt/es.json`. The library renders source content for any entry without a translation.
- **Bundling the files:** to ship the generated files with your app instead of loading them from the CDN, follow [Storing translations locally](/docs/react/guides/storing-translations).
