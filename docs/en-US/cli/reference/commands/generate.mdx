Generates local template files for your default and target locales. Use it when you handle translations yourself rather than through the General Translation API.

*Note: Available when the CLI detects `gt-next`, `gt-react`, `gt-react-native`, `gt-tanstack-start`, `gt-node`, `gt-vue`, `gt-flask`, or `gt-fastapi`. It is not registered for projects without one of these libraries. If you use the General Translation API, use [`gt translate`](/docs/cli/reference/commands/translate) instead.*

## Overview [#overview]

Configure the project first, then generate the templates:

```bash
npx gt configure
npx gt generate
```

## How it works [#how-it-works]

1. Reads `gt.config.json` to determine the default and target locales, source paths, dictionary, and `files.gt.output` path.
2. Uses the detected library's parser to scan inline content and the configured dictionary, the same way [`gt translate`](/docs/cli/reference/commands/translate) collects content.
3. Replaces the default-locale template with the current source entries.
4. Merges those entries into each target-locale file. Existing target values are preserved, new entries use the source text, and stale entries are removed.

The command does not call the General Translation API. If `files.gt.output` is not configured, it scans the project but exits without writing a template.

## Flags [#flags]

### Template generation flags

| Parameter | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| `-c, --config <path>` | Path to `gt.config.json`. | `string` | Yes | Detected `gt.config.json` |
| `--default-language, --default-locale <locale>` | Default locale used for the source template. | `string` | Yes | Configured default locale |
| `--new, --locales <locales...>` | Target locales whose template files are merged. | `string[]` | Yes | Configured locales |
| `--src <paths...>` | Glob patterns for source files. | `string[]` | Yes | `src`, `app`, `pages`, and `components` globs |
| `--dictionary <path>` | Path to the dictionary file. | `string` | Yes | — |
| `--tsconfig, --jsconfig <path>` | Path to a TypeScript or JavaScript config file used to resolve source imports. | `string` | Yes | Detected config, or `./tsconfig.json` |
| `--inline` | Include inline content supported by the detected library. | `boolean` | Yes | `true` |
| `--ignore-errors` | Ignore errors found while scanning inline content. | `boolean` | Yes | `false` |

## Example [#example]

```bash
# Generate templates for the configured locales
npx gt generate

# Generate from a custom source locale, ignoring scan errors
npx gt generate --default-locale en-US --ignore-errors
```

## Other notes [#notes]

After generating the template files, translate the target values and serve them with [local translations](/docs/react/guides/storing-translations). Re-run `generate` whenever the source content changes; review the target files because entries removed from the source are removed there too.
