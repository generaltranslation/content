title: gt configure
description: Create a General Translation gt.config.json file. API reference for the gt configure command.

---

Creates or updates `gt.config.json` without the experimental React framework rewrite performed by [`gt init`](/docs/cli/reference/commands/init). It can still generate loaders, install the CLI, prompt for login, and provision development credentials.

The command resolves locale settings and the file types you want to translate. `--locales` replaces the configured locale list and `--file-formats` replaces the formats setup offers; other formats and unrelated settings are kept. For a walkthrough of the resulting file, see [Configuring the CLI](/docs/cli/guides/configuring).

```bash
npx gt configure
```

## How it works [#how-it-works]

1. Reads existing configuration and resolves the default locale, target locales, and file types from flags, `gt.config.json`, or prompts. It offers the recommended defaults only with `--defaults`.
2. Writes `defaultLocale`, `locales`, and a `files` object without replacing unrelated file settings.

For config-only setup, [write the file manually](/docs/cli/guides/configuring#create); for authentication without setup changes, use [`gt login`](/docs/cli/reference/commands/login). The same [credential precedence](/docs/cli/guides/configuring#credentials) and [local-write failure boundaries](/docs/cli/reference/commands/init#notes) apply.

## Flags [#flags]

`configure` accepts the [`gt init` setup, configuration, and credential flags](/docs/cli/reference/commands/init#flags), except the framework setup flags. It supports the same [headless runs](/docs/cli/reference/commands/init#headless). The [global options](/docs/cli/reference/global-options) also apply.

## Example [#example]

```bash
# Write gt.config.json interactively
npx gt configure
```

## Other notes [#notes]

- In a monorepo, run `configure` from the specific app directory. The command stops without changing files at a workspace root with `pnpm-workspace.yaml` or a `workspaces` field, unless it lists only the app itself.
- Automatic configuration is not available for Electron applications.
- The generated `gt.config.json` includes your `defaultLocale`, `locales`, and a `files` object describing the content to translate. See the [configuration reference](/docs/cli/reference/config) for every available option.
