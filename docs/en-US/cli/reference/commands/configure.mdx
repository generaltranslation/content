title: gt configure

Creates or updates `gt.config.json` without the experimental React framework rewrite performed by [`gt init`](/docs/cli/reference/commands/init). It can still generate loaders, install the CLI, prompt for login, and provision development credentials.

The command prompts for missing locale settings and the file types you want to translate. It preserves valid existing locale and file settings. For a walkthrough of the resulting file, see [Configuring the CLI](/docs/cli/guides/configuring).

```bash
npx gt configure
```

## How it works [#how-it-works]

1. Reads existing configuration and prompts for missing default locale, target locales, and file types.
2. Writes `defaultLocale`, `locales`, and a `files` object without replacing unrelated file settings.

`configure` shares the init wizard's configuration and credential flow, including local-loader generation, CLI installation when needed, and optional runtime key provisioning. It is not a config-only or offline command. For side-effect-free configuration, [write the file manually](/docs/cli/guides/configuring#create); for authentication without setup changes, use [`gt login`](/docs/cli/reference/commands/login).

The same [credential precedence](/docs/cli/guides/configuring#credentials) and [local-write failure boundaries](/docs/cli/reference/commands/init#notes) apply.

## Flags [#flags]

`configure` takes no command-specific flags — it is fully interactive and writes to `gt.config.json` (or an existing `src/gt.config.json` for non-Vite setups). The [global options](/docs/cli/reference/global-options), including `--skip-version-check`, apply.

## Example [#example]

```bash
# Configure files and the selected translation workflow interactively
npx gt configure
```

## Other notes [#notes]

- In a monorepo, run `configure` from the specific app directory. The command stops without changing files when the current directory is a workspace root with `pnpm-workspace.yaml` or a `workspaces` field.
- Automatic configuration is not available for Electron applications.
- The generated `gt.config.json` includes your `defaultLocale`, `locales`, and a `files` object describing the content to translate. See the [configuration reference](/docs/cli/reference/config) for every available option.
