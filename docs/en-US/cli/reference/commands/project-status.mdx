---

title: gt project status
description: Check the current status of a translation or project context-generation job. API reference for the gt project status command.

---

Use `gt project status` to inspect a job returned by a translation workflow or [`generateProjectContext`](/docs/platform/core/reference/gt-class-methods/translation/generate-project-context). Project creation completes synchronously and does not return a job ID.

## Overview [#overview]

```bash
npx gt project status <job-id> [options]
```

The command makes one status request and prints the status returned by the API.

## How it works [#how-it-works]

1. Resolves the project ID and [saved login or explicit tooling key](/docs/cli/guides/configuring#credentials).
2. Reads the supplied job with [`queryJobs`](/docs/platform/core/reference/gt-class-methods/jobs/query-jobs).
3. Prints the job's status: `queued`, `processing`, `completed`, `failed`, or `not_found`.

The command exits with status 1 when credentials are missing or the API rejects the request. If the project has no matching job, the command prints `not_found` and exits successfully; a printed `failed` job status also does not make the command exit with an error.

## Arguments and flags [#arguments-flags]

| Parameter | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| `<job-id>` | Translation or context-generation job ID to inspect. | `string` | No | — |
| `-c, --config <path>` | Path to `gt.config.json`. | `string` | Yes | Auto-resolved |
| `--api-key <key>` | Explicit tooling key override. | `string` | Yes | `GT_API_KEY`, otherwise login |
| `--project-id <id>` | project ID override. | `string` | Yes | Config or `GT_PROJECT_ID` |

## Example [#example]

```bash
npx gt project status job_123
```

## Other notes [#notes]

- `gt project status` is available in `gt` 2.20.0 and later.
- The command needs a project ID and authentication with the `project:files:read` permission.
- **Response shapes:** [Query jobs](/docs/platform/openapi/reference/jobs/query-jobs).
