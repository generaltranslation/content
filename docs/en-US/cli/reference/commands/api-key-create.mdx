---

title: gt api-key create
description: Create a project API key with an explicit permission set. API reference for the gt api-key create command.

---

Use `gt api-key create` to provision a key for CI, production, or another non-interactive environment. The command prints the secret once and never writes it to an environment file.

## Overview [#overview]

```bash
npx gt api-key create \
  --name <name> \
  --permission <permissions...> \
  [options]
```

## How it works [#how-it-works]

- Resolves the project ID from `--project-id`, `gt.config.json`, or `GT_PROJECT_ID`.
- Authenticates with `--api-key` or `GT_API_KEY` when provided. Otherwise, it uses the account authenticated by [`gt login`](/docs/cli/reference/commands/login).
- Requests the complete permission set in one operation. The server creates the key with every requested permission or creates nothing.
- Writes only the new secret to standard output. Project details, warnings, and errors go to standard error, so redirecting standard output captures only the key.

## Flags [#flags]

| Parameter | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| `--name <name>` | Non-empty name for the new key. | `string` | No | — |
| `--permission <permissions...>` | One or more permissions to grant. | `string[]` | No | — |
| `-c, --config <path>` | Path to `gt.config.json`. The `.json` suffix may be omitted. | `string` | Yes | Auto-resolved |
| `--api-key <key>` | API key used to authorize key creation. | `string` | Yes | Signed-in account or `GT_API_KEY` |
| `--project-id <id>` | Project that owns the new key. | `string` | Yes | Config or `GT_PROJECT_ID` |

Allowed permissions are:

- `project:write`
- `project:context:read`
- `project:context:write`
- `project:files:read`
- `project:files:write`
- `project:translations:generate`
- `project:translations:enqueue`

## Example [#example]

```bash
# Create a CI key and save only its secret
npx gt api-key create \
  --name CI \
  --permission project:files:read project:files:write project:translations:enqueue \
  > gt-api-key.txt
```

## Other notes [#notes]

- The secret is available only in the command output. Move it to your secret manager, then delete any temporary plaintext file.
- The command does not modify `.env`, `.env.local`, or `gt.config.json`.
- `gt api-key create` is available in `gt` 2.22.0 and later.
