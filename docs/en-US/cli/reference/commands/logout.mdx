Sign out of the issuer selected by `GT_AUTH_URL`, or the default Dashboard issuer. Sessions for other issuers are preserved.

## Overview [#overview]

```bash
npx gt logout
```

| Option | Description |
| --- | --- |
| [Global options](#flags) | Output, compatibility checks, and help; no command-specific flags. |

## How it works [#how-it-works]

The command attempts to revoke the selected issuer's refresh token, then always attempts to delete that local session. It warns if remote revocation cannot be confirmed; local filesystem failures can still fail the command. The credentials file is removed when no issuer entries remain. (See [session storage](/docs/cli/reference/commands/login#storage)).

Logout does not revoke API keys, remove `.env.local`, or clear `GT_API_KEY`. An explicit key can still authenticate hosted commands after logout.

## Flags [#flags]

There are no command-specific flags. The [global options](/docs/cli/reference/global-options) apply; there is no config, project-ID, API-key, or JSON-output flag.

## Example [#example]

```bash
npx gt logout
```

The command reports completion after local deletion succeeds; that does not confirm remote revocation when a warning was shown. To sign in again, use [`gt login`](/docs/cli/reference/commands/login).
