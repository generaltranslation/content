title: gt logout

Use `gt logout` to revoke the current refresh token and delete its locally stored credentials.

## Overview [#overview]

```bash
npx gt logout
```

## How it works [#how-it-works]

1. Reads the login for the default General Translation authorization server.
2. Attempts to revoke its refresh token.
3. Deletes the local credentials even when remote revocation cannot be confirmed.

When remote revocation fails, the command warns you to revoke the session in the Dashboard if needed.

## Example [#example]

```bash
npx gt logout
```

## Other notes [#notes]

- Logging out does not delete API keys or change `GT_API_KEY`.
- Run [`gt login`](/docs/cli/reference/commands/login) to sign in again.
- `gt logout` is available in `gt` 2.22.0 and later.
