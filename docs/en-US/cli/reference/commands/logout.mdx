---

title: gt logout
description: Revoke and remove the current General Translation CLI login. API reference for the gt logout command.

---

Use `logout` when you want the CLI to stop using your stored user session. Project API keys and project configuration are not changed.

## Overview [#overview]

```bash
npx gt logout
```

## How it works [#how-it-works]

1. Loads the login for the current General Translation authorization server.
2. Attempts to revoke its refresh token.
3. Removes that server's credentials from the local credential file.

Local credentials are removed even when remote revocation cannot be confirmed. In that case, the CLI warns you to revoke the session in the Dashboard if necessary.

## Example [#example]

```bash
npx gt logout
```

## Other notes [#notes]

- Logging out does not delete credentials stored for a different authorization server.
- Use [`gt login`](/docs/cli/reference/commands/login) to sign in again.
- `gt logout` is available in `gt` 2.22.0 and later.
