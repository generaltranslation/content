title: gt git setup
description: Configure Git merge drivers for generated translation files. API reference for the gt git setup command.

---

Use `gt git setup` to let Git merge `gt-lock.json` and generated GTJSON translation files with format-aware drivers.

## Overview [#overview]

```bash
npx gt git setup [options]
```

Run the command from a Git worktree containing a `gt.config.json`.

## How it works [#how-it-works]

- Adds merge-driver entries for `gt-lock.json` and configured GTJSON output files to the repository's `.gitattributes`.
- Registers the `gt-lock` and `gtjson` drivers in the worktree's local Git configuration.
- Uses the project-local `node_modules/.bin/gt` executable when available. Otherwise, it configures Git to call `gt` from the shell path.
- Leaves an existing matching `.gitattributes` entry unchanged, so the command is safe to run more than once.
- Optionally sets `omitConfigIds` to `true` and removes `_versionId` and `_branchId` from `gt.config.json`.

## Flags [#flags]

| Parameter | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| `-c, --config <path>` | Path to `gt.config.json`. The `.json` suffix may be omitted. | `string` | Yes | Auto-resolved |
| `--dry-run` | Print the planned attributes and Git configuration without changing files or repository settings. | `boolean` | Yes | `false` |
| `--omit-config-ids` | Persist `omitConfigIds: true` and remove generated config IDs. | `boolean` | Yes | Prompted interactively; `false` otherwise |
| `--driver-command <command>` | Command Git uses to call the CLI merge driver. | `string` | Yes | Project-local `gt`, then `gt` |

## Example [#example]

```bash
# Preview the repository changes
npx gt git setup --dry-run

# Configure the drivers and omit generated config IDs
npx gt git setup --omit-config-ids

# Use the package manager when Git calls the driver
npx gt git setup --driver-command "pnpm exec gt"
```

## Other notes [#notes]

- Commit the updated `.gitattributes` file. Local Git driver configuration is not tracked, so each clone must run the command.
- The `gt-lock` driver requires the version 2 lockfile format. Run [`gt translate`](/docs/cli/reference/commands/translate) or [`gt stage`](/docs/cli/reference/commands/stage) to regenerate an older lockfile; until then, Git falls back to a normal conflict.
- `gt git setup` is available in `gt` 2.14.53 and later.
