title: gt project create
description: Create a project from the command line using your account or an Organization API key. API reference for the gt project create command.

---

Use `gt project create` to provision a project before a project ID or project-scoped API key exists.

## Overview [#overview]

```bash
npx gt project create \
  --org-id <orgId> \
  --name <name> \
  --default-locale <locale> \
  [options]
```

The command accepts a [saved user login or an explicit Organization API key](/docs/cli/guides/configuring#credentials) with `org:projects:create` in the selected Organization. Project keys cannot create projects.

## How it works [#how-it-works]

1. Resolves an explicit key from `--api-key` or `GT_API_KEY`, otherwise uses the saved login.
2. Standardizes the default locale.
3. Creates the project in the Organization selected by `--org-id`.
4. Prints the created project's name and ID.

The command exits with status 1 when a required flag or authentication is missing, an explicit key is not authorized, or the API rejects the request. An invalid or insufficient explicit key does not fall back to login.

## Flags [#flags]

| Parameter | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| `--org-id <orgId>` | Organization that will own the project. | `string` | No | — |
| `--name <name>` | Project name. | `string` | No | — |
| `--default-locale <locale>` | Source locale for the project. | `string` | No | — |
| `--cdn-enabled` | Enables CDN delivery for the project. | `boolean` | Yes | `false` |
| `-c, --config <path>` | Path to `gt.config.json`. | `string` | Yes | Auto-resolved |
| `--api-key <key>` | Organization API key override. | `string` | Yes | `GT_API_KEY`, otherwise login |
| `--project-id <id>` | Shared project ID override; not required for project creation. | `string` | Yes | Config or `GT_PROJECT_ID` |

## Example [#example]

```bash
# Use your saved login after signing in
npx gt project create \
  --org-id "your-organization-id" \
  --name "Storefront" \
  --default-locale en

# Non-interactive alternative: an authorized Organization key
GT_API_KEY="gtx-org-..." npx gt project create \
  --org-id "your-organization-id" \
  --name "Storefront" \
  --default-locale en \
  --cdn-enabled
```

The command prints the project name and its new ID. Store that ID as `GT_PROJECT_ID` for later project-scoped commands.

## Other notes [#notes]

- The signed-in user or Organization key needs the `org:projects:create` permission.
