---

title: Lottie
description: Translate Lottie animations with the General Translation CLI. API reference for the Lottie file format.

---

The CLI translates the text layers in Lottie animations. A Lottie bundle is a binary archive, so the CLI carries it through the pipeline as raw bytes and writes the translated animation back byte-for-byte, preserving every layer, asset, and keyframe outside the translated text.

Lottie support requires `gtx-cli` 2.16.0 or later.

## Configuration [#config]

Add a `lottie` entry under `files` with an `include` array of glob patterns. Use the `[locale]` placeholder so the CLI can find source files and save translations to the right path.

```json title="gt.config.json"
{
  "defaultLocale": "en",
  "locales": ["es", "fr"],
  "files": {
    "lottie": {
      "include": ["animations/[locale]/**/*.lottie"]
    }
  }
}
```

See the [configuration reference](/docs/cli/reference/config#files) for all file keys, including `transform` for renaming translated output.

## Fonts [#fonts]

Translated text is laid out with the fonts you upload through the [`fonts`](/docs/cli/reference/config#fonts) key in `gt.config.json`. Without it, translated layers fall back to a default typeface, which can change how an animation looks.

```json title="gt.config.json"
{
  "fonts": {
    "include": ["animations/fonts/**/*.{ttf,otf}"]
  }
}
```

Lottie is currently the only format that uses uploaded fonts.

## Stage and download [#stage-and-download]

Lottie translations are processed asynchronously, so [`gt translate`](/docs/cli/reference/commands/translate) cannot finish them in a single run and exits with an error when it finds Lottie files. Use the two-step flow instead:

1. Stage the files for translation:

   ```bash
   npx gt stage
   ```

2. Download the finished translations:

   ```bash
   npx gt download
   ```

Animations that are still processing are skipped, so re-run [`gt download`](/docs/cli/reference/commands/download) until every locale has been written.

## After Effects expressions [#expressions]

The CLI rejects Lottie files that contain After Effects expressions, because expressions are executable code. When it finds them, it names every offending file and exits without uploading anything.

To translate an affected animation, re-export it from After Effects with expressions baked into keyframes or removed, then run the command again.
