---

title: Global flags
description: Flags and environment variables that apply to every General Translation CLI command.

---

These flags are registered on the root `gt` command, so they work on every command and in any position on the command line. That includes nested commands such as `gt git setup`.

```bash
npx gt translate --quiet
npx gt git setup --quiet
npx gt --quiet translate
```

## Flags [#flags]

| Parameter | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| `-q, --quiet` | Suppress informational output; only warnings and errors are shown. | `boolean` | Yes | `false` |
| `--skip-version-check` | Skip the monorepo GT package version consistency check. | `boolean` | Yes | `false` |
| `--suppress-id-compatibility-warning` | Suppress the React package ID compatibility warning. | `boolean` | Yes | `false` |

## Quiet mode [#quiet]

`--quiet` (or `-q`) hides the informational chatter and keeps the output you need when something goes wrong. It suppresses:

- The ASCII banner and the command intro and outro markers
- `info`, `step`, and `success` lines, plus `debug` and `trace`
- Spinners and progress bars

Warnings and errors still print, and exit codes and command results are unchanged. This makes it a good fit for CI logs and for scripts that only need to surface failures.

```bash
npx gt translate --quiet
```

Quiet mode mutes output, not interaction. Prompts still run, so pass the flags a command needs when you run it non-interactively.

## Logging environment variables [#logging]

The CLI also reads these environment variables.

| Variable | Description | Values | Default |
| --- | --- | --- | --- |
| `GT_LOG_LEVEL` | Minimum level printed to the console. | `debug`, `info`, `warn`, `error` | `info` |
| `GT_LOG_FORMAT` | Console output format. Use `json` for machine-readable logs. | `default`, `json` | `default` |
| `GT_LOG_FILE` | Write a full log to this file path. | File path | — |

`--quiet` works alongside `GT_LOG_LEVEL` and takes the stricter of the two. It raises the console level to `warn`, and it never lowers a level that is already more restrictive, so `GT_LOG_LEVEL=error` stays at `error`.

```bash
# Quiet wins: debug output is suppressed, warnings and errors still print
GT_LOG_LEVEL=debug npx gt translate --quiet
```

In `GT_LOG_FORMAT=json` mode, `--quiet` drops the `info`, `debug`, and `trace` JSON lines the same way it drops the human-readable chatter. Warning and error records still print with their shape unchanged.

`GT_LOG_FILE` is an explicit debug-capture opt-in and is not affected by `--quiet`, so you can silence the console and still keep a complete log on disk.

```bash
npx gt translate --quiet
GT_LOG_FILE=gt.log npx gt translate --quiet
```
