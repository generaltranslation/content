## Derive values that change the sentence [#derive]

Use [`<Derive>`](/docs/react/reference/components/derive) or [`derive`](/docs/react/reference/functions/derive) when a value changes the words around it. The CLI creates one translation for each possible value, so every language can handle agreement and word order.

Wrap runtime values inside derived content in [`<Var>`](/docs/react/reference/components/var) or [`declareVar`](/docs/react/reference/functions/declare-var). They are inserted at runtime instead of translated.

```tsx
import { T, Derive, derive, declareVar, useGT } from 'gt-react';

const getSubject = (gender) => (gender === 'male' ? 'boy' : 'girl');
const getGreeting = (name) => (name ? `Hello, ${declareVar(name)}` : 'Hello, stranger');

function Example({ gender, name }) {
  const gt = useGT();
  return (
    <>
      <T>The <Derive>{getSubject(gender)}</Derive> is playing.</T>
      <p>{gt(`${derive(getGreeting(name))}! How are you?`)}</p>
    </>
  );
}
```

- Every possible value must be known at build time.
- Each derived value multiplies the number of translations, so keep them few.

## Derived functions can live in other files [#imports]

The CLI follows imports to find a derived function's definition, so you can keep shared helpers in their own module. It resolves relative paths, `tsconfig.json` path aliases, package `exports`, and re-exports such as `export * from './utils'`.

```tsx
// utils/subject.ts
export const getSubject = (gender) => (gender === 'male' ? 'boy' : 'girl');

// Example.tsx
import { getSubject } from '@/utils/subject';

<T>The <Derive>{getSubject(gender)}</Derive> is playing.</T>;
```

- Define derived functions as function declarations or `const` arrow functions.
- Avoid loops, recursion, and circular imports. The CLI cannot resolve them.

## Check derived content with `gt validate` [#validate]

Run [`gt validate`](/docs/cli/reference/commands/validate) after adding or changing a derived value. It resolves every derived value without calling the API, and flags any it cannot resolve. Treat those warnings as failures: an unresolved value is not translated correctly.

```bash
npx gt validate src/components/Example.tsx
```

On success, it reports how many translatable entries it found. Use that count to confirm each derived value produced the outcomes you expect.
