title: getLocaleProperties
description: Return display metadata for a locale without reading framework state. API reference for getLocaleProperties.

`getLocaleProperties` returns names, codes, scripts, regions, and a representative emoji for a BCP 47 locale. It does not read the active locale or require a provider.

*Available from `gt-react`, `gt-next`, and `gt-react-native`. `gt-tanstack-start` does not re-export this function.*

## Overview [#overview]

Call the function with the locale to inspect, an optional locale for display names, and an optional custom mapping.

```ts
import { getLocaleProperties } from 'gt-react-native';

const properties = getLocaleProperties('de-AT', 'en');
console.log(properties.name); // "Austrian German"
console.log(properties.emoji); // "🇦🇹"
```

```ts
getLocaleProperties(
  locale: string,
  defaultLocale?: string,
  customMapping?: CustomMapping
): LocaleProperties
```

## Parameters [#parameters]

| Parameter | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| [`locale`](#locale) | BCP 47 locale to inspect. | `string` | No | — |
| [`defaultLocale`](#defaultlocale) | Locale used for display names. | `string` | Yes | `en` |
| [`customMapping`](#custommapping) | Locale aliases and property overrides. | [`CustomMapping`](/docs/platform/core/reference/types/custom-mapping) | Yes | — |

### `locale`

**Type** `string` · **Required**

The BCP 47 locale code to inspect, such as `fr-CA`.

### `defaultLocale`

**Type** `string` · **Optional** · **Default** `en`

The locale used to localize display names. Native names remain in the inspected locale.

### `customMapping`

**Type** [`CustomMapping`](/docs/platform/core/reference/types/custom-mapping) · **Optional**

Aliases locale codes or overrides returned properties. Custom values take precedence over values resolved through `Intl`.

## Returns [#returns]

**Type** [`LocaleProperties`](/docs/platform/core/reference/types/locale-properties)

The result includes canonical, maximized, and minimized codes; localized and native names; language, script, and region properties; and a representative emoji. See the [`LocaleProperties`](/docs/platform/core/reference/types/locale-properties) reference for every field.

## Examples [#examples]

```ts
import { getLocaleProperties } from 'gt-react';

const properties = getLocaleProperties('es-MX', 'fr');

console.log(properties.name); // "espagnol du Mexique"
console.log(properties.nativeName); // "español de México"
console.log(properties.regionCode); // "MX"
```

```ts
import { getLocaleProperties } from 'gt-next';

const properties = getLocaleProperties('pirate', 'en', {
  pirate: {
    code: 'en-GB',
    name: 'Pirate English',
  },
});

console.log(properties.name); // "Pirate English"
console.log(properties.code); // "pirate"
```
