title: getLocaleProperties
description: Read locale display metadata from initialized framework configuration. API reference for getLocaleProperties.

---

`getLocaleProperties` returns names, codes, scripts, regions, and a representative emoji for a BCP 47 locale. It reads the active framework configuration, including its current locale and custom mapping.

*Available from `gt-react`, `gt-next`, and `gt-react-native`. `gt-tanstack-start` does not re-export this function.*

## Overview [#overview]

Call the function after General Translation is initialized. Pass a locale to inspect it, or omit the argument to inspect the active locale.

```ts
import { getLocaleProperties } from 'gt-react-native';

const properties = getLocaleProperties('de-AT');
console.log(properties.nativeName);
console.log(properties.emoji);
```

```ts
getLocaleProperties(locale?: string): LocaleProperties
```

Calling this function before framework initialization throws an error. For a state-independent utility that accepts a display locale and custom mapping directly, import [`getLocaleProperties`](/docs/platform/core/reference/utility-functions/locales/get-locale-properties) from `generaltranslation`.

## Parameter [#parameter]

| Parameter | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| [`locale`](#locale) | BCP 47 locale to inspect. | `string` | Yes | Active locale |

### `locale`

**Type** `string` · **Optional** · **Default** Active locale

The BCP 47 locale code to inspect, such as `fr-CA`. When omitted, the initialized i18n configuration supplies the active locale. Configured locale aliases and property overrides are applied automatically.

## Returns [#returns]

**Type** [`LocaleProperties`](/docs/platform/core/reference/types/locale-properties)

The result includes canonical, maximized, and minimized codes; localized and native names; language, script, and region properties; and a representative emoji. See the [`LocaleProperties`](/docs/platform/core/reference/types/locale-properties) reference for every field.

## Examples [#examples]

```ts
import { getLocaleProperties } from 'gt-react';

// Call after initializeGT() or initializeGTSPA() has completed.
const properties = getLocaleProperties('es-MX');

console.log(properties.nativeName); // "español de México"
console.log(properties.regionCode); // "MX"
```

```ts
import { getLocaleProperties } from 'gt-next';

// Uses the active request locale when no argument is provided.
const properties = getLocaleProperties();

console.log(properties.code);
console.log(properties.nativeNameWithRegionCode);
```
