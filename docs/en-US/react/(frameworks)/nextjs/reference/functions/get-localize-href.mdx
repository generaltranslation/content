The `getLocalizeHref` function resolves to the same function as [`useLocalizeHref`](/docs/react/nextjs/reference/hooks/use-localize-href), using the request locale. Import it from `gt-next/server`.

## Overview [#overview]

```tsx title="app/[locale]/cart/page.tsx"
import { getLocalizeHref } from 'gt-next/server';
import { Button } from '@/components/Button';

export default async function CartPage() {
  const localizeHref = await getLocalizeHref();
  return <Button href={localizeHref('/checkout')}>Checkout</Button>;
}
```

## Returns [#returns]

**Type** `Promise<(href: string, locale?: string | false) => string>`
