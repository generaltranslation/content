title: getLocalizeHref
description: Add the locale prefix to App Router paths in async server code. API reference for getLocalizeHref.

---

The `getLocalizeHref` function resolves to a function that localizes a path with the same rules as the `<Link>` component from `gt-next/link`, using the current request locale. Import it from `gt-next/server` in async components, Route Handlers, and other server code.

`getLocalizeHref` is server-only and does not work with the Pages Router. In synchronous Server Components and Client Components, use [`useLocalizeHref`](/docs/react/nextjs/reference/hooks/use-localize-href).

## Overview [#overview]

```tsx
import { getLocalizeHref } from 'gt-next/server';

const localizeHref = await getLocalizeHref();
localizeHref('/checkout'); // '/fr/checkout', or '/checkout' for the default locale
```

## How it works [#how-it-works]

- **Same rules as `<Link>`.** Internal paths are prefixed with the target locale, except default-locale paths when `prefixDefaultLocale` is `false`; the middleware still resolves localized path aliases and locale availability. (See [Localized navigation](/docs/react/nextjs/link#how-it-works)).
- **Routing options.** The function reads `prefixDefaultLocale` and `enableSmartRouting` from [`withGTConfig`](/docs/react/nextjs/config#routing).
- **Request locale.** The current locale comes from [`getLocale`](/docs/react/nextjs/reference/functions/get-locale). In Route Handlers, call [`registerLocale`](/docs/react/nextjs/reference/functions/register-locale) first. (See [Registering request locales](/docs/react/nextjs/registering-request-locales)).

## Returns [#returns]

**Type** `Promise<(href: string, locale?: LinkLocale) => string>`

A promise resolving to a function with the same parameters as the function returned by [`useLocalizeHref`](/docs/react/nextjs/reference/hooks/use-localize-href#parameters):

- `href`: the unlocalized path to localize. An href that already contains a locale is prefixed again.
- `locale`: the locale to prefix, `false` to return `href` unchanged, or omitted for the request locale.

## Example [#example]

```tsx title="app/[locale]/cart/page.tsx"
import { getLocalizeHref } from 'gt-next/server';
import { Button } from '@/components/Button';

export default async function CartPage() {
  const localizeHref = await getLocalizeHref();
  return <Button href={localizeHref('/checkout')}>Checkout</Button>;
}
```
