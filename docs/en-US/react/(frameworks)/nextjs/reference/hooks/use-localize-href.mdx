---

title: useLocalizeHref
description: Localize App Router paths for navigation that does not render a link. API reference for useLocalizeHref.

---

The `useLocalizeHref` hook returns a function that localizes a path with the same rules as [`<Link>`](/docs/react/nextjs/link). Use it for navigation that does not render a `<Link>`, such as `router.push()` or a component's `href` prop.

Import it from `gt-next/link` in Client Components, or from `gt-next` in Server and Client Components. In async server code, use [`getLocalizeHref`](/docs/react/nextjs/reference/functions/get-localize-href).

## Overview [#overview]

```tsx title="components/CheckoutButton.tsx"
'use client';

import { useRouter } from 'next/navigation';
import { useLocalizeHref } from 'gt-next/link';

export function CheckoutButton() {
  const router = useRouter();
  const localizeHref = useLocalizeHref();

  return (
    <button onClick={() => router.push(localizeHref('/checkout'))}>
      Checkout
    </button>
  );
}
```

## Returns [#returns]

**Type** `(href: string, locale?: string | false) => string`

A function that localizes `href` for the current locale, or for `locale` when given. Pass `false` to return `href` unchanged.
