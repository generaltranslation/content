title: useLocalizeHref
description: Add the locale prefix to App Router paths for navigation that does not render a link. API reference for useLocalizeHref.

The `useLocalizeHref` hook returns a function that localizes a path with the same rules as the `<Link>` component from `gt-next/link`. Use it for navigation that does not render a `<Link>`, such as `router.push()` or a button component's `href` prop.

*Import it from `gt-next/link` in Client Components, or from `gt-next` in both Server and Client Components. In async server code, use [`getLocalizeHref`](/docs/react/nextjs/reference/functions/get-localize-href) instead.*

## Overview [#overview]

```tsx
import { useLocalizeHref } from 'gt-next';

const localizeHref = useLocalizeHref();
localizeHref('/checkout'); // '/fr/checkout', or '/checkout' for the default locale
```

## How it works [#how-it-works]

- **Same rules as `<Link>`.** Internal paths are prefixed with the target locale. Current default-locale paths stay unprefixed unless `prefixDefaultLocale` is `true`, and an explicit default locale keeps its prefix while `enableSmartRouting` is `true`. The middleware still resolves localized path aliases and locale availability. (See [Localized navigation](/docs/react/nextjs/link#how-it-works)).
- **Routing options.** The function reads `prefixDefaultLocale` and `enableSmartRouting` from [`withGTConfig`](/docs/react/nextjs/config#routing), not from [`createNextMiddleware`](/docs/react/nextjs/reference/functions/create-next-middleware).
- **Current locale.** In Client Components, the hook reads the locale from [`<GTProvider>`](/docs/react/reference/components/gt-provider) and must render inside it. In Server Components, the version exported from `gt-next` reads the request locale, like [`useLocale`](/docs/react/reference/hooks/use-locale).
- **Unchanged hrefs.** External URLs, protocol-relative URLs, and relative paths are returned unchanged.

## Parameters [#parameters]

The hook takes no arguments. The returned function takes these parameters:

| Parameter | Description | Type | Optional | Default |
| --- | --- | --- | --- | --- |
| [`href`](#href) | Unlocalized path to localize. | `string` | No | — |
| [`locale`](#locale) | Locale to prefix, or `false` to leave the href unchanged. | `LinkLocale` | Yes | Current locale |

### `href` [#href]

**Type** `string` · **Required**

The path to localize, such as `/checkout?step=2`. Pass an unlocalized path: an href that already contains a locale is prefixed again, so `/de/checkout` becomes `/de/de/checkout`. URL objects are not accepted; localize the `pathname` field instead.

### `locale` [#locale]

**Type** `LinkLocale` · **Optional** · **Default** Current locale

```ts
type LinkLocale = string | false | undefined;
```

Omit it to use the current locale, pass a locale code to target that locale, or pass `false` to return `href` unchanged. `LinkLocale` is exported from `gt-next/link`.

## Returns [#returns]

**Type** `(href: string, locale?: LinkLocale) => string`

A function that returns the localized href.

## Examples [#examples]

### Navigate with the router [#router]

```tsx title="components/CheckoutButton.tsx"
'use client';

import { useRouter } from 'next/navigation';
import { useLocalizeHref } from 'gt-next/link';

export function CheckoutButton() {
  const router = useRouter();
  const localizeHref = useLocalizeHref();

  return (
    <button onClick={() => router.push(localizeHref('/checkout'))}>
      Checkout
    </button>
  );
}
```

### Pass an href to a component [#server-component]

```tsx title="app/[locale]/cart/page.tsx"
import { useLocalizeHref } from 'gt-next';
import { Button } from '@/components/Button';

export default function CartPage() {
  const localizeHref = useLocalizeHref();
  return <Button href={localizeHref('/checkout')}>Checkout</Button>;
}
```
