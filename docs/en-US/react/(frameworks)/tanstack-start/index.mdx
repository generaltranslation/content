`gt-tanstack-start` brings General Translation to TanStack Start apps. It re-exports the shared `gt-react` components, hooks, and functions, and adds a Vite plugin, a router integration, and isomorphic runtime helpers.

If you are just getting started, follow the [TanStack Start Quickstart](/docs/react/tanstack-start-quickstart) first. The shared [Guides](/docs/react/guides/configuring) and [Reference](/docs/react/reference/config) cover everything that works the same across frameworks; the pages here cover the TanStack Start-only setup.

<Callout type="warn">
  **Warning:** `gt-tanstack-start` is experimental and may have breaking changes. It is not yet recommended for production use.
</Callout>

*Note: The current setup requires `gt-tanstack-start` 11.5.0 or later.*

## What is TanStack Start-specific [#overview]

- **Vite plugin.** Add [`gtTanstackStart`](/docs/react/tanstack-start/config) to your Vite config. It reads `gt.config.json`, loads translations from your `files.gt.output` path or the CDN, finds dictionary files, and can run the experimental compiler. (See [Configuration](/docs/react/tanstack-start/config)).
- **Router integration.** Call [`setupRouterGTIntegration`](/docs/react/tanstack-start/reference/functions/setup-router-gt-integration) in `getRouter()`. It resolves each request's locale, loads translations before render, hydrates them in the browser, and wraps your app in [`<GTProvider>`](/docs/react/reference/components/gt-provider). (See [Setup](/docs/react/tanstack-start/setup)).
- **Locale routing.** Set `localeRouting` to `true` to keep non-default locales in the pathname while leaving the default locale unprefixed. The router integration rewrites URLs, so routes and links stay locale-free. (See [Setup](/docs/react/tanstack-start/setup#locale-routing)).
- **Isomorphic runtime functions.** Read runtime state and translate in loaders, server functions, and components with [`getLocale`](/docs/react/tanstack-start/reference/functions/get-locale), [`getEnableI18n`](/docs/react/tanstack-start/reference/functions/get-enable-i18n), [`getGT`](/docs/react/tanstack-start/reference/functions/get-gt), [`getMessages`](/docs/react/tanstack-start/reference/functions/get-messages), and [`getTranslations`](/docs/react/tanstack-start/reference/functions/get-translations).
