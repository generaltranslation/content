The `getEnableI18n` function returns whether General Translation internationalization is enabled for the current server request or browser. Import it from `gt-tanstack-start`.

## Overview [#overview]

```ts
import { getEnableI18n } from 'gt-tanstack-start';

const enableI18n = getEnableI18n();
```

```ts
getEnableI18n(): boolean
```

## How it works [#how-it-works]

On the server, `getEnableI18n` reads the setting resolved for the current request. In the browser, it reads the setting that [`setupRouterGTIntegration`](/docs/react/tanstack-start/reference/functions/setup-router-gt-integration) hydrates. Translation functions use this setting to select either the active locale or the source locale.

The function is synchronous. Server calls throw outside a TanStack Start request, such as at module scope.

## Returns [#returns]

**Type** `boolean`

`true` when internationalization is enabled for the request; otherwise `false`.

## Example [#example]

```ts
import { createServerFn } from '@tanstack/react-start';
import { getEnableI18n } from 'gt-tanstack-start';

export const loadI18nState = createServerFn({ method: 'GET' }).handler(() => {
  return { enableI18n: getEnableI18n() };
});
```
