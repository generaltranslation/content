The `getLocale` function returns the locale associated with the current server request or browser as a BCP 47 locale code. Import it from `gt-tanstack-start`.

## Overview [#overview]

```ts
import { getLocale } from 'gt-tanstack-start';

const locale = getLocale(); // 'en-US'
```

```ts
getLocale(): string
```

## How it works [#how-it-works]

On the server, `getLocale` returns the locale resolved for the current request. With `localeRouting` enabled, the locale comes from the path prefix, then the locale cookie, the `Accept-Language` header, and `defaultLocale`. Without locale routing, resolution starts with the cookie. The locale is resolved once per request, so every call during the request returns the same value.

In the browser, it returns the locale that [`setupRouterGTIntegration`](/docs/react/tanstack-start/reference/functions/setup-router-gt-integration) hydrates. The function is synchronous. Server calls throw outside a TanStack Start request, such as at module scope.

<Callout type="info">
  **Changed in v11:** use `getLocale()` instead of the deprecated `parseLocale()`, and import runtime helpers from `gt-tanstack-start` instead of `gt-tanstack-start/server`.
</Callout>

## Returns [#returns]

**Type** `string`

The current request locale.

## Example [#example]

```ts
import { createServerFn } from '@tanstack/react-start';
import { getLocale } from 'gt-tanstack-start';

export const loadLocale = createServerFn({ method: 'GET' }).handler(() => {
  return getLocale();
});
```
