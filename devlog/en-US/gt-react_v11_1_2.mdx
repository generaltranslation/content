## Overview [#overview]

`gt-react`, `gt-next`, and `gt-tanstack-start` v11.1.2 fix server-side rendering on runtimes that expose both worker and browser package conditions, including Cloudflare Workers and OpenNext deployments.

These runtimes now resolve the server build instead of the browser build. This prevents server renders from accessing browser-only globals and keeps request-scoped locale state isolated correctly.

No application code changes are required. Upgrade the affected package to v11.1.2 or later.
