## Overview

`gt-vue` brings General Translation's inline translation model to Vue 3. It includes rich-content translation, variables, formatters, branches, plurals, string translation, locale switching, and request-scoped server-side rendering. The CLI extracts translatable content from Vue single-file components, JSX, and module-level translations. Browser SPAs reload after locale changes so module-level translations run again, while server-side rendering uses one localization instance per request. This initial 0.x release remains unstable.
