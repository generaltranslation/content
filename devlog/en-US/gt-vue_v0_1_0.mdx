## Overview

`gt-vue` brings General Translation's inline translation model to Vue 3. It
includes rich-content translation, variables, formatters, branches, plurals,
string translation, locale switching, and request-scoped server-side rendering.
The GT CLI extracts translatable content from Vue single-file components, JSX,
and module-level translations. This initial 0.x release remains unstable.
