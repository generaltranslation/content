## Overview

`generaltranslation` v10 replaces the previous project and file methods on `GT` with canonical API methods and removes their old result shapes. Every remaining project method calls one canonical [API](/docs/platform/core/reference/api-client) operation.

Installed 9.x versions keep working, so you can upgrade when convenient.

## Removed methods

| Removed | Use instead |
| --- | --- |
| `getProjectInfo`, `getProjectData` | [`getProject`](/docs/platform/core/reference/gt-class-methods/projects/get-project) |
| `queryBranchData` | [`listBranches`](/docs/platform/core/reference/gt-class-methods/branches/list-branches) |
| `createTag` | [`setTag`](/docs/platform/core/reference/gt-class-methods/branches/set-tag) |
| `getOrphanedFiles` | [`listBranchFiles`](/docs/platform/core/reference/gt-class-methods/branches/list-branch-files) |
| `processFileMoves` | [`moveFiles`](/docs/platform/core/reference/gt-class-methods/files/move-files) |

| `querySourceFile` | [`getFileStatus`](/docs/platform/core/reference/gt-class-methods/files/get-file-status) |
| `downloadFile` | [`getFileContent`](/docs/platform/core/reference/gt-class-methods/files/get-file-content) |
| `downloadFileBatch` | [`queryFilesContent`](/docs/platform/core/reference/gt-class-methods/files/query-files-content) |

Types that only described these methods are removed from `generaltranslation/types`.

## Changed methods

- [`awaitJobs`](/docs/platform/core/reference/gt-class-methods/jobs/await-jobs) takes an array of job IDs and returns the [`queryJobs`](/docs/platform/core/reference/gt-class-methods/jobs/query-jobs) job shape: read `job.id` instead of `job.jobId`, and `job.error` (a string) instead of `job.error.message`. A missing job is `not_found`; `unknown` now means only that the job was not polled before the timeout. The options accept `onPoll`.
- [`createBranch`](/docs/platform/core/reference/gt-class-methods/branches/create-branch) takes `{ name, isDefault }` instead of `{ branchName, defaultBranch }`.
- [`uploadSourceFiles`](/docs/platform/core/reference/gt-class-methods/files/upload-source-files) and [`uploadTranslations`](/docs/platform/core/reference/gt-class-methods/files/upload-translations) return `{ summary, results }` without `uploadedFiles`, `count`, or `message`. Check each result's `status`.
- [`publishFiles`](/docs/platform/core/reference/gt-class-methods/files/publish-files) results drop `success`; check each result's `status`. Entries no longer take `fileName`.
- `generaltranslation/api` re-exports [`@generaltranslation/api`](/docs/platform/core/reference/api-client) unchanged. `createApiClient` no longer takes `projectId`; pass the project ID to its [`awaitJobs`](/docs/platform/core/reference/api-client#job-polling) instead.

## Upgrading

1. Install the new version: `npm install generaltranslation@10`.
2. Replace each removed method with the method in the table above.
3. Update code that reads [`awaitJobs`](/docs/platform/core/reference/gt-class-methods/jobs/await-jobs), upload, or publish results to the new fields.
4. Run your type checker; it reports every remaining call to a removed method or field.
