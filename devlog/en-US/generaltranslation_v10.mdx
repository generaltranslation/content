## Overview

`generaltranslation` v10 replaces the previous project and file methods on `GT` with canonical API methods and removes their old result shapes. Every remaining project method calls one canonical [API](/docs/platform/core/reference/api-client) operation.

Installed 9.x versions keep working, so you can upgrade when convenient.

| `createTag` | [`setTag`](/docs/platform/core/reference/gt-class-methods/branches/set-tag) |

Types that only described these methods are removed from `generaltranslation/types`, including `CheckFileTranslationsOptions`, `DownloadFileOptions`, `DownloadFileBatchOptions`, `CreateBranchQuery`, `ProcessMovesOptions`, and `TranslationResultReference`. `PublishFilesResult` is replaced by `PublishFilesResponse` from `generaltranslation/api`.

## Changed methods

- [`awaitJobs`](/docs/platform/core/reference/gt-class-methods/jobs/await-jobs) takes an array of job IDs and returns the [`queryJobs`](/docs/platform/core/reference/gt-class-methods/jobs/query-jobs) job shape: read `job.id` instead of `job.jobId`, and `job.error` (a string) instead of `job.error.message`. A missing job is `not_found`; `unknown` now means only that the job was not polled before the timeout. The options accept `onPoll`.
- [`createBranch`](/docs/platform/core/reference/gt-class-methods/branches/create-branch) takes `{ name, isDefault }` instead of `{ branchName, defaultBranch }`.
- [`uploadSourceFiles`](/docs/platform/core/reference/gt-class-methods/files/upload-source-files) and [`uploadTranslations`](/docs/platform/core/reference/gt-class-methods/files/upload-translations) return `{ summary, results }` without `uploadedFiles`, `count`, or `message`. Check each result's `status`.
- [`publishFiles`](/docs/platform/core/reference/gt-class-methods/files/publish-files) results drop `success`; check each result's `status`. Entries no longer take `fileName`.
- `generaltranslation/api` re-exports [`@generaltranslation/api`](/docs/platform/core/reference/api-client) unchanged. `createApiClient` no longer takes `projectId`; pass the project ID to its [`awaitJobs`](/docs/platform/core/reference/api-client#job-polling) instead.

## Removed compatibility options

- **`devApiKey`.** `GT` and `GTRuntime` no longer accept `devApiKey`, expose a `devApiKey` property, or read `GT_DEV_API_KEY`. Pass the key as [`apiKey`](/docs/platform/core/reference/gt-class/constructor#api-key) or set `GT_API_KEY`. Framework packages such as `gt-next` keep their own development key settings.
- **Runtime translation metadata.** [`TranslateOptions`](/docs/platform/core/reference/types/translation-config#translate-options) no longer accepts arbitrary extra keys. Runtime translation sends `modelProvider` as its only metadata.
- **Zero timeout.** A `timeout` of `0` on [`translate`](/docs/platform/core/reference/gt-class-methods/translation/translate#timeout) and [`translateMany`](/docs/platform/core/reference/gt-class-methods/translation/translate-many#timeout) is a zero timeout. Omit `timeout` to use the 60000 ms default.
- **Upload options.** [`uploadTranslations`](/docs/platform/core/reference/gt-class-methods/files/upload-translations) takes only `{ timeout }` and no longer requires a source locale. [`uploadSourceFiles`](/docs/platform/core/reference/gt-class-methods/files/upload-source-files) no longer accepts `modelProvider`; set the provider on [`translateFiles`](/docs/platform/core/reference/gt-class-methods/translation/translate-files).
- **`hashSource` `id`.** `hashSource` no longer accepts `id`. Callers that passed one get a content-based hash, so those entries hash differently.
- **`reverseCustomMapping`.** The unused `GTRuntime.reverseCustomMapping` property is removed.
- **`generaltranslation/internal` duplicates.** Import `createDiagnosticMessage` and `formatDiagnosticErrorDetails` from `generaltranslation/diagnostics`, `API_VERSION` from `generaltranslation/api`, and `derive`, `declareVar`, and `decodeVars` from `generaltranslation`.
- **`ApiError` constructor.** [`ApiError`](/docs/platform/core/reference/api-client#api-error) takes `(message, code)` instead of `(error, code, message)`.
- **Config types.** `GTConfig` drops `devApiKey`, the top-level `files.gt.includeSourceCodeContext`, and `files.gt.parsingFlags.legacyGtReactImportSource`, matching [`gt` 3](/devlog/gt_v3_0_0).

## Upgrading

1. Install the new version: `npm install generaltranslation@10`.
2. Replace each removed method with the method in the table above.
3. Update code that reads [`awaitJobs`](/docs/platform/core/reference/gt-class-methods/jobs/await-jobs), upload, or publish results to the new fields.
4. Replace `devApiKey` with `apiKey`, and remove `sourceLocale` from [`uploadTranslations`](/docs/platform/core/reference/gt-class-methods/files/upload-translations) calls.
5. Run your type checker; it reports every remaining call to a removed method or field.
