## Overview

`gt-remark` v2 removes the default export. The plugin is exported by name only.

## Breaking changes

- **The default export is removed.** Import `escapeHtmlInTextNodes` by name.

```ts
// Before
import escapeHtmlInTextNodes from 'gt-remark';

// After
import { escapeHtmlInTextNodes } from 'gt-remark';
```
