## Overview

`@generaltranslation/compiler` v2 removes support for `gt-react` releases that still exported the `gt-react/client` and `gt-react/browser` subpaths. Compiler-injected imports come from `gt-react` by default (the `autoJsxImportSource` option still overrides it; `gt-next` passes `gt-next`), and [`<T>`](/docs/react/reference/components/t) props are read without a `$` prefix, matching [`gt-react` 12](/devlog/gt-react_v12_0_0).

## Breaking changes

- **`legacyGtReactImportSource` is removed.** The compiler option and the matching `files.gt.parsingFlags.legacyGtReactImportSource` key in `gt.config.json` no longer exist. Injected imports use the root `gt-react` package unless `autoJsxImportSource` overrides it.
- **Old `gt-react` subpaths are not recognized.** Imports from `gt-react/client` and `gt-react/browser` are no longer treated as General Translation imports. Import from `gt-react`.
- **[`<T>`](/docs/react/reference/components/t) prop validation.** The compiler validates `context`, `id`, `maxChars`, and `requiresReview` on [`<T>`](/docs/react/reference/components/t); the `$`-prefixed names are no longer read.

## Upgrading

1. Install `@generaltranslation/compiler@2` together with `gt-react@12` or `gt-next@12`.
2. Remove `legacyGtReactImportSource` from your compiler options and `gt.config.json`.
3. Replace imports from `gt-react/client` or `gt-react/browser` with `gt-react`.
