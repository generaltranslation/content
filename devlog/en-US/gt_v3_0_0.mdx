## Overview

The `gt` CLI v3 removes flag aliases and `gt.config.json` keys that were kept from earlier releases, so each setting has one name. The `gtx-cli` wrapper moves to 3.0.0 with the same changes. It ships alongside [`generaltranslation` 10](/devlog/generaltranslation_v10) and [`gt-react` 12](/devlog/gt-react_v12_0_0).

## Breaking changes

### Flags

| Removed | Use instead |
| --- | --- |
| `--default-language` | `--default-locale` |
| `--new` | `--locales` |
| `--jsconfig` | [`--tsconfig`](/docs/cli/reference/commands/translate#source), which accepts a TS or JS config file |
| `--inline` | Nothing; inline content is always scanned |

Scripts that pass a removed flag fail with an unknown-option error.

### `gt.config.json`

- The top-level `files.gt.includeSourceCodeContext` key is removed. Set [`files.gt.parsingFlags.includeSourceCodeContext`](/docs/cli/reference/formats/gt-jsx-files#parsing) instead.
- The `files.gt.parsingFlags.legacyGtReactImportSource` flag is removed. Injected imports come from `gt-react` by default; the compiler's `autoJsxImportSource` option still overrides it (`gt-next` passes `gt-next`).

### Source scanning

The CLI reads `context`, `id`, `maxChars`, and `requiresReview` on [`<T>`](/docs/react/reference/components/t). The `$`-prefixed [`<T>`](/docs/react/reference/components/t) props are no longer extracted, matching `gt-react` 12.

### Project API keys

A project API key (`gtx-api-`) can no longer list or create projects. [`gt init`](/docs/cli/reference/commands/init) without a configured project ID and [`gt project create`](/docs/cli/reference/commands/project-create) stop before sending a request and explain what to do. To set up credentials with a project key, pass `--project-id` or set `GT_PROJECT_ID`. To list or create projects, sign in or use an Organization API key.

### Package subpaths

The `gt/updates/*` and `gt/jsx/*` subpaths are removed; they pointed at files that no longer exist. `gt/types` now resolves to the CLI's type definitions.

## Upgrading

1. Install the new version: `npm install gt@3`.
2. Replace removed flags in scripts and CI configuration.
3. Move `includeSourceCodeContext` under `parsingFlags`, and remove `legacyGtReactImportSource`.
4. With a project API key, pass `--project-id` to [`gt init`](/docs/cli/reference/commands/init), and use an Organization API key or your login for [`gt project create`](/docs/cli/reference/commands/project-create).
5. Rename `$`-prefixed [`<T>`](/docs/react/reference/components/t) props before your next [`gt translate`](/docs/cli/reference/commands/translate).
