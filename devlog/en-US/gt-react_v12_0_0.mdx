## Overview

`gt-react`, `gt-next`, `@generaltranslation/react-core`, `gt-react-native`, and `gt-tanstack-start` move to version 12 together. The release removes APIs that were deprecated during the v11 line, so each feature has one supported form. It ships alongside [`generaltranslation` 10](/devlog/generaltranslation_v10), [`gt` 3](/devlog/gt_v3_0_0), [`@generaltranslation/compiler` 2](/devlog/compiler_v2_0_0), and [`gt-i18n` 2](/devlog/gt-i18n_v2_0_0).

Installed 11.x versions keep working, so you can upgrade when convenient.

## Breaking changes

### `<T>` props without the `$` prefix

[`<T>`](/docs/react/reference/components/t) and [`<Tx>`](/docs/react/nextjs/reference/components/tx) no longer accept `$context`, `$id`, `$maxChars`, `$requiresReview`, or `$format`. Use `context`, `id`, `maxChars`, and `requiresReview`. Leaving a hash-affecting `$`-prefixed prop unrenamed can change the entry's hash and trigger retranslation. Renaming to the unprefixed prop keeps the same hash inputs; `$id` never affected hashes. The `$`-prefixed options of string functions such as [`msg()`](/docs/react/reference/functions/msg) are unchanged.

```tsx
// Before
<T $id="home.title" $context="page heading">Welcome</T>

// After
<T id="home.title" context="page heading">Welcome</T>
```

### `LocaleSelector` drops `customNames`

Pass locale labels to [`customMapping`](/docs/react/reference/components/locale-selector#custom-mapping) instead.

### `gt-next`

- **Pages Router locale.** Without `nextConfig.i18n`, [`withGTServerSideProps`](/docs/react/nextjs-pages-router-quickstart) no longer detects the locale from request headers and cookies. It uses `defaultLocale` and logs a warning. Configure [Next.js internationalized routing](/docs/react/nextjs/pages-router-middleware).
- **Compiler options.** `experimentalCompilerOptions.compileTimeHash: false` no longer turns the compiler off. Set [`type: 'none'`](/docs/react/nextjs/config#compiler-options) instead.

### `gt-tanstack-start`

The `gt-tanstack-start/server` subpath and `parseLocale()` are removed. Import every runtime helper from `gt-tanstack-start`, and read the request locale with [`getLocale()`](/docs/react/tanstack-start/reference/functions/get-locale).

## Upgrading

1. Install version 12 of your framework package, such as `npm install gt-next@12`, and `gt@3` if you use the CLI.
2. Rename `$`-prefixed [`<T>`](/docs/react/reference/components/t) props and replace `customNames` with `customMapping`.
3. Update imports from `gt-tanstack-start/server`, and replace `parseLocale()` calls with [`getLocale()`](/docs/react/tanstack-start/reference/functions/get-locale).
