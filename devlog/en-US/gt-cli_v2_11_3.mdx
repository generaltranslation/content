## Overview

[`gt upload`](/docs/cli/reference/commands/upload) and [`gt save-local`](/docs/cli/reference/commands/save-local) now apply configured CDN publishing rules after they sync files. This extends the publishing step that was already part of [`gt translate`](/docs/cli/reference/commands/translate).

## How it works

- **Upload:** after a successful upload, the CLI publishes or unpublishes files that match the configured rules.
- **Save local edits:** the CLI runs the publishing step only when it finds and saves local translation changes.
- **Failure handling:** a CDN publishing failure produces a warning without failing the completed upload or local-edit sync.

Use the [`publish`](/docs/cli/reference/config#publish) configuration or the `--publish` flag to opt into CDN publishing:

```bash
# Upload files and apply configured CDN publishing rules
npx gt upload

# Save local edits and publish changed translations
npx gt save-local --publish
```
