## Overview

`gt-sanity` v3.1.1 normalizes the plugin's target locales before configuring Sanity's localization tools. Duplicate entries and the source locale are removed automatically. See [Configure Sanity locales](/docs/integrations/sanity/guides/configuring-sanity#set-locales) for the current setup.

This makes it safe to spread a shared `gt.config.json` whose `locales` array includes `defaultLocale`. It also prevents duplicate language entries from causing repeated internationalized-array updates and a Studio render loop.

No configuration changes are required. Upgrade to v3.1.1 or later.
