The `gt-vue` package is the Vue library from General Translation, and `gt` is its CLI. The library runs as a Vue plugin. It loads each language's translation catalog once, caches it, and rerenders translated content when the locale changes, so switching languages does not reload the page.

You need a Vue 3 app on Vue 3.3 or later. The current Vite toolchain needs Node.js `^20.19.0 || >=22.12.0`. The `gt-vue` package is a 0.x release, and its API and behavior may change between releases.

## 1. Install the packages

The `gt-vue` package renders translations in your app. The [`gt`](/docs/cli/quickstart) CLI extracts your source content and generates translation catalogs.

```bash
npm install gt-vue
npm install --save-dev gt
```

## 2. List your languages

Create `gt.config.json` in the project root:

```json title="gt.config.json"
{
  "defaultLocale": "en",
  "locales": ["es", "fr", "ja"],
  "files": {
    "gt": {
      "output": "src/_gt/[locale].json"
    }
  }
}
```

The `defaultLocale` field is the language of your source content, and `locales` lists the target languages from the [supported locales list](/docs/platform/dashboard/reference/supported-locales). The CLI writes each catalog to the `files.gt.output` path, so keep the `[locale]` placeholder in it.

## 3. Add a translation loader

The loader returns the generated catalog for a requested locale:

```ts title="src/loadTranslations.ts"
import type { LoadTranslations } from 'gt-vue';

const loadTranslations: LoadTranslations = async (locale) => {
  try {
    return (await import(`./_gt/${locale}.json`)).default;
  } catch {
    return {};
  }
};

export default loadTranslations;
```

The plugin does not call the loader for the default locale, because your source content is already its catalog. When a target catalog is missing, the loader returns an empty object and the app renders source content.

## 4. Register the plugin

Create one [`createGT()`](/docs/vue/reference/functions/create-gt) plugin and install it before you mount the app:

```ts title="src/main.ts"
import { createApp } from 'vue';
import { createGT } from 'gt-vue';
import App from './App.vue';
import gtConfig from '../gt.config.json';
import loadTranslations from './loadTranslations';

const gt = createGT({
  defaultLocale: gtConfig.defaultLocale,
  loadTranslations,
});

createApp(App).use(gt).mount('#app');
```

The plugin starts in the locale saved in the `generaltranslation.locale` cookie, or in `defaultLocale` when there is no cookie. The app mounts at once with source content and updates when the requested catalog finishes loading.

## 5. Mark content and add a language switcher

Use the [`<T>`](/docs/vue/reference/components/t) component for rich template content and [`useGT()`](/docs/vue/reference/composables/use-gt) for standalone strings, such as input attributes. Read the current locale with [`useLocale()`](/docs/vue/reference/composables/use-locale) and change it with [`useSetLocale()`](/docs/vue/reference/composables/use-set-locale):

```vue title="src/App.vue"
<script setup lang="ts">
import { T, useGT, useLocale, useSetLocale } from 'gt-vue';
import gtConfig from '../gt.config.json';

const gt = useGT();
const locale = useLocale();
const setLocale = useSetLocale();
const locales = [gtConfig.defaultLocale, ...gtConfig.locales];

async function changeLocale(event: Event) {
  const target = event.target as HTMLSelectElement;
  await setLocale(target.value);
}
</script>

<template>
  <main>
    <label>
      Language
      <select :value="locale" @change="changeLocale">
        <option v-for="code in locales" :key="code" :value="code">
          {{ code }}
        </option>
      </select>
    </label>

    <T>
      <h1>Welcome to my app</h1>
      <p>This content will be translated automatically.</p>
    </T>

    <input :placeholder="gt('Search products')" />
  </main>
</template>
```

Keep content inside [`<T>`](/docs/vue/reference/components/t) static, and use the [variable and branching components](/docs/vue/guides/formatting-variables) for runtime values. Call the function from [`useGT()`](/docs/vue/reference/composables/use-gt) in the template or in a computed value. A string translated once during setup does not update when the locale changes.

The setter from [`useSetLocale()`](/docs/vue/reference/composables/use-set-locale) loads a missing catalog, saves the locale cookie, and rerenders the translated content. If a loader rejects, the current locale stays active.

## 6. Sign in and translate

Sign in with [`gt login`](/docs/cli/reference/commands/login):

```bash
npx gt login
```

Login does not select a project or write environment files. Set your existing project's ID in `.env.local`, or add [`projectId`](/docs/cli/reference/config#project-id) to `gt.config.json`:

```bash title=".env.local"
GT_PROJECT_ID="your-project-id"
```

Keep `.env.local` out of version control. Then generate the catalogs:

```bash
npx gt translate
```

The CLI scans your Vue source, translates the extracted content, and writes one JSON file per target locale to `src/_gt/`. Run it again whenever your source content changes. In CI, use a separately scoped `GT_API_KEY` from your secret store, and never put a tooling key in browser code.

Start the app with `npm run dev` and choose `es`, `fr`, or `ja` from the selector. The heading and the search placeholder change to that language.
