The `gt-react` package is the open-source internationalization library from General Translation for React, and `gt` is its CLI. The steps below are for a single-page app (SPA) that renders in the browser, such as a Vite, webpack, or Create React App project. The code is for Vite. In an SPA, `gt-react` runs entirely in the browser: you initialize it once at startup, and you don't need a provider component.

Other kinds of React app have their own setup. A server-rendered app follows the [React Quickstart](/docs/react/react-quickstart), a React Router framework app follows the [React Router Quickstart](/docs/react/react-router-quickstart), and a Next.js app follows the [Next.js App Router Quickstart](/docs/react/nextjs-quickstart).

You need Node.js 18 or later, and your build tool may need a newer version. For example, Vite 8 requires Node.js `^20.19.0 || >=22.12.0`.

## 1. Install the packages

The `gt-react` package renders translations in your app. The `gt` package is the CLI that prepares them.

```bash
npm i gt-react
npm i -D gt
```

## 2. List your languages

Create `gt.config.json` in the project root:

```json title="gt.config.json"
{
  "defaultLocale": "en",
  "locales": ["es", "fr", "ja"],
  "files": {
    "gt": {
      "output": "src/_gt/[locale].json"
    }
  }
}
```

The `defaultLocale` field is the language your app is written in, and `locales` lists the languages to translate into. The `output` path is where the CLI writes one file per language. It sits inside `src/` because bundlers such as Vite import translation files as modules.

By default, the CLI scans JavaScript and TypeScript files under `src`, `app`, `pages`, and `components`. Set [`src`](/docs/cli/reference/config#src) in `gt.config.json` when your code lives elsewhere.

## 3. Add a translation loader

The [`loadTranslations`](/docs/react/reference/functions/load-translations) function loads a language's file in the browser at runtime. Its import path matches the `output` path from step 2:

```ts title="src/loadTranslations.ts"
export default async function loadTranslations(locale: string) {
  try {
    const translations = await import(`./_gt/${locale}.json`);
    return translations.default;
  } catch (error) {
    console.warn(`No translations found for ${locale}`);
    return {};
  }
}
```

## 4. Initialize before the app renders

Call [`initializeGTSPA`](/docs/react/reference/config#initialize-spa) once at startup, before your app renders. It takes your config and translation loader, determines the user's locale, and loads that locale's translations. Put the call in a small entry module that initializes GT first and then loads the rest of the app:

```ts title="src/index.ts"
import { initializeGTSPA } from 'gt-react';
import gtConfig from '../gt.config.json';
import loadTranslations from './loadTranslations';

await initializeGTSPA({
  ...gtConfig,
  loadTranslations,
});

await import('./main'); // render the app only after GT is ready
```

Your existing `src/main.tsx` stays as it is and renders the app. In Vite, point the module script tag in `index.html` at the new entry by changing its `src` from `/src/main.tsx` to `/src/index.ts`:

```html title="index.html"
<script type="module" src="/src/index.ts"></script>
```

The configuration is fixed for the lifetime of the app. The active locale comes from a saved choice, the browser's settings, or the default locale. The [React SPA Quickstart](/docs/react/react-spa-quickstart) has variants of this entry file for CommonJS and Create React App, which do not support top-level `await`.

## 5. Mark content and add a language menu

Wrap the text you want translated in the [`<T>`](/docs/react/reference/components/t) component. The component translates everything inside it as a unit, including nested elements and formatting. The [`<LocaleSelector>`](/docs/react/reference/components/locale-selector) component renders a dropdown of the languages in `gt.config.json`:

```tsx title="src/components/Welcome.tsx"
import { T, LocaleSelector } from 'gt-react';

export default function Welcome() {
  return (
    <main>
      <LocaleSelector />
      <T>
        <h1>Welcome to my app</h1>
        <p>This content will be translated automatically.</p>
      </T>
    </main>
  );
}
```

Render the component from your application:

```tsx title="src/App.tsx"
import Welcome from './components/Welcome';

export default function App() {
  return <Welcome />;
}
```

When a user picks a language, `gt-react` saves the choice in the `generaltranslation.locale` cookie and reloads the page. Then [`initializeGTSPA`](/docs/react/reference/config#initialize-spa) runs again and loads the new locale's translations before the app renders.

Strings outside React components go through the [`t()`](/docs/react/reference/functions/t-function) function. It works at module level because [`initializeGTSPA`](/docs/react/reference/config#initialize-spa) loads translations before the rest of your app:

```ts title="src/navigation.ts"
import { t } from 'gt-react';

export const navigation = [
  { label: t('Home'), href: '/' },
  { label: t('About'), href: '/about' },
];
```

## 6. Sign in and translate

Sign in with [`gt login`](/docs/cli/reference/commands/login):

```bash
npx gt login
```

Login does not select a project or write environment files. Set your existing project's ID in `.env.local`, or add [`projectId`](/docs/cli/reference/config#project-id) to `gt.config.json`:

```bash title=".env.local"
GT_PROJECT_ID="your-project-id"
```

Keep `.env.local` out of version control. Then translate:

```bash
npx gt translate
```

The CLI scans your app, translates its content, and writes one file per language to the `output` path. Run it again whenever your source content changes. In CI, use a separately scoped `GT_API_KEY` from your secret store, and never put a tooling key in browser code.

Start the dev server with `npm run dev` and pick a language from the dropdown. The page reloads and shows the heading in that language. To see new strings translated while you edit, add the compiler and a project API key with runtime translation permission, as [Developing with SPA translations](/docs/react/guides/developing-spa-translations) describes.
