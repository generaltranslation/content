The `gt-node` package from General Translation translates strings in Node.js servers and services, such as Express or Fastify APIs. It needs Node.js 18 or later, and it binds a locale to each request with `AsyncLocalStorage` from `node:async_hooks`. The steps below build an Express server in `server.js` at the project root. The server answers each request in the language of its `Accept-Language` header and reads translations from local files.

## 1. Install the packages

Install `gt-node` and Express as dependencies and the [`gt` CLI](/docs/cli/quickstart) as a dev dependency:

```bash
npm install gt-node express && npm install gt --save-dev
```

The server code uses ES module `import` syntax, so set `"type": "module"` in `package.json`.

## 2. Initialize with a translation loader

Call [`initializeGT`](/docs/node/reference/functions/initialize-gt) once at startup, before the server handles requests. Pass your locales directly, because `gt-node` does not read `gt.config.json` automatically. The [`loadTranslations`](/docs/react/reference/functions/load-translations) callback reads the translation file for a locale from disk:

```ts title="server.js"
import { readFile } from 'node:fs/promises';
import { initializeGT } from 'gt-node';

initializeGT({
  defaultLocale: 'en',
  locales: ['en', 'es', 'fr'],
  loadTranslations: async (locale) =>
    JSON.parse(await readFile(`./translations/${locale}.json`, 'utf8')),
});
```

With a local loader in place, the server reads translations from disk and makes no CDN request. Without one, a `projectId` makes `gt-node` fetch translations from the General Translation CDN.

## 3. Bind the request locale

Wrap each request in [`withGT`](/docs/node/reference/functions/with-gt) so the translation functions know its locale. The [`getRequestLocale`](/docs/node/reference/functions/get-request-locale) helper picks the best supported locale from the `Accept-Language` header and falls back to the default locale:

```js title="server.js"
import express from 'express';
import { withGT, getRequestLocale } from 'gt-node';

const app = express();
app.use((req, res, next) => withGT(getRequestLocale(req), () => next()));
```

A translation call outside a [`withGT`](/docs/node/reference/functions/with-gt) scope throws in development. In production, it falls back to the default locale.

## 4. Translate a string

Inside a handler, await [`getGT`](/docs/node/reference/functions/get-gt) to get a translation function for the request's locale. Values go into ICU placeholders such as `{name}`:

```js title="server.js"
import { getGT } from 'gt-node';

app.get('/api/greeting', async (req, res) => {
  const gt = await getGT();
  res.json({ message: gt('Hello, {name}!', { name: 'Alice' }) });
});

app.listen(3000, () => console.log('Listening on http://localhost:3000'));
```

Combine the snippets from steps 2 to 4 into one `server.js` file. When a translation is missing, the function returns the source string with your values filled in.

## 5. Generate the translation files

Create `gt.config.json` in the project root:

```json title="gt.config.json"
{
  "defaultLocale": "en",
  "locales": ["es", "fr"],
  "src": ["server.js"],
  "files": { "gt": { "output": "translations/[locale].json" } }
}
```

The `files.gt.output` path matches the path in the loader. The [`src`](/docs/cli/reference/config#src) field tells the CLI to scan `server.js` for strings.

Sign in with [`gt login`](/docs/cli/reference/commands/login), set your project ID, and run [`gt translate`](/docs/cli/reference/commands/translate):

```bash
npx gt login
export GT_PROJECT_ID="your-project-id"
npx gt translate
```

The CLI saves translations locally by default. It writes one file per locale, here `translations/es.json` and `translations/fr.json`. Add the command to your build or deploy step so the files stay current. In CI, provide a separately scoped `GT_API_KEY` and the project ID through your secret settings.

## 6. Run and verify

Start the server:

```bash
node server.js
```

In another terminal, send a request with a Spanish `Accept-Language` header:

```bash
curl -H "Accept-Language: es" http://localhost:3000/api/greeting
```

The response carries the Spanish translation of the greeting. Without the header, or with a language the server does not list, the request gets the source string:

```json title="Output"
{"message":"Hello, Alice!"}
```
