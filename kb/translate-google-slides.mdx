The Google Drive integration leaves the source presentation unchanged and writes each translation into a separate Google Slides file. It translates the text in shapes, table cells, and speaker notes. Images, videos, charts, and other non-text content stay as they are.

## Requirements

- Your [project](/docs/platform/dashboard/get-started) is on a Starter or Enterprise plan.
- Connecting Google Drive requires `project:write` permission. Connecting a personal Google account requires `project:files:write` and `project:translations:enqueue`.
- Adding, removing, or translating files requires `translations:content:write` permission.
- The Google account you connect can open the presentation. A project that uses an Organization shared drive connection reaches the file through that connection instead.

## Translate a presentation

1. In the Dashboard, open **Project > Integrations > Catalog**. Find **Google Drive**, click **Connect**, and choose how the project connects. For a personal account, click **Connect account** and sign in to Google. For an Organization shared drive, select your team's existing connection.
2. Click **Add files** and choose the presentation in the Google Picker. Check that the language in the **Source** column matches the deck.
3. Select the file. Under **Translate into**, choose the languages you want. If the project has no languages yet, click **Select locales** to add them.
4. Click **Translate**. The Dashboard shows progress for every file and language, and translation continues if you leave the page.

Personal connections request the full Google Drive scope, so they also cover a presentation opened from the Google Slides add-on. An older connection that holds only the narrower `drive.file` grant asks you to reconnect before it translates a document opened from an add-on. An Organization shared drive connection requires an Enterprise plan, and an Organization admin sets it up once under **Organization > Connections**.

## Where the translated copies go

The first translation creates one copy for each source file and target language, in the source file's folder. Open a copy from the integration's progress view, or find it next to the source in Google Drive. Each copy takes the source file's name followed by the target language's name, written in the source file's language:

```text
<source file name> [<target language>]
```

An English deck named `Launch deck` becomes `Launch deck [French]` in French. The French copy of a Spanish deck with the same name is `Launch deck [francés]`.

## How the layout is kept

The translated file starts as a copy of the source. The integration applies the source's paragraph styling, text styling, links, and lists to the translated text. Translated text is usually longer or shorter than the original, so the integration then runs a formatting pass that fits the new text to each slide.

While the pass edits the deck, the copy's name ends in `, DRAFT]`, and a successful pass restores the plain name. If the pass leaves the deck recolored, the integration keeps the `DRAFT` marker and fails the job, and retrying the run usually recovers the copy. Do not share a deck whose name still ends in `, DRAFT]`. After the pass, check slides where the text now overflows or wraps differently.

The formatting pass appears as **Layout Processing** in Usage and has its own per-slide charge. The [usage rates](https://generaltranslation.com/pricing/usage) list the current price.

## Update the copies after the deck changes

1. Open **Project > Integrations > Connected** and select the Google Drive integration.
2. Select each source file that changed, and choose the languages to update.
3. Click **Apply changes**.

Every run rebuilds a Google Slides copy from the source, so removed slides disappear and added or reordered slides appear. Translations whose source text has not changed are reused, and an **Apply changes** run restores the previous copy's text-box geometry and run styles. You can edit a translated copy by hand, and later **Apply changes** runs keep your edits where the source text still matches.

**Force retranslation** starts over. It replaces the translated text and any layout changes in the copy, including edits made by hand, and it uses additional translation credits.
