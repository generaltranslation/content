## Por qué es importante la pluralización en React

Es habitual encontrar aplicaciones que muestran mensajes poco naturales como:

```text
Tienes 1 mensaje(s) nuevo(s)
```

Es una señal inequívoca de que el desarrollador no ha pensado detenidamente en la experiencia de usuario.

Las aplicaciones de React suelen necesitar gestionar la pluralización: en contadores de notificaciones, longitudes de listas o resultados de búsqueda.
**Y no es tan difícil hacer bien la pluralización, sobre todo si tu aplicación solo tiene que estar en inglés.**
Pero hay muchas malas prácticas en las que caen los desarrolladores principiantes, especialmente al crear interfaces multilingües.

Esta guía explica cómo gestionar los plurales en inglés de forma limpia, dar formato a los números según la configuración regional y crear un sistema de plurales totalmente multilingüe en React y Next.js.

### El problema de los plurales escritos directamente en el código

Muchos proyectos —incluidos algunos sorprendentemente grandes e importantes— escriben la lógica de los plurales directamente en el código.

```jsx
export default function Example({ n }) {
  return (
    <p>
      Displaying {n} item{n === 1 ? '' : 's'}
    </p>
  )
}
```

Pero la pluralización suele ser más compleja que simplemente añadir una &quot;s&quot; al final de una palabra.
Algunos sustantivos tienen formas plurales irregulares, como &quot;child&quot; y &quot;children&quot;.
A veces, otras partes de la oración también deben cambiar para concordar con el sustantivo, como
&quot;is&quot; y &quot;are&quot;, según la cantidad.

La siguiente tabla muestra algunos casos habituales:

| Escenario                | Ejemplos                                                                                    | Notas                                                                                                        |
| ------------------------ | ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| Número de espectadores   | &quot;1 person is watching&quot; <br /> &quot;2 people are watching&quot;                   | Hay que cambiar tanto el sustantivo irregular (&quot;person&quot; → &quot;people&quot;) como el verbo.       |
| Eliminación de elementos | &quot;Delete this message?&quot; <br /> &quot;Delete these 2 messages?&quot;                | Cambia el demostrativo (&quot;this&quot; frente a &quot;these&quot;) y, además, el sustantivo pasa a plural. |
| Resultados de búsqueda   | &quot;No results&quot; <br /> &quot;1 result found&quot; <br /> &quot;2 results found&quot; | Redacción distinta para cero, uno y varios resultados.                                                       |

Recurrir a expresiones condicionales se vuelve inmanejable enseguida.

Y se convierte en una pesadilla cuando necesitas lanzar tu aplicación en otros idiomas.
Lo que funciona en inglés suele fallar por completo en idiomas como el polaco o el árabe, que tienen reglas totalmente distintas para expresar cantidades.
**Las empresas con las que trabajamos suelen posponer la internacionalización
por lo engorroso que resulta refactorizar UI hardcodeada como esta.**

## Cómo gestionar los plurales en inglés

En inglés, usar los plurales correctos en tu aplicación suele ser sencillo.

Para pluralizar sustantivos de forma simple, escribe una función auxiliar:

```jsx
export function pluralize(
  count: number,
  singular: string,
  plural: string = singular + 's'
) {
  return `${count === 1 ? singular : plural}`;
}
```

Ahora hay una sola función para gestionar toda la lógica de plurales,
y también funciona con plurales irregulares:

```js
pluralize(2, 'user') // "users"
pluralize(2, 'person', 'people') // "people"
pluralize(2, 'child', 'children') // "children"
```

Pero ¿qué pasa si necesitas una lógica más compleja, como por ejemplo:

```text
"Nadie está mirando"
"1 persona está mirando"
"2 personas están mirando"
```

Llegados a este punto, conviene plantearse seriamente usar una biblioteca de internacionalización (&quot;i18n&quot;) que requiera poco mantenimiento.

Aunque los desarrolladores suelen pensar que las bibliotecas de i18n solo sirven para interfaces multilingües,
pueden resultar muy útiles para dar formato a plurales y variables, incluso en aplicaciones de un solo idioma.
Internamente, la mayoría de las bibliotecas de i18n recurren a la API nativa de JavaScript `Intl.PluralRules` para determinar la forma plural correcta en cualquier idioma.

Hay muchas bibliotecas de i18n para React, entre ellas la nuestra, [`gt-react`](/docs/react/overview) (o [`gt-next`](/docs/react/nextjs-quickstart) si usas Next.js).
Mostrar un plural en inglés con gt-react es muy sencillo:

```jsx
import { Plural } from 'gt-react'

function Example({ count }) {
  return (
    <Plural n={count} zero={'No one is watching'} one={`${count} person is watching`}>
      {count} people are watching
    </Plural>
  )
}
```

La UI se renderiza de forma condicional según el valor de `n`.

La mayoría de las bibliotecas usan la API [`Intl.PluralRules`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/PluralRules) de JavaScript para decidir qué forma plural mostrar.
Esto significa que, en inglés, usarías el nombre `"one"` para referirte al singular y `"other"` para referirte al plural.
Nuestro componente [`<Plural>`](/docs/react/reference/components/plural) comprueba primero la categoría plural exacta y después las props genéricas `plural` y `other`. Solo recurre a sus hijos cuando no hay ninguna de esas props disponible.

Usar una biblioteca en este caso es una buena práctica incluso en aplicaciones que solo están en inglés, y facilita mucho la internacionalización futura.

## Pluralización en aplicaciones React multilingües (i18n)

Si tu aplicación solo está dirigida a usuarios de habla inglesa, puede que el enfoque anterior sea todo lo que necesitas, pero la mayoría de las aplicaciones en producción acaban teniendo que admitir varios idiomas. Ahí es donde la cosa se pone interesante.

* En árabe, los sustantivos tienen formas distintas según haya cero, uno, dos o muchos
* En configuraciones regionales como `de-DE`, `es-ES` e `it-IT`, los números grandes usan puntos en lugar de comas, así que 1,000,000 pasa a ser 1.000.000
* En hindi, los dígitos se agrupan de dos en dos, así que 1,000,000 pasaría a ser 10,00,000

**Para una aplicación internacionalizada, conviene usar una biblioteca de i18n específica**, que tendrá su propia documentación sobre cómo gestionar los plurales y el formato de números.

### Formato de números para distintas configuraciones regionales

Puedes usar el objeto `Intl` para [dar formato a números](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/NumberFormat) en cualquier configuración regional.
La forma más sencilla de hacerlo es con el método integrado `toLocaleString()`.

De forma predeterminada, se usará la configuración regional actual del entorno de ejecución:

```javascript
const n = 1000000
n.toLocaleString() // muestra 1,000,000 cuando la configuración regional del entorno de ejecución es "en-US" (inglés estadounidense)
n.toLocaleString('de') // 1.000.000 porque la configuración regional se especificó como "de" (alemán)
```

gt-react también ofrece un componente [`<Num>`](/docs/react/reference/components/num) que, internamente, se basa en `Intl.NumberFormat`.

```jsx
import { Num } from 'gt-react'

// muestra 1,000,000 cuando el idioma es "en-US"
// muestra 1.000.000 cuando el idioma es "de"
// muestra 10,00,000 cuando el idioma es "hi"
export default function Example() {
  return <Num>1000000</Num>
}
```

### Comprender las formas plurales en distintos idiomas

Las seis formas plurales que admite la API `Intl.PluralRules` de JavaScript son: `zero`, `one`, `two`, `few`, `many`, `other`.
Aunque el inglés solo usa `one` («singular») y `other` («plural»),
idiomas como el árabe y el polaco tienen más formas que estas dos.

Por ejemplo, un usuario angloparlante podría esperar:

```text
"No one is watching"
"1 person is watching"
"2 people are watching"
```

En cambio, un usuario de habla árabe podría esperar expresiones distintas para el singular,
el dual (cuando hay exactamente dos elementos) y las formas plurales para cantidades pequeñas y grandes:

```text
"لا أحد يشاهد"
"1 شخص يشاهد"
"2 شخصان يشاهدان"
"3 أشخاص يشاهدون"
"11 شخصاً يشاهدون"
```

Aquí es donde una biblioteca de internacionalización se vuelve imprescindible.
Cada idioma tiene su propia lógica sobre cuándo y cómo mostrar los plurales,
así que es mejor recurrir a una biblioteca especializada para hacerlo bien.

Una buena biblioteca de i18n hará dos cosas:

1. Decidir qué forma plural (`one`, `many`, `other`, etc.) usar según la configuración regional
2. Encontrar la traducción en el idioma correcto que corresponde a esa forma

**Si ya usas una biblioteca de internacionalización,
consulta su documentación para obtener información sobre el formato de plurales.**
Casi todas las bibliotecas tienen documentación específica sobre cómo renderizar plurales.

### Ejemplo completo: plurales en una aplicación React multilingüe

Si todavía no usas ninguna biblioteca de internacionalización, ¡prueba [`gt-react`](/docs/react/react-quickstart)!

El componente [`<Plural>`](/docs/react/reference/components/plural) de gt-react:

* Ofrece una forma sencilla y declarativa de renderizar plurales correctamente en React
* Funciona de forma nativa con el componente de formato [`<Num>`](/docs/react/reference/components/num)
* Funciona de forma nativa con el componente de traducción [`<T>`](/docs/react/reference/components/t), que se integra con nuestro [servicio de traducción](https://generaltranslation.com) para generar formas plurales automáticamente

Si juntamos todas las piezas, obtenemos este componente multilingüe completo:

```jsx
import { T, Plural, Num } from 'gt-react'

// Funciona sin configuración adicional en más de 100 idiomas
function Example({ count }) {
  return (
    <T>
      <Plural
        n={count}
        zero={'No one is watching'}
        one={
          <>
            <Num>{count}</Num> person is watching
          </>
        }
      >
        <Num>{count}</Num> people are watching
      </Plural>
    </T>
  )
}
```

***

Configura la pluralización con el [Inicio rápido de `gt-react`](/docs/react/react-quickstart) para aplicaciones de React o con el [Inicio rápido de `gt-next`](/docs/react/nextjs-quickstart) para aplicaciones de Next.js. Consulta la [referencia de la API de `<Plural>`](/docs/react/reference/components/plural) para ver la API completa del componente.

La pluralización es uno de los retos de i18n más habituales en React: resolverla bien desde el principio te ahorrará mucha refactorización más adelante.
