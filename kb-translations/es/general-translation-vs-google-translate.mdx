Google Translate es una forma rápida de leer una página en otro idioma o de traducir un párrafo puntual. Lo realmente complicado de localizar un producto es traducir cada cadena con el significado que tiene en tu UI, mantener una terminología coherente entre lanzamientos y hacer llegar las traducciones al lugar desde donde tu aplicación las carga. Uses Google Translate como lo uses en una aplicación, siempre te tocará resolver parte de ese trabajo por tu cuenta.

## Tres formas de usar Google Translate en una aplicación

### Permitir que los navegadores de los visitantes traduzcan la página

Chrome ofrece traducir las páginas escritas en idiomas que el usuario no lee. La traducción se realiza en el navegador del visitante una vez cargada la página: el script de traducción de Google sustituye el texto de la página por texto traducido envuelto en elementos `<font>`. Tú no ves ni revisas el resultado, y no hay ninguna URL traducida que los motores de búsqueda puedan rastrear, cuando la recomendación de Google para sitios multilingües es publicar cada idioma en su propia URL ([Managing multilingual sites](https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites)).

Esta reescritura también puede romper las aplicaciones de React. React conserva referencias a los nodos de texto que renderizó, de modo que, cuando la traducción los sustituye, la siguiente actualización puede fallar con `NotFoundError: Failed to execute 'removeChild' on 'Node'`. Los mantenedores de React cerraron la incidencia correspondiente ([react#11538](https://github.com/react/react/issues/11538)) en 2018 y explicaron que React no puede sortear el problema por sí mismo sin enmascarar otros errores o ralentizar los casos habituales. Los elementos marcados con `translate="no"` quedan intactos.

### Añadir el widget Website Translator

El Website Translator integrable de Google solo está disponible para sitios académicos, gubernamentales, sin ánimo de lucro y no comerciales, así que una empresa no puede añadirlo a su producto ([Ayuda de Google Translate](https://support.google.com/translate/answer/2534559?co=GENIE.Platform%3DDesktop)).

### Llamar a la Cloud Translation API

La Cloud Translation API es la opción pensada para desarrolladores. Mantiene intactas las etiquetas HTML. En entradas HTML, su edición Advanced omite el texto marcado con `translate="no"` o `class="notranslate"`, y además ofrece glosarios, traducción adaptativa a partir de pares de oraciones de ejemplo y un Translation LLM basado en Gemini. Cada solicitud incluye el texto, los idiomas y, de forma opcional, un modelo y un glosario:

```json title="translateText request body"
{
  "contents": ["Save"],
  "mimeType": "text/plain",
  "sourceLanguageCode": "en",
  "targetLanguageCode": "de"
}
```

No hay ningún campo que indique dónde aparece una cadena. En alemán, &quot;Save&quot; puede ser *speichern* (guardar un archivo) o *sparen* (ahorrar), y una solicitud de una sola palabra no le da al modelo ningún criterio para elegir. El resto del flujo tendrás que construirlo tú: extraer las cadenas de tus archivos de i18n, proteger marcadores de posición como `{{count}}`, generar las formas plurales de cada idioma, escribir de vuelta los resultados, volver a ejecutar el proceso con cada cambio y ofrecer a los revisores un lugar donde corregir la salida sin que la siguiente ejecución la sobrescriba. Si muestras la salida a los usuarios, Google también exige atribución: una insignia de &quot;powered by Google Translate&quot; junto a los resultados, un aviso legal para la salida sin modificar y marcado de traducción automática en las páginas que indexen los motores de búsqueda ([requisitos de atribución](https://docs.cloud.google.com/translate/attribution)).

## Comparación de las opciones

| Enfoque                  | Contexto de cada cadena                                                            | Variables y plurales                                                                                                                                                                                    | Motores de búsqueda                                                                     | Revisión y actualizaciones                                                                                           |
| ------------------------ | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| Traducción del navegador | El texto visible de la página                                                      | Se traducen como texto sin formato                                                                                                                                                                      | No hay nada nuevo que indexar                                                           | Sin revisión; se vuelve a ejecutar en el navegador de cada visitante                                                 |
| Cloud Translation API    | El texto, más un glosario opcional o pares de ejemplo                              | Tú proteges los marcadores de posición y defines las formas plurales de cada idioma                                                                                                                     | Se indexa una vez que publicas cada idioma en su propia URL                             | Vuelves a ejecutar tu script y te encargas tú mismo de la revisión                                                   |
| General Translation      | El JSX circundante, una nota de contexto, tu glosario y tus prompts personalizados | Los valores de [`<Var>`](/docs/react/reference/components/var) quedan fuera de la traducción, y las ramas de [`<Plural>`](/docs/react/reference/components/plural) se traducen como oraciones completas | Se indexa con el enrutamiento por configuración regional de `gt-next`, como `/es/about` | Cada compilación o pull request de Locadex traduce lo que ha cambiado, y los revisores editan en el panel de control |

Usa Google Translate para leer contenido en otros idiomas o para traducir puntualmente texto interno. Usa la Cloud Translation API si quieres traducción automática en bruto y estás dispuesto a encargarte tú mismo del contexto, los marcadores de posición, los plurales, la revisión y la atribución. Usa General Translation cuando las traducciones formen parte de tu producto, como la UI de una aplicación, la documentación o un sitio de marketing que tenga que leerse bien en todos los idiomas y mantenerse al día con cada lanzamiento.

## En qué se diferencia General Translation

General Translation está diseñado para las partes de la localización que Google Translate deja en tus manos. Dos cosas lo distinguen:

* **Entiende todo el contexto.** Una solicitud a Cloud Translation incluye el texto y los idiomas, además de un glosario opcional. General Translation traduce cada cadena teniendo en cuenta su lugar en tu producto: el componente y los elementos que la rodean, las variables y las formas plurales de la oración, cualquier nota de contexto que añadas, y tu glosario y tus prompts personalizados. Un grupo de contexto aplica los mismos términos y el mismo tono a todos los proyectos a los que lo asignes, para que tu aplicación, tu documentación y tu sitio de marketing usen las mismas palabras.
* **Automatiza todo el flujo de trabajo de localización.** Sus bibliotecas de código abierto internacionalizan tu código en React, Next.js, Vue y Node.js, y en aplicaciones de Next.js y React, [Locadex](/docs/platform/locadex/quickstart), el Agente de IA de General Translation, puede escribir ese código por ti. [`npx gt translate`](/docs/cli/reference/commands/translate) se ejecuta durante tu compilación o en tu CI y escribe las traducciones en tu repositorio o en la CDN de General Translation; los revisores las editan en la página **Traducciones** del panel de control, y cada lanzamiento sale en todos los idiomas.

Así se ve el contexto en código. La insignia de este selector de facturación dice «Ahorra un 20 %»:

```tsx title="BillingToggle.tsx"
import { T, Var } from 'gt-react';

export function BillingToggle({ discount }: { discount: string }) {
  return (
    <T context="Pricing page billing toggle. Save means pay less, not store data.">
      <button>Yearly</button>
      <span className="badge">Save <Var>{discount}</Var></span>
    </T>
  );
}
```

[`<T>`](/docs/react/reference/components/t) envía el bloque como una sola unidad, junto con sus elementos (un botón y una insignia) y la nota de [`context`](/docs/react/reference/components/t#context), para que la traducción pueda resolver el significado de &quot;Save&quot; y colocar el descuento donde corresponda en cada idioma. [`<Var>`](/docs/react/reference/components/var) reserva un marcador de posición para el descuento, y su valor nunca se envía a la API de General Translation. El glosario fija términos como los nombres de productos en todos los idiomas, y los prompts personalizados establecen reglas como el uso del &quot;Sie&quot; formal en alemán. (Consulta [Definir el contexto para las traducciones](/docs/platform/dashboard/guides/defining-context-for-translations) y [Revisar y editar traducciones](/docs/platform/dashboard/guides/reviewing-translations)). Para el contenido que solo existe en tiempo de ejecución, como el texto generado por usuarios o procedente de un CMS, [`tx`](/docs/node/reference/functions/tx) de `gt-node` traduce bajo demanda.

General Translation admite más de 120 configuraciones regionales. Empieza con el [Inicio rápido de Next.js](/docs/react/nextjs-quickstart) o el [Quickstart de React](/docs/react/react-quickstart).

## Conclusiones clave

* Google Translate traduce bien el texto. La traducción del navegador no ofrece revisión ni páginas indexables y puede romper aplicaciones de React; además, el widget Website Translator está limitado a sitios no comerciales.
* Una solicitud a Cloud Translation API no tiene ningún campo para indicar dónde aparece una cadena, y los marcadores de posición, los plurales, la revisión, la entrega y la atribución corren de tu cuenta.
* General Translation entiende el contexto de cada cadena en tu código y automatiza todo el flujo de trabajo en torno a la traducción: desde la internacionalización del código hasta la revisión y la publicación de cada lanzamiento en todos los idiomas.
