Google Translate permet de lire rapidement une page dans une autre langue ou de traduire un paragraphe à l’occasion. Mais le plus difficile, quand on localise un produit, c’est de traduire chaque chaîne de caractères selon le sens qu’elle a dans votre interface, de conserver une terminologie cohérente d’une livraison à l’autre et d’acheminer les traductions là où votre application les charge. Quelle que soit la façon dont vous utilisez Google Translate pour une application, une partie de ce travail reste à votre charge.

## Trois façons d&#39;utiliser Google Translate pour une application

### Laisser le navigateur des visiteurs traduire la page

Chrome propose de traduire les pages rédigées dans des langues que l’utilisateur ne lit pas. La traduction s’effectue dans le navigateur du visiteur, une fois la page chargée : le script de traduction de Google remplace le texte de la page par du texte traduit encapsulé dans des éléments `<font>`. Vous ne voyez pas le résultat et ne pouvez pas le relire, et il n’existe aucune URL traduite que les moteurs de recherche pourraient explorer, alors que Google recommande, pour les sites multilingues, de publier chaque langue sur sa propre URL ([Managing multilingual sites](https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites)).

Cette réécriture peut aussi casser les applications React. React conserve des références aux nœuds de texte qu’il a affichés : une fois ces nœuds remplacés par la traduction, la mise à jour suivante peut échouer avec `NotFoundError: Failed to execute 'removeChild' on 'Node'`. Les mainteneurs de React ont fermé le ticket correspondant ([react#11538](https://github.com/react/react/issues/11538)) en 2018, en expliquant que React ne peut pas contourner lui-même ce problème sans masquer d’autres bugs ni ralentir les cas courants. Les éléments marqués avec `translate="no"` restent intacts.

### Ajouter le widget Website Translator

Le widget Website Translator de Google, à intégrer dans un site, est réservé aux sites universitaires, gouvernementaux, associatifs et non commerciaux : une entreprise ne peut donc pas l&#39;ajouter à son produit ([Aide Google Translate](https://support.google.com/translate/answer/2534559?co=GENIE.Platform%3DDesktop)).

### Appeler la Cloud Translation API

La Cloud Translation API est l&#39;option pensée pour les développeurs. Elle conserve les balises HTML intactes. Pour les entrées HTML, son édition Advanced ignore le texte marqué `translate="no"` ou `class="notranslate"`, et elle propose en plus des glossaires, une traduction adaptative à partir de paires de phrases d&#39;exemple, ainsi qu&#39;un Translation LLM basé sur Gemini. Une requête contient le texte, les langues et, éventuellement, un modèle et un glossaire :

```json title="translateText request body"
{
  "contents": ["Save"],
  "mimeType": "text/plain",
  "sourceLanguageCode": "en",
  "targetLanguageCode": "de"
}
```

Aucun champ n&#39;indique où une chaîne de caractères apparaît. En allemand, « Save » se traduit par *speichern* (enregistrer un fichier) ou *sparen* (économiser), et une requête d&#39;un seul mot ne donne au modèle aucun indice pour trancher. Le reste du pipeline est à votre charge : extraire les chaînes de vos fichiers i18n, protéger les espaces réservés tels que `{{count}}`, générer les formes du pluriel propres à chaque langue, réinjecter les résultats, relancer le processus à chaque modification et offrir aux relecteurs un endroit où corriger la sortie sans que la prochaine exécution ne l&#39;écrase. Si vous affichez la sortie à vos utilisateurs, Google exige en outre une attribution : un badge « powered by Google Translate » à côté des résultats, un avertissement pour toute sortie non modifiée et un balisage signalant la traduction automatique sur les pages indexées par les moteurs de recherche ([exigences d&#39;attribution](https://docs.cloud.google.com/translate/attribution)).

## Comparaison des options

| Approche                     | Contexte pour chaque chaîne de caractères                                                    | Variables et formes plurielles                                                                                                                                                                       | Moteurs de recherche                                                                         | Révision et mises à jour                                                                                                                    |
| ---------------------------- | -------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| Traduction par le navigateur | Le texte visible de la page                                                                  | Traduites comme du texte brut                                                                                                                                                                        | Rien de nouveau à indexer                                                                    | Aucune révision ; traduction relancée dans le navigateur de chaque visiteur                                                                 |
| Cloud Translation API        | Le texte, avec éventuellement un glossaire ou des paires d’exemples                          | Vous protégez vous-même les espaces réservés et construisez les formes du pluriel de chaque langue                                                                                                   | Indexé dès que chaque langue est publiée à sa propre URL                                     | Vous relancez votre script et mettez en place la révision vous-même                                                                         |
| General Translation          | Le JSX environnant, une note de contexte, votre glossaire et vos instructions personnalisées | Les valeurs [`<Var>`](/docs/react/reference/components/var) sont exclues de la traduction, et les branches [`<Plural>`](/docs/react/reference/components/plural) sont traduites en phrases complètes | Indexé grâce au routage selon les paramètres régionaux de `gt-next`, par exemple `/es/about` | Chaque compilation ou pull request Locadex traduit les modifications, et les relecteurs apportent leurs corrections dans le tableau de bord |

Utilisez Google Translate pour lire du contenu en langue étrangère ou traduire ponctuellement du texte interne. Utilisez la Cloud Translation API si vous voulez une traduction automatique brute et êtes prêt à gérer vous-même le contexte, les espaces réservés, les formes plurielles, la révision et l’attribution. Utilisez General Translation lorsque les traductions font partie de votre produit (interface d’application, documentation ou site marketing, par exemple), qui doit être irréprochable dans chaque langue et rester à jour à chaque livraison.

## Ce qui distingue General Translation

General Translation est conçu pour les aspects de la localisation que Google Translate vous laisse gérer. Deux points le distinguent :

* **Il comprend l&#39;ensemble du contexte.** Une requête Cloud Translation transmet le texte et les langues, accompagnés d&#39;un glossaire facultatif. General Translation traduit chaque chaîne de caractères en tenant compte de sa place dans votre produit : le composant et les éléments qui l&#39;entourent, les variables et les formes du pluriel de la phrase, les notes de contexte que vous ajoutez, ainsi que votre glossaire et vos instructions personnalisées. Un groupe de contexte applique la même terminologie et le même ton à chaque projet auquel vous l&#39;assignez : votre application, votre documentation et votre site marketing emploient ainsi les mêmes mots.
* **Il automatise l&#39;ensemble du workflow de localisation.** Des bibliothèques open source internationalisent votre code en React, Next.js, Vue et Node.js, et pour les applications Next.js et React, [Locadex](/docs/platform/locadex/quickstart), l&#39;agent IA de General Translation, peut écrire ce code à votre place. [`npx gt translate`](/docs/cli/reference/commands/translate) s&#39;exécute pendant votre compilation ou dans votre CI et écrit les traductions dans votre dépôt ou sur le CDN de General Translation ; les relecteurs les modifient depuis la page **Traductions** du tableau de bord, et chaque livraison sort dans toutes les langues.

Voici à quoi ressemble ce contexte dans le code. Le badge de ce sélecteur de facturation affiche « Save 20% » :

```tsx title="BillingToggle.tsx"
import { T, Var } from 'gt-react';

export function BillingToggle({ discount }: { discount: string }) {
  return (
    <T context="Pricing page billing toggle. Save means pay less, not store data.">
      <button>Yearly</button>
      <span className="badge">Save <Var>{discount}</Var></span>
    </T>
  );
}
```

[`<T>`](/docs/react/reference/components/t) envoie le bloc d&#39;un seul tenant, avec ses éléments (un bouton et un badge) et la note [`context`](/docs/react/reference/components/t#context), afin que la traduction puisse lever l&#39;ambiguïté sur &quot;Save&quot; et positionner la remise là où chaque langue l&#39;attend. [`<Var>`](/docs/react/reference/components/var) contient un espace réservé pour la remise, et sa valeur n&#39;est jamais envoyée à l&#39;API de General Translation. Le glossaire fige certains termes, comme les noms de produits, dans chaque langue, et les instructions personnalisées définissent des règles telles que le vouvoiement (&quot;Sie&quot;) en allemand. (Voir [Définir le contexte des traductions](/docs/platform/dashboard/guides/defining-context-for-translations) et [Relire et modifier les traductions](/docs/platform/dashboard/guides/reviewing-translations).) Pour le contenu qui n&#39;existe qu&#39;à l&#39;exécution, comme le texte généré par les utilisateurs ou issu d&#39;un CMS, [`tx`](/docs/node/reference/functions/tx) de `gt-node` traduit à la demande.

General Translation prend en charge plus de 120 paramètres régionaux. Commencez par le [Démarrage rapide avec Next.js](/docs/react/nextjs-quickstart) ou le [Démarrage rapide avec React](/docs/react/react-quickstart).

## Points clés

* Google Translate traduit bien le texte. La traduction par le navigateur n&#39;offre ni relecture ni pages indexables, et peut casser les applications React ; quant au widget Website Translator, il est réservé aux sites non commerciaux.
* Une requête à Cloud Translation API ne comporte aucun champ précisant où apparaît une chaîne de caractères, et c&#39;est à vous de développer la gestion des espaces réservés, des formes plurielles, de la relecture, de la livraison et de l&#39;attribution.
* General Translation comprend le contexte de chaque chaîne de caractères dans votre code et automatise tout le workflow autour de la traduction, de l&#39;internationalisation du code à la relecture, jusqu&#39;à la livraison de chaque version dans toutes les langues.
