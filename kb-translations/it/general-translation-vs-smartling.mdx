Smartling propone una localizzazione end-to-end: un sistema di gestione delle traduzioni (TMS) con uno strumento CAT (traduzione assistita dal computer) e una memoria di traduzione, la traduzione con IA tramite il suo AI Hub, la traduzione umana fornita da Smartling Language Services e una Global Delivery Network (GDN) che traduce i siti web fungendo da proxy. Per il software, il lato codice passa attraverso i file: i file di risorse del tuo repository diventano file in Smartling, da cui vengono estratte e tradotte le stringhe, e le traduzioni rientrano tramite il GitHub Connector, un Repository Connector self-hosted o la CLI. General Translation, invece, parte dal codice.

## I punti di forza di Smartling

* **Traduzione AI e umana da un unico fornitore.** La [pagina dei servizi di traduzione](https://www.smartling.com/translation-services) di Smartling elenca la traduzione automatica e AI con consegna immediata, AI Human Translation (traduzione umana assistita dall&#39;AI) in 1 giorno e Creative Translation (traduzione specialistica per progetti complessi) in 2 giorni, affidate a un team di servizi linguistici con oltre 4.000 linguisti.
* **AI Hub.** [LLM e motori di traduzione automatica](https://help.smartling.com/hc/en-us/articles/10318350761883-Smartling-s-AI-Hub) come DeepL, Google e Microsoft, con il tuo glossario e la tua memoria di traduzione inseriti nei prompt.
* **Siti web senza modifiche al codice.** Il GDN distribuisce le pagine tradotte fungendo da [proxy di traduzione](https://help.smartling.com/hc/en-us/articles/18558261190683-Introduction-to-the-GDN).
* **Contesto visivo.** [HTML acquisito tramite un&#39;estensione di Chrome o una libreria JavaScript](https://help.smartling.com/hc/en-us/articles/360057484273--Overview-of-Visual-Context), screenshot associati alle stringhe tramite OCR, PDF e video.
* **Strumenti per la qualità.** Uno strumento CAT, controlli di qualità e un [LQA Agent](https://help.smartling.com/hc/en-us/articles/49428460628507-LQA-Agent-AI-Powered-Quality-Assurance) che valuta i job in base al framework MQM.
* **Conformità e connettori.** [PCI Level 1, SOC 2, HIPAA, HITRUST, ISO 27001 e ISO 42001](https://www.smartling.com/security), oltre a più di 50 connettori per CMS e strumenti di marketing come AEM, Contentful e Salesforce.

## Cosa Smartling lascia ancora ai tuoi ingegneri

Il flusso di lavoro basato su repository di Smartling fa passare i file di risorse attraverso un&#39;attività di traduzione:

1. Configura una libreria i18n ed estrai o scrivi i file di risorse che carica. [Gli SDK di Smartling](https://help.smartling.com/hc/en-us/articles/1260806475390-Smartling-SDKs-Overview) si collegano alla sua API.
2. Collega il repository. Il GitHub Connector in hosting monitora le pull request o i commit, il [Repository Connector](https://help.smartling.com/hc/en-us/articles/360008032174-Options-for-Automation-with-Source-Repositories) self-hosted supporta GitHub Enterprise, GitLab, Bitbucket e SVN, oppure puoi caricare i file con `smartling-cli files push`.
3. Attendi il completamento dell&#39;attività di traduzione. Nella [modalità pull request](https://help.smartling.com/hc/en-us/articles/14901568064411-GitHub-Configuration-Modes-Pull-Request-Single-Branch-On-Demand) del GitHub Connector, la documentazione di Smartling indica che una pull request non dovrebbe essere sottoposta a merge né eliminata finché le relative traduzioni non sono state consegnate: di conseguenza, una pull request di funzionalità resta bloccata in attesa della traduzione.
4. Esegui il merge della pull request di consegna (il [Repository Connector, invece, esegue il commit direttamente sul branch](https://help.smartling.com/hc/en-us/articles/44557348474139-Repository-Connector-Architecture-Overview)), integra ogni nuova lingua nell&#39;app e controlla ogni schermata.

Inoltre, le stringhe dell&#39;app sono inizialmente prive di contesto visivo: il GitHub Connector non lo acquisisce automaticamente e, nella tabella dei [tipi di file supportati](https://help.smartling.com/hc/en-us/articles/360007998893--Supported-File-Types) di Smartling, per i file JSON, iOS e Android non è previsto alcun contesto predefinito. Il contesto deve quindi provenire da screenshot o acquisizioni aggiunti dal tuo team.

Smartling offre un piano Core gratuito per iniziare e un Piano Enterprise disponibile tramite il reparto vendite, e pubblica tariffe base per parola per ciascun tipo di traduzione. (Vedi [i piani di Smartling](https://www.smartling.com/plans), verificato a ottobre 2026.)

## Smartling e General Translation a confronto

| --------------------------- | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| Dove si trovano le stringhe | File di risorse le cui stringhe vengono analizzate e archiviate da Smartling                            | Nel tuo codice all&#39;interno di [`<T>`](/docs/react/reference/components/t), oppure nei file di risorse che hai già                             |
| Come si collega il codice   | GitHub Connector, Repository Connector, CLI o API                                                       | [`npx gt translate`](/docs/cli/reference/commands/translate) nella tua build, oppure pull request di [Locadex](/docs/platform/locadex/quickstart) |
| Chi traduce                 | Motori di AI Hub, Smartling AI Translation o i linguisti di Smartling                                   | AI con il contesto ricavato dal tuo codice, dal Glossario e dai prompt personalizzati, con revisione da parte del tuo team nella dashboard        |
| Contesto per ogni stringa   | Acquisizione del contesto visivo, screenshot con OCR, glossario, memoria di traduzione e guide di stile | Struttura JSX contrassegnata, segnaposto per le variabili, note di contesto, Glossario e prompt personalizzati                                    |
| Siti web                    | Il proxy di traduzione GDN                                                                              | Traduce i contenuti presenti nel tuo codice, con il routing delle impostazioni regionali in `gt-next`                                             |

## Perché i team scelgono General Translation invece di Smartling

Con General Translation, la stessa modifica al codice che introduce i testi può generarne anche le traduzioni. I testi restano leggibili all&#39;interno di [`<T>`](/docs/react/reference/components/t) e la build produce i file di lingua necessari all&#39;app.

* **Più veloce.** Esegui [`npx gt translate`](/docs/cli/reference/commands/translate) prima della build dell&#39;applicazione per generare le traduzioni del rilascio che stai distribuendo. In alternativa, configura [Locadex](/docs/platform/locadex/guides/configuring-automations) per aprire pull request di traduzione in risposta agli eventi del repository. Gli ingegneri possono gestire la localizzazione con il processo di build e revisione già in uso, senza dover coordinare un job di consegna separato.
* **Costi di gestione inferiori.** I blocchi inline [`<T>`](/docs/react/reference/components/t) eliminano la creazione di chiavi e lo scambio di file di risorse dalle normali modifiche ai testi. La CLI riutilizza le traduzioni invariate, quindi le build successive generano solo il testo nuovo o modificato. Consulta i [prezzi di General Translation](https://generaltranslation.com/pricing) per le tariffe di utilizzo e le [tariffe dei servizi di Smartling](https://www.smartling.com/translation-services) per le sue opzioni di traduzione con IA e umana.
* **Qualità superiore.** Per i file JSON, iOS e Android, Smartling non prevede alcun contesto visivo predefinito: sono i team a dover fornire screenshot o acquisizioni. General Translation trasferisce nella traduzione la struttura del JSX contrassegnato e dei segnaposto delle variabili, con [note di contesto](/docs/react/reference/components/t) per chiarire l&#39;intento, oltre al Glossario e ai prompt personalizzati per la terminologia di prodotto. I revisori possono correggere il risultato nell&#39;[Editor di traduzione della dashboard](/docs/platform/dashboard/guides/reviewing-translations), mantenendo generazione e revisione in un unico flusso di lavoro.
* **Rischio minore.** Le librerie `gt-react` e `gt-next`, con licenza MIT, possono renderizzare le [traduzioni incluse nel bundle](/docs/react/guides/storing-translations) senza un account General Translation né chiamate a servizi a runtime. I file generati restano insieme alla tua app, così hai il pieno controllo sui testi distribuiti.

General Translation è certificata SOC 2 Type II e ISO 27001 e conforme al GDPR; i piani Enterprise aggiungono SSO, provisioning SCIM, log di audit, ruoli personalizzati e ingegneri integrati presso il cliente. (Consulta il suo [centro di fiducia](https://trust.inc/generaltranslation).)

Cursor utilizza General Translation per il suo prodotto web e la sua documentazione in oltre 14 impostazioni regionali. (Consulta le [distribuzioni in produzione](https://generaltranslation.com/enterprise).)

## Quando Smartling è la scelta migliore

Scegli Smartling se vuoi acquistare traduzione AI e umana da un unico fornitore con garanzia di qualità, se devi tradurre siti di marketing tramite un proxy senza modificare il codice, se il tuo settore richiede certificazioni come PCI o HIPAA, se i contenuti sono distribuiti su numerosi CMS aziendali e strumenti di marketing, oppure se scambi file XLIFF, TMX o Office con i fornitori.

## Passare da Smartling a General Translation

Parti dai file di risorse che la tua app carica già, come JSON o PO. [Configura la CLI](/docs/cli/guides/configuring) per questi file ed esegui [`npx gt upload`](/docs/cli/reference/commands/upload) per importare i file sorgente e le traduzioni esistenti prima della prima esecuzione di [`npx gt translate`](/docs/cli/reference/commands/translate). Puoi mantenere la tua libreria i18n e l&#39;attuale struttura dei file.

Importa il tuo glossario in un [gruppo di contesto](/docs/platform/dashboard/guides/defining-context-for-translations), poi rivedi i testi generati nella dashboard. Adottare il componente inline [`<T>`](/docs/react/reference/components/t) è un&#39;opzione a parte, pensata per i team che vogliono anche smettere di gestire le chiavi sorgente. Per una valutazione più ampia della piattaforma, consulta [Perché usare General Translation invece di un TMS?](/kb/general-translation-vs-tms).

## General Translation è un&#39;alternativa a Smartling?

Sì. General Translation unisce generazione consapevole del codice, automazione della build e revisione nella Dashboard, pensate per i team di sviluppo software. Puoi mantenere i cataloghi esistenti oppure usare JSX inline. Smartling è un&#39;ottima scelta se ti serve un proxy di traduzione per siti web o se vuoi affidarti allo stesso fornitore anche per i servizi di traduzione umana.

## Punti chiave

* Smartling è una piattaforma enterprise completa, ideale quando si vogliono ottenere da un unico fornitore traduzione con IA e traduzione umana, un proxy per siti web e un&#39;ampia conformità normativa.
* Gli sviluppatori continuano a gestire file di risorse basati su chiavi e, in modalità pull request, una pull request di funzionalità resta in sospeso finché le relative traduzioni non vengono consegnate.
* General Translation integra il contesto del codice, la generazione e la revisione nel flusso di lavoro di rilascio, mentre le traduzioni incluse nel bundle fanno sì che la distribuzione in produzione resti all&#39;interno della tua app.
