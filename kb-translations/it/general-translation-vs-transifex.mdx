General Translation è la scelta migliore se vuoi che la traduzione si integri nel flusso di lavoro di sviluppo React: contrassegna il JSX con [`<T>`](/docs/react/reference/components/t), genera le traduzioni prima della build e distribuiscile insieme all&#39;app. Transifex è un sistema di gestione delle traduzioni (TMS), [parte di XTM International](https://xtm.ai/news/xtm-international-acquires-transifex) da gennaio 2025, che combina AI, traduttori e fornitori partner.

Transifex supporta sia i file di risorse sia le stringhe contrassegnate direttamente nel codice tramite Transifex Native. Native invia i messaggi a Transifex e carica le traduzioni dal proprio servizio di consegna dei contenuti (CDS). General Translation estrae il JSX contrassegnato da tradurre e consente all&#39;app di caricare il risultato da file inclusi nel bundle o dalla sua CDN.

## I punti di forza di Transifex

* **Stringhe dal codice senza file.** [Transifex Native](https://developers.transifex.com/docs/javascript-sdk) contrassegna le stringhe con una funzione di traduzione o un componente React, usa per impostazione predefinita il testo di origine come chiave e invia le stringhe con `txjs-cli push`. Gli SDK e il [CDS](https://github.com/transifex/transifex-delivery) sono open source con licenza Apache-2.0 e il CDS può essere self-hosted.
* **IA con punteggi di qualità.** Transifex AI traduce sfruttando il tuo glossario, la memoria di traduzione e il contesto, mentre il suo [Translation Quality Index (TQI)](https://help.transifex.com/en/articles/9465000-translation-quality-index-tqi) assegna un punteggio alle traduzioni generate dall&#39;IA. Quelle che raggiungono la soglia configurata possono essere contrassegnate automaticamente come revisionate.
* **Partner di traduzione umana.** Puoi [ordinare traduzioni a partner](https://help.transifex.com/en/articles/6235673-ordering-translations) come e2f, Gengo e TextMaster direttamente da Transifex.
* **Siti web senza modifiche al codice.** [Transifex Live](https://help.transifex.com/en/articles/6244596-introduction-to-transifex-live) traduce un sito web tramite uno snippet JavaScript, anche se per le app React e Vue Transifex consiglia Native.
* **Collaboratori illimitati.** Il piano attuale non prevede costi per postazioni, progetti o contenuti ospitati.
* **Formati di file.** [Oltre 46 formati](https://help.transifex.com/en/articles/6219670-introduction-to-file-formats), tra cui XLIFF, file Office e sottotitoli.

## Cosa Transifex lascia ancora ai tuoi ingegneri

Gli ingegneri collegano l&#39;app al flusso di lavoro di traduzione e consegna di Transifex:

1. Contrassegnare ogni stringa per Transifex: estrarla in un file di risorse associandola a una chiave, oppure racchiuderla nella funzione di traduzione o nel componente React di Native.
2. Inviarla a Transifex con [`tx push`](https://github.com/transifex/cli), un&#39;integrazione Git o `txjs-cli push`, di solito come passaggio della CI.
3. Configurare la traduzione AI o un fornitore partner, insieme a eventuali requisiti di revisione.
4. Consegnare le traduzioni. Nel flusso di lavoro basato su file, un&#39;[integrazione Git](https://help.transifex.com/en/articles/6265125-github-via-transifex-ui) apre una pull request o esegue un commit quando una lingua raggiunge una determinata soglia di completamento. Native recupera le traduzioni dal [CDS](https://developers.transifex.com/docs/content-delivery-service), i cui contenuti per impostazione predefinita diventano obsoleti dopo un&#39;ora; l&#39;intervallo di aggiornamento è configurabile.

Transifex AI utilizza [termini del glossario, memoria di traduzione, campi di contesto e informazioni aziendali](https://help.transifex.com/en/articles/9867663-context-in-transifex-ai). È possibile abilitare anche note per gli sviluppatori e istruzioni specifiche per le stringhe. La libreria React di General Translation ricava il contesto dalla struttura JSX contrassegnata e dai segnaposto con nome, a cui si aggiungono note per gli sviluppatori e terminologia del progetto per guidare la traduzione.

L&#39;offerta prevede un unico piano AI-first, acquistabile tramite il team commerciale e fatturato in base alle parole tradotte con l&#39;AI, senza tariffe pubbliche. (Vedi i [prezzi di Transifex](https://www.transifex.com/pricing), verificati a ottobre 2026.)

## Transifex e General Translation a confronto

| Funzionalità              | Transifex                                                                                                    | General Translation                                                                                                                        |
| ------------------------- | ------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Come arrivano le stringhe | File di risorse tramite `tx push` o integrazioni Git, oppure stringhe del Native SDK tramite `txjs-cli push` | Il contenuto resta nel tuo codice all&#39;interno di [`<T>`](/docs/react/reference/components/t), oppure nei file di risorse che hai già   |
| Chi traduce               | Transifex AI con punteggi TQI, oppure fornitori partner                                                      | AI con il contesto ricavato dal tuo codice, dal Glossario e dai prompt personalizzati, con revisione da parte del tuo team nella dashboard |
| Contesto per ogni stringa | Glossario, memoria di traduzione, campi di contesto e note facoltative per gli sviluppatori                  | JSX contrassegnato, segnaposto con nome, note per gli sviluppatori, Glossario e prompt personalizzati                                      |
| Consegna                  | Pull request o commit per i file; il CDS a runtime per Native                                                | Traduzioni incluse localmente nel bundle o CDN di General Translation                                                                      |
| Prezzi                    | In base al volume di parole tradotte con AI, con preventivi tramite il team commerciale                      | [Tariffe di utilizzo](https://generaltranslation.com/pricing) pubbliche                                                                    |

## Perché i team scelgono General Translation invece di Transifex

* **Più veloce.** [`npx gt translate`](/docs/cli/reference/commands/translate) estrae i contenuti contrassegnati, genera le traduzioni e scarica i risultati prima della build dell&#39;app. In questo modo ogni rilascio richiede un solo passaggio di traduzione. Se preferisci revisionare le modifiche su GitHub, [Locadex](/docs/platform/locadex/quickstart) apre una pull request quando il codice cambia.
* **Costi di gestione inferiori.** General Translation riduce il lavoro di sviluppo necessario per tradurre interfacce complesse: una frase può mantenere link, formattazione e valori dinamici all&#39;interno di un unico blocco [`<T>`](/docs/react/reference/components/t), anziché dover essere ricostruita come stringa di messaggio. Puoi stimare i costi di traduzione direttamente dalle [tariffe pubblicate](https://generaltranslation.com/pricing).
* **Qualità superiore.** Mantenendo insieme una frase e i suoi elementi annidati, la traduzione conserva le relazioni tra parole, link e segnaposto. Le note degli sviluppatori chiariscono i testi ambigui, mentre i [gruppi di contesto](/docs/platform/dashboard/guides/defining-context-for-translations) assegnati applicano la stessa terminologia alla tua app e al tuo sito web. Il tuo team può perfezionare il risultato nell&#39;[Editor di traduzione](/docs/platform/dashboard/guides/reviewing-translations).
* **Rischio minore.** Con le [traduzioni locali](/docs/react/guides/storing-translations), l&#39;app esegue il rendering a partire da file inclusi nel bundle del rilascio e non effettua alcuna chiamata a General Translation in fase di runtime. I team che vogliono pubblicare le modifiche alle traduzioni senza ridistribuire l&#39;app possono usare la CDN di General Translation. Le librerie JavaScript con licenza MIT funzionano anche senza account, se fornisci tu le traduzioni.

Sierra distribuisce i suoi contenuti web e go-to-market in oltre 7 impostazioni regionali con General Translation. (Vedi le [distribuzioni in produzione](https://generaltranslation.com/enterprise).)

## Quando Transifex è la scelta migliore

Scegli Transifex se vuoi tradurre un sito web con un semplice snippet, senza modificare il codice, se vuoi commissionare traduzioni umane ai suoi fornitori partner, se l&#39;approvazione automatica basata su TQI si adatta al tuo processo di revisione, se scambi file XLIFF, Office o di sottotitoli, oppure se le tue app native iOS e Android richiedono [aggiornamenti over-the-air con bundle offline](https://developers.transifex.com/docs/ios-sdk).

## Passare da Transifex a General Translation

Per i progetti basati su file che utilizzano formati supportati come JSON, YAML, PO o i file di risorse iOS e Android, segui l&#39;[Avvio rapido della CLI](/docs/cli/quickstart). Configura i percorsi dei file sorgente e delle impostazioni regionali, quindi importa le traduzioni esistenti con [`npx gt upload`](/docs/cli/reference/commands/upload) prima di generarne di nuove.

Per un&#39;app React che utilizza Native, configura `gt-react` o `gt-next` seguendo la [Guida rapida a React](/docs/react/react-quickstart) o l&#39;[Avvio rapido di Next.js](/docs/react/nextjs-quickstart). Migra una schermata alla volta: racchiudi testi e markup in [`<T>`](/docs/react/reference/components/t), quindi esegui [`npx gt translate`](/docs/cli/reference/commands/translate). Lascia le altre schermate su Native mentre revisioni quella tradotta. Importa il tuo glossario in un [gruppo di contesto](/docs/platform/dashboard/guides/defining-context-for-translations) per mantenere la terminologia del prodotto.

## General Translation è un&#39;alternativa a Transifex?

Sì. Scegli General Translation per generare traduzioni a partire da JSX strutturato prima della build e distribuirle come file inclusi nel bundle o tramite la sua CDN. Puoi anche mantenere un&#39;app esistente basata su file e usare General Translation per tradurne i cataloghi. Per un confronto più ampio con altri fornitori, consulta [Perché usare General Translation invece di un TMS?](/kb/general-translation-vs-tms).

## In cosa si differenzia Transifex Native da General Translation?

Entrambi utilizzano SDK open source e consentono di mantenere il testo di origine nel codice. Nell&#39;[SDK React di Transifex](https://developers.transifex.com/docs/react-sdk), un messaggio `<T _str="...">` può ricevere elementi React come valori di interpolazione. Il componente [`<T>`](/docs/react/reference/components/t) di General Translation mantiene la frase e gli elementi annidati direttamente nel JSX ed estrae questa struttura per la traduzione. Native distribuisce le traduzioni tramite il CDS, mentre General Translation ti permette di scegliere tra file inclusi nel bundle e la propria CDN.

## Punti chiave

* Transifex è un TMS con SDK Native open source, traduzione AI con punteggi di qualità, fornitori partner e Transifex Live per i siti web.
* Native supporta già le stringhe nel codice. Il punto di forza di General Translation in React è la possibilità di scrivere e tradurre JSX strutturato, con note per gli sviluppatori e una terminologia condivisa.
* General Translation genera le traduzioni prima della build e supporta sia la consegna tramite bundle sia gli aggiornamenti via CDN, così puoi scegliere in che modo il contenuto tradotto arriva agli utenti.
