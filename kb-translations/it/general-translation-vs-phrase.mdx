Phrase si definisce una [Language Intelligence Platform](https://phrase.com/). Ai team di sviluppo software offre Phrase Strings, che memorizza le chiavi e le sincronizza con il tuo repository, e Phrase TMS ([in precedenza Memsource](https://phrase.com/memsource/)), un sistema di gestione delle traduzioni (TMS) e strumento CAT (traduzione assistita da computer) pensato per documenti, fornitori e programmi di traduzione su larga scala. Language AI collega entrambi a motori di traduzione automatica e LLM. General Translation porta i testi dell&#39;app e la documentazione all&#39;interno del flusso di lavoro di rilascio, generando le traduzioni dai file sorgente e applicando una terminologia condivisa tra i progetti.

## I punti di forza di Phrase

* **Due strumenti in un&#39;unica piattaforma.** [Phrase Strings](https://phrase.com/platform/strings/) per le chiavi degli sviluppatori e Phrase TMS per documenti, gestione dei fornitori e traduzione con strumenti CAT.
* **Language AI.** [Oltre 30 motori di traduzione automatica e LLM](https://phrase.com/platform/ai/) con selezione automatica del motore, Next GenMT che sfrutta le corrispondenze della memoria di traduzione e una valutazione della qualità che segnala per la revisione i segmenti con il punteggio più basso.
* **Automazione del repository.** [Repo Sync per GitHub](https://support.phrase.com/hc/en-us/articles/5784125562012-GitHub-Strings), GitLab e Bitbucket importa i file da un branch monitorato ed esporta le traduzioni sotto forma di pull request, mentre una GitHub Action esegue la CLI in CI.
* **Aggiornamenti over-the-air per mobile e web.** [Gli SDK per iOS, Android, React Native, Flutter, i18next e Rails](https://support.phrase.com/hc/en-us/articles/5804059067804-Over-the-Air-Strings) scaricano le nuove traduzioni senza bisogno di un nuovo rilascio e, in caso di problemi, ricorrono agli ultimi file in cache o inclusi nel bundle.
* **Contesto per i traduttori.** [Screenshot il cui testo viene associato alle chiavi](https://support.phrase.com/hc/en-us/articles/5822309698204-Screenshot-Management-Strings), descrizioni delle chiavi e limiti di caratteri, oltre a un plugin per Figma.
* **Traduzione umana.** Ordini a Gengo o TextMaster direttamente da Phrase Strings; secondo Phrase, [la maggior parte delle traduzioni viene consegnata entro 24 ore](https://support.phrase.com/hc/en-us/articles/5821933165596-Ordering-Professional-Translations-Strings).
* **Scelta dell&#39;hosting.** [Dati ospitati nell&#39;UE o negli Stati Uniti](https://support.phrase.com/hc/en-us/articles/5748008399388-Data-Centers).

## Cosa resta ancora a carico dei tuoi ingegneri con Phrase

Phrase Strings collega i progetti software tramite un flusso di lavoro basato su file di risorse:

1. Configura una libreria i18n e scrivi o estrai i file di risorse che questa carica.
2. Descrivi i tuoi file in `.phrase.yml` e inviali con [`phrase push`](https://developers.phrase.com/en/developer-tools/strings-cli), oppure lascia che Repo Sync li importi dal branch monitorato.
3. Traduci nelle lingue di destinazione con l&#39;IA o tramite flussi di lavoro con traduttori.
4. Riporta le traduzioni nel progetto con `phrase pull` o con un&#39;esportazione di Repo Sync, che apre una pull request.

Repo Sync e la CI possono automatizzare lo scambio di file. Il tuo team deve comunque gestire la struttura delle chiavi dell&#39;app e la mappatura tra codice, file di risorse e progetti Phrase. I traduttori lavorano con le descrizioni delle chiavi e gli screenshot associati a quei contenuti.

[Gli abbonamenti Phrase](https://phrase.com/pricing/) includono licenze Strings, una capacità di parole gestite e un volume di traduzione. È possibile acquistare capacità aggiuntiva. Il piano software pubblicato include lingue illimitate.

## Phrase e General Translation a confronto

| Funzionalità                  | Phrase                                                                                 | General Translation                                                                                                                               |
| ----------------------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| Dove risiedono le stringhe    | Chiavi in Phrase Strings, sincronizzate con i tuoi file di risorse                     | Nel tuo codice, all&#39;interno di [`<T>`](/docs/react/reference/components/t), oppure nei file di risorse che hai già                            |
| Come si integra con il codice | CLI `phrase`, Repo Sync o una GitHub Action                                            | [`npx gt translate`](/docs/cli/reference/commands/translate) nella tua build, oppure pull request di [Locadex](/docs/platform/locadex/quickstart) |
| Chi traduce                   | Motori Language AI, oppure fornitori come Gengo e TextMaster                           | AI con contesto ricavato dal tuo codice, dal Glossario e dai prompt personalizzati, con revisione del tuo team nella dashboard                    |
| Contesto per ogni stringa     | Memoria di traduzione, termbase, guida di stile, descrizioni delle chiavi e screenshot | Struttura JSX contrassegnata e note di contesto, con Glossario e prompt personalizzati condivisi tra i progetti                                   |
| Prezzi                        | Abbonamenti con licenze Strings, parole gestite e capacità di traduzione               | [In base all&#39;utilizzo](https://generaltranslation.com/pricing)                                                                                |
| App mobile native             | SDK over-the-air per iOS, Android, React Native e Flutter                              | Traduce i file di risorse iOS e Android; React Native usa `gt-react-native`                                                                       |

## Perché i team scelgono General Translation invece di Phrase

General Translation riunisce i testi del software e la documentazione che li descrive in un unico flusso di lavoro di traduzione. Mantieni i testi dell&#39;app all&#39;interno di [`<T>`](/docs/react/reference/components/t), traduci Markdown o MDX insieme a essi e applica a entrambi la stessa terminologia di prodotto.

* **Più veloce.** Esegui [`npx gt translate`](/docs/cli/reference/commands/translate) in CI sui file sorgente modificati da un rilascio. General Translation supporta [Markdown e MDX](/docs/cli/reference/formats/mdx-md-files) oltre ai contenuti dell&#39;app, così la nuova funzionalità e la relativa pagina di assistenza possono essere tradotte nello stesso processo di rilascio. [Locadex](/docs/platform/locadex/quickstart) può gestire gli aggiornamenti continui tramite pull request.
* **Costi di gestione inferiori.** General Translation riutilizza le traduzioni invariate nelle build successive. Paghi il lavoro di traduzione e le traduzioni completate restano utilizzabili senza dover acquistare capacità di parole gestite per i testi archiviati. Confronta [le tariffe di utilizzo di General Translation](https://generaltranslation.com/pricing) con la capacità Strings inclusa nel tuo abbonamento Phrase.
* **Qualità superiore.** Assegna lo stesso [gruppo di contesto](/docs/platform/dashboard/guides/defining-context-for-translations) ai progetti dell&#39;app e della documentazione. In questo modo, le stesse definizioni di prodotto e istruzioni sul tono guidano entrambi: una funzionalità citata in una schermata di onboarding usa la terminologia definita per il relativo articolo di assistenza. Il JSX contrassegnato conserva inoltre la struttura dei messaggi e i segnaposto delle variabili, e i revisori possono [modificare le traduzioni nella dashboard](/docs/platform/dashboard/guides/reviewing-translations).
* **Rischio minore.** Parti dai cataloghi esistenti di una singola applicazione e mantieni la sua libreria i18n. Importa le traduzioni già revisionate prima di generarne di nuove, poi estendi l&#39;adozione ad altri progetti quando sei pronto. Adottare General Translation per la localizzazione del software non richiede di migrare contemporaneamente un programma separato dedicato ai documenti o ai fornitori.

Profound traduce la propria piattaforma e la propria documentazione in oltre 47 impostazioni regionali con General Translation. (Vedi le [distribuzioni in produzione](https://generaltranslation.com/enterprise).)

## Quando Phrase è la scelta migliore

Scegli Phrase quando un&#39;unica piattaforma deve gestire sia le stringhe del software sia un programma di traduzione incentrato sui documenti, svolto in uno strumento CAT insieme ai fornitori; quando vuoi smistare le traduzioni tra numerosi motori di traduzione automatica e LLM; quando le app native e React Native richiedono aggiornamenti over-the-air; quando scambi [file XLIFF o Office](https://phrase.com/platform/tms/) con i fornitori; oppure quando ti serve poter scegliere tra hosting nell&#39;UE e negli Stati Uniti.

## Passare da Phrase a General Translation

Esegui `phrase pull` per scaricare le traduzioni attuali. Per i [formati supportati](/docs/cli/reference/config#files), configura `gt.config.json` in modo che punti a quei file sorgente e di destinazione, quindi esegui [`npx gt upload`](/docs/cli/reference/commands/upload) prima di generare le traduzioni con [`npx gt translate`](/docs/cli/reference/commands/translate). In questo modo partirai dalle traduzioni già revisionate e dalle chiavi attualmente in uso nell&#39;applicazione.

Importa la tua terminologia in un [gruppo di contesto](/docs/platform/dashboard/guides/defining-context-for-translations) e assegnalo ai progetti dell&#39;app e della documentazione. Affidare la generazione a General Translation e adottare JSX inline sono scelte indipendenti: puoi continuare a usare la libreria attuale. Per un confronto più ampio tra le piattaforme, consulta [Perché usare General Translation invece di un TMS?](/kb/general-translation-vs-tms).

## General Translation è un&#39;alternativa a Phrase?

Sì, per i team di sviluppo che vogliono integrare le traduzioni di app e documentazione nel proprio flusso di lavoro di build. General Translation supporta i cataloghi esistenti e il JSX inline, la terminologia condivisa e la revisione nella Dashboard. Phrase TMS è invece più indicato per programmi di traduzione incentrati soprattutto sui documenti, gestiti in uno strumento CAT con fornitori esterni.

## Punti chiave

* Phrase è una scelta solida quando le stringhe del software e un programma di traduzione ampio, con molti documenti, devono convivere su un&#39;unica piattaforma, con un&#39;ampia scelta di motori e SDK over-the-air.
* Phrase Strings automatizza lo scambio dei file di risorse; i suoi abbonamenti includono licenze Strings e una capacità di parole gestite.
* General Translation collega i rilasci dell&#39;app e della documentazione grazie a terminologia condivisa, traduzione incrementale e revisione, e ti permette di mantenere i tuoi cataloghi esistenti.
