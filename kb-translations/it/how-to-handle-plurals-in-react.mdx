## Perché la pluralizzazione è importante in React

Capita spesso di imbattersi in app che mostrano messaggi goffi come:

```text
Hai 1 nuovo/i messaggio/i
```

Questo è il segnale inequivocabile di uno sviluppatore che non ha riflettuto a fondo sull&#39;esperienza utente.

Le app React devono spesso gestire la pluralizzazione: per il numero di notifiche, la lunghezza degli elenchi o i risultati di ricerca.
**E gestire correttamente la pluralizzazione non è poi così difficile, soprattutto se la tua app deve funzionare solo in inglese.**
Ci sono però molte cattive pratiche in cui gli sviluppatori alle prime armi cadono facilmente, soprattutto quando creano interfacce multilingue.

Questa guida spiega come gestire in modo pulito i plurali in inglese, formattare i numeri in base alle diverse impostazioni regionali e realizzare un sistema di plurali completamente multilingue in React e Next.js.

### Il problema dei plurali hard-coded

Molti progetti, compresi alcuni sorprendentemente grandi e importanti, gestiscono i plurali con logica hard-coded.

```jsx
export default function Example({ n }) {
  return (
    <p>
      Displaying {n} item{n === 1 ? '' : 's'}
    </p>
  )
}
```

Ma la pluralizzazione è spesso più complessa della semplice aggiunta di una &quot;s&quot; alla fine di una parola.
Alcuni sostantivi hanno forme plurali irregolari, come &quot;child&quot; e &quot;children&quot;.
A volte anche altre parti della frase devono cambiare per accordarsi con il sostantivo, come
&quot;is&quot; e &quot;are&quot; a seconda della quantità.

La tabella seguente illustra alcuni scenari comuni:

| Scenario                 | Esempi                                                                                      | Note                                                                                              |
| ------------------------ | ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| Numero di spettatori     | &quot;1 person is watching&quot; <br /> &quot;2 people are watching&quot;                   | Cambiano sia il sostantivo irregolare (&quot;person&quot; → &quot;people&quot;) sia il verbo.     |
| Eliminazione di elementi | &quot;Delete this message?&quot; <br /> &quot;Delete these 2 messages?&quot;                | Cambia il dimostrativo (&quot;this&quot; vs. &quot;these&quot;), oltre al plurale del sostantivo. |
| Risultati di ricerca     | &quot;No results&quot; <br /> &quot;1 result found&quot; <br /> &quot;2 results found&quot; | Formulazioni diverse per zero, uno o più risultati.                                               |

Le espressioni condizionali diventano rapidamente ingestibili.

E la situazione si trasforma in un incubo quando devi distribuire la tua app in altre lingue.
Ciò che funziona in inglese spesso non regge affatto in lingue come il polacco o l&#39;arabo, che gestiscono le quantità con regole completamente diverse.
**Le aziende con cui lavoriamo spesso rimandano l&#39;internazionalizzazione
per non dover affrontare il refactoring di UI hardcoded come questa.**

## Come gestire i plurali in inglese

In inglese, usare i plurali corretti nella tua app è di solito semplice.

Per la pluralizzazione dei sostantivi più semplici, scrivi una funzione di utilità:

```jsx
export function pluralize(
  count: number,
  singular: string,
  plural: string = singular + 's'
) {
  return `${count === 1 ? singular : plural}`;
}
```

Ora basta un&#39;unica funzione per gestire tutta la logica dei plurali,
e funziona anche con i plurali irregolari:

```js
pluralize(2, 'user') // "users"
pluralize(2, 'person', 'people') // "people"
pluralize(2, 'child', 'children') // "children"
```

Ma se ti serve una logica più complessa, ad esempio:

```text
"No one is watching"
"1 person is watching"
"2 people are watching"
```

A questo punto, conviene valutare seriamente una libreria di internazionalizzazione (&quot;i18n&quot;) che richieda poca manutenzione.

Sebbene molti sviluppatori ritengano che le librerie i18n servano solo per le interfacce multilingue,
possono rivelarsi molto utili per la formattazione di plurali e variabili anche nelle applicazioni monolingua.
Dietro le quinte, la maggior parte delle librerie i18n utilizza l&#39;API nativa di JavaScript `Intl.PluralRules` per determinare la forma plurale corretta in qualsiasi lingua.

Esistono molte librerie i18n per React, tra cui la nostra, [`gt-react`](/docs/react/overview) (oppure [`gt-next`](/docs/react/nextjs-quickstart) se usi Next.js).
Visualizzare un plurale in inglese con gt-react è semplice:

```jsx
import { Plural } from 'gt-react'

function Example({ count }) {
  return (
    <Plural n={count} zero={'No one is watching'} one={`${count} person is watching`}>
      {count} people are watching
    </Plural>
  )
}
```

L&#39;UI viene renderizzata in modo condizionale in base al valore di `n`.

La maggior parte delle librerie usa l&#39;API [`Intl.PluralRules`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/PluralRules) di JavaScript per decidere quale forma plurale mostrare.
Ciò significa che in inglese si usa il nome `"one"` per indicare il singolare e `"other"` per indicare il plurale.
Il nostro componente [`<Plural>`](/docs/react/reference/components/plural) verifica prima la categoria plurale esatta, poi le props generiche `plural` e `other`. Ricorre al proprio contenuto figlio solo se nessuna di queste props è disponibile.

Usare una libreria in questo caso è una best practice anche per le applicazioni solo in inglese e semplifica notevolmente un&#39;eventuale internazionalizzazione futura.

## Pluralizzazione nelle app React multilingue (i18n)

Se la tua app si rivolge solo a utenti di lingua inglese, l&#39;approccio descritto sopra potrebbe bastarti, ma prima o poi la maggior parte delle app in produzione deve supportare più lingue. Ed è qui che le cose si fanno interessanti.

* In arabo, i sostantivi cambiano forma a seconda che ce ne siano zero, uno, due o molti
* In impostazioni regionali come `de-DE`, `es-ES` e `it-IT`, i numeri grandi usano il punto anziché la virgola come separatore delle migliaia, quindi 1,000,000 diventa 1.000.000
* In hindi, le cifre sono raggruppate a coppie, quindi 1,000,000 diventerebbe 10,00,000

**Per un&#39;app internazionalizzata, conviene usare una libreria i18n dedicata**, che avrà una propria documentazione su come gestire i plurali e la formattazione dei numeri.

### Formattazione dei numeri per diverse impostazioni regionali

Puoi usare l&#39;oggetto `Intl` per [formattare i numeri](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/NumberFormat) in qualsiasi impostazione regionale.
Il modo più semplice è usare il metodo integrato `toLocaleString()`.

Per impostazione predefinita, viene utilizzata l&#39;impostazione regionale corrente del runtime:

```javascript
const n = 1000000
n.toLocaleString() // mostra 1,000,000 se l'impostazione regionale del runtime è "en-US" (inglese americano)
n.toLocaleString('de') // 1.000.000 perché è stata specificata l'impostazione regionale "de" (tedesco)
```

gt-react offre anche un componente [`<Num>`](/docs/react/reference/components/num) che si basa internamente su `Intl.NumberFormat`.

```jsx
import { Num } from 'gt-react'

// mostra 1,000,000 quando la lingua è "en-US"
// mostra 1.000.000 quando la lingua è "de"
// mostra 10,00,000 quando la lingua è "hi"
export default function Example() {
  return <Num>1000000</Num>
}
```

### Comprendere le forme plurali nelle diverse lingue

Le sei forme plurali supportate dall&#39;API `Intl.PluralRules` di JavaScript sono: `zero`, `one`, `two`, `few`, `many`, `other`.
Mentre l&#39;inglese usa solo `one` (&quot;singolare&quot;) e `other` (&quot;plurale&quot;),
lingue come l&#39;arabo e il polacco prevedono più di queste due forme.

Ad esempio, un utente anglofono potrebbe aspettarsi:

```text
"No one is watching"
"1 person is watching"
"2 people are watching"
```

Un utente di lingua araba, invece, potrebbe aspettarsi espressioni diverse per il singolare,
il duale (quando gli elementi sono esattamente due) e le forme plurali per quantità piccole e grandi:

```text
"لا أحد يشاهد"
"1 شخص يشاهد"
"2 شخصان يشاهدان"
"3 أشخاص يشاهدون"
"11 شخصاً يشاهدون"
```

È qui che una libreria di internazionalizzazione diventa essenziale.
Ogni lingua ha una propria logica per stabilire quando e come mostrare i plurali,
quindi è meglio affidarsi a una libreria dedicata per gestirli correttamente.

Una buona libreria i18n fa due cose:

1. Stabilisce quale forma plurale (`one`, `many`, `other`, ecc.) usare in base all&#39;impostazione regionale
2. Individua, nella lingua corretta, la traduzione corrispondente a quella forma

**Se usi già una libreria di internazionalizzazione,
consulta la sua documentazione per informazioni sulla formattazione dei plurali.**
Quasi tutte le librerie offrono una documentazione dedicata al rendering dei plurali.

### Esempio completo: plurali in un&#39;app React multilingue

Se non usi ancora una libreria di internazionalizzazione, prova [`gt-react`](/docs/react/react-quickstart)!

Il componente [`<Plural>`](/docs/react/reference/components/plural) di gt-react:

* Offre un modo semplice e dichiarativo per renderizzare correttamente i plurali in React
* Funziona nativamente con il componente di formattazione [`<Num>`](/docs/react/reference/components/num)
* Funziona nativamente con il componente di traduzione [`<T>`](/docs/react/reference/components/t), che si integra con il nostro [servizio di traduzione](https://generaltranslation.com) per generare automaticamente le forme plurali

Mettendo insieme tutti i tasselli, ecco un componente multilingue completo:

```jsx
import { T, Plural, Num } from 'gt-react'

// Funziona subito in oltre 100 lingue, senza configurazione
function Example({ count }) {
  return (
    <T>
      <Plural
        n={count}
        zero={'No one is watching'}
        one={
          <>
            <Num>{count}</Num> person is watching
          </>
        }
      >
        <Num>{count}</Num> people are watching
      </Plural>
    </T>
  )
}
```

Configura la pluralizzazione con l&#39;[Avvio rapido di `gt-react`](/docs/react/react-quickstart) per le app React o con l&#39;[Avvio rapido di `gt-next`](/docs/react/nextjs-quickstart) per le app Next.js. Per l&#39;API completa del componente, consulta il [Riferimento API di `<Plural>`](/docs/react/reference/components/plural).

La pluralizzazione è una delle sfide i18n più comuni in React: impostarla correttamente fin dall&#39;inizio ti risparmia un bel po&#39; di refactoring in seguito.
