## Почему обработка форм множественного числа важна в React

Нам часто попадаются приложения, которые выводят корявые сообщения вроде:

```text
У вас 1 новых сообщение(-й)
```

Это явный признак того, что разработчик не продумал пользовательский опыт.

В React-приложениях часто требуется обработка форм множественного числа — для счётчиков уведомлений, длины списков или результатов поиска.
**И правильно реализовать обработку форм множественного числа не так уж сложно, особенно если приложение нужно только на английском.**
Но начинающие разработчики нередко совершают типичные ошибки, особенно при создании многоязычных интерфейсов.

В этом руководстве мы разберём, как аккуратно обрабатывать формы множественного числа в английском языке, форматировать числа для разных локалей и построить полноценную многоязычную систему форм множественного числа в React и Next.js.

### Чем плохи жёстко закодированные формы множественного числа

Многие проекты — в том числе на удивление крупные и важные — жёстко прописывают логику форм множественного числа прямо в коде.

```jsx
export default function Example({ n }) {
  return (
    <p>
      Displaying {n} item{n === 1 ? '' : 's'}
    </p>
  )
}
```

Но обработка форм множественного числа зачастую сложнее, чем просто добавление &quot;s&quot; в конец слова.
У некоторых существительных неправильные формы множественного числа, например &quot;child&quot; и &quot;children&quot;.
Иногда вслед за существительным должны меняться и другие части предложения, например
&quot;is&quot; и &quot;are&quot; в зависимости от количества.

В таблице ниже приведены несколько типичных сценариев:

| Сценарий           | Примеры                                                                                     | Заметка                                                                                                     |
| ------------------ | ------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| Число зрителей     | &quot;1 person is watching&quot; <br /> &quot;2 people are watching&quot;                   | Меняются и неправильное существительное (&quot;person&quot; → &quot;people&quot;), и глагол.                |
| Удаление элементов | &quot;Delete this message?&quot; <br /> &quot;Delete these 2 messages?&quot;                | Меняется указательное местоимение (&quot;this&quot; или &quot;these&quot;), а также форма существительного. |
| Результаты поиска  | &quot;No results&quot; <br /> &quot;1 result found&quot; <br /> &quot;2 results found&quot; | Разные формулировки для нуля, одного и нескольких результатов.                                              |

Условные выражения быстро становятся громоздкими.

А когда приложение нужно выпустить на других языках, всё превращается в кошмар.
То, что работает в английском, часто полностью ломается в таких языках, как польский или арабский, где действуют совсем другие правила выражения количества.
**Компании, с которыми мы работаем, часто откладывают интернационализацию,
потому что рефакторить подобный жёстко заданный UI слишком болезненно.**

## Как работать с формами множественного числа в английском языке

В английском языке подобрать в приложении правильную форму множественного числа обычно несложно.

Для простой обработки форм множественного числа существительных достаточно написать вспомогательную функцию:

```jsx
export function pluralize(
  count: number,
  singular: string,
  plural: string = singular + 's'
) {
  return `${count === 1 ? singular : plural}`;
}
```

Теперь вся логика множественного числа умещается в одну функцию,
и она справляется даже с нерегулярными формами множественного числа:

```js
pluralize(2, 'user') // "users"
pluralize(2, 'person', 'people') // "people"
pluralize(2, 'child', 'children') // "children"
```

Но что, если вам нужна более сложная логика, например:

```text
"No one is watching"
"1 person is watching"
"2 people are watching"
```

На этом этапе стоит всерьёз задуматься о библиотеке интернационализации (&quot;i18n&quot;), которая не требует больших затрат на поддержку.

Хотя разработчики часто считают, что библиотеки интернационализации нужны только для многоязычных интерфейсов,
они могут пригодиться для форматирования множественного числа и переменных даже в одноязычных приложениях.
Под капотом большинство библиотек интернационализации используют встроенный в JavaScript API `Intl.PluralRules`, чтобы выбрать правильную форму множественного числа для любого языка.

Для React существует множество библиотек интернационализации, в том числе и наша — [`gt-react`](/docs/react/overview) (или [`gt-next`](/docs/react/nextjs-quickstart), если вы используете Next.js).
Вывести английское множественное число с помощью gt-react очень просто:

```jsx
import { Plural } from 'gt-react'

function Example({ count }) {
  return (
    <Plural n={count} zero={'No one is watching'} one={`${count} person is watching`}>
      {count} people are watching
    </Plural>
  )
}
```

UI рендерится условно в зависимости от значения `n`.

Большинство библиотек используют API JavaScript [`Intl.PluralRules`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/PluralRules), чтобы определить, какую форму множественного числа отображать.
Это означает, что в английском языке для единственного числа используется имя `"one"`, а для множественного — `"other"`.
Наш компонент [`<Plural>`](/docs/react/reference/components/plural) сначала проверяет точную категорию множественного числа, а затем общие пропсы `plural` и `other`. К дочерним элементам он прибегает только в том случае, если ни один из этих пропсов не задан.

Использовать здесь библиотеку рекомендуется даже в приложениях, работающих только на английском: это значительно упростит интернационализацию в будущем.

## Обработка форм множественного числа в многоязычных React-приложениях (i18n)

Если ваше приложение рассчитано только на англоязычных пользователей, описанного выше подхода может быть вполне достаточно. Однако большинству приложений в рабочей среде рано или поздно требуется поддержка нескольких языков — и вот тут начинается самое интересное.

* В арабском языке форма существительного зависит от количества: ноль, один, два или много
* В таких локалях, как `de-DE`, `es-ES` и `it-IT`, разряды больших чисел разделяются точками, а не запятыми, поэтому 1,000,000 превращается в 1.000.000
* В хинди цифры группируются парами, поэтому 1,000,000 записывается как 10,00,000

**Для интернационализированного приложения следует использовать специализированную библиотеку интернационализации**: в её документации описано, как работать с формами множественного числа и форматированием чисел.

### Форматирование чисел для разных локалей

С помощью объекта `Intl` можно [форматировать числа](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/NumberFormat) для любой локали.
Проще всего это сделать с помощью встроенного метода `toLocaleString()`.

По умолчанию он использует текущую локаль среды выполнения:

```javascript
const n = 1000000
n.toLocaleString() // выводит 1,000,000, если в среде выполнения задана локаль "en-US" (американский английский)
n.toLocaleString('de') // 1.000.000, поскольку явно указана локаль "de" (немецкий)
```

gt-react также предоставляет компонент [`<Num>`](/docs/react/reference/components/num), который под капотом использует `Intl.NumberFormat`.

```jsx
import { Num } from 'gt-react'

// выводит 1,000,000, если выбран язык «en-US»
// выводит 1.000.000, если выбран язык «de»
// выводит 10,00,000, если выбран язык «hi»
export default function Example() {
  return <Num>1000000</Num>
}
```

### Формы множественного числа в разных языках

API `Intl.PluralRules` в JavaScript поддерживает шесть форм множественного числа: `zero`, `one`, `two`, `few`, `many`, `other`.
В английском языке используются только `one` («единственное число») и `other` («множественное число»),
однако в таких языках, как арабский и польский, форм больше двух.

Например, англоязычный пользователь ожидает увидеть:

```text
"No one is watching"
"1 person is watching"
"2 people are watching"
```

А вот арабоязычный пользователь может ожидать разных вариантов для единственного числа,
двойственного (когда предметов ровно два), а также для форм множественного числа, обозначающих малое и большое количество:

```text
"لا أحد يشاهد"
"1 شخص يشاهد"
"2 شخصان يشاهدان"
"3 أشخاص يشاهدون"
"11 شخصاً يشاهدون"
```

Именно здесь без библиотеки интернационализации не обойтись.
В каждом языке свои правила того, когда и как использовать формы множественного числа,
поэтому лучше положиться на специализированную библиотеку, которая сделает всё правильно.

Хорошая библиотека интернационализации решает две задачи:

1. Определяет, какую форму множественного числа (`one`, `many`, `other` и т. д.) использовать в зависимости от локали
2. Находит перевод на нужном языке, соответствующий этой форме

**Если вы уже используете библиотеку интернационализации,
загляните в её документацию: там описано форматирование форм множественного числа.**
Почти у всех библиотек есть отдельный раздел документации, посвящённый рендерингу форм множественного числа.

### Полный пример: формы множественного числа в многоязычном React-приложении

Если у вас ещё нет библиотеки интернационализации, обратите внимание на [`gt-react`](/docs/react/react-quickstart)!

Компонент [`<Plural>`](/docs/react/reference/components/plural) из gt-react:

* Предлагает простой декларативный способ корректного рендеринга форм множественного числа в React
* Нативно работает с компонентом форматирования [`<Num>`](/docs/react/reference/components/num)
* Нативно работает с компонентом перевода [`<T>`](/docs/react/reference/components/t), который интегрирован с нашим [сервисом перевода](https://generaltranslation.com) и автоматически генерирует формы множественного числа

Если собрать всё вместе, получится полноценный многоязычный компонент:

```jsx
import { T, Plural, Num } from 'gt-react'

// Работает «из коробки» более чем на 100 языках
function Example({ count }) {
  return (
    <T>
      <Plural
        n={count}
        zero={'No one is watching'}
        one={
          <>
            <Num>{count}</Num> person is watching
          </>
        }
      >
        <Num>{count}</Num> people are watching
      </Plural>
    </T>
  )
}
```

***

Настройте обработку форм множественного числа с помощью руководства [«Быстрый старт» для `gt-react`](/docs/react/react-quickstart) в React-приложениях или [«Быстрый старт» для `gt-next`](/docs/react/nextjs-quickstart) в приложениях Next.js. Полное описание API компонента см. в [справочнике API `<Plural>`](/docs/react/reference/components/plural).

Обработка форм множественного числа — одна из самых распространённых задач i18n в React. Если сразу реализовать её правильно, в будущем не придётся проводить масштабный рефакторинг.
