Babel форматирует даты, числа и денежные суммы на основе данных Unicode CLDR, а его команда `pybabel` извлекает, обновляет и компилирует каталоги сообщений gettext. Flask-Babel связывает эти инструменты с обработкой запросов во Flask и шаблонами Jinja. General Translation заполняет каталоги на этапе между извлечением и компиляцией: ваше приложение получает автоматический перевод, а существующая настройка Flask-Babel остаётся без изменений.

## Сильные стороны Babel и Flask-Babel

* **Форматирование по локали на основе CLDR.** [Babel 2.18.0 включает данные CLDR 47](https://babel.pocoo.org/en/latest/changelog.html#version-2-18-0) для более чем тысячи идентификаторов локалей. `format_currency(1234.5, "EUR")` выдаёт «1.234,50 €» на испанском, а `format_date` — «16 października 2026» на польском.
* **Инструменты для работы с каталогами.** [`pybabel extract`](https://babel.pocoo.org/en/latest/cmdline.html) извлекает строки из файлов Python и шаблонов Jinja согласно сопоставлению в `babel.cfg`, `pybabel init` создаёт PO-файл с нужным правилом множественного числа и количеством форм (для польского — три), `pybabel update` вливает новые строки и помечает изменённые как fuzzy, а `pybabel compile` собирает файлы `.mo`.
* **Интеграция с Flask.** `locale_selector` и `timezone_selector` [определяют локаль и часовой пояс для каждого запроса](https://python-babel.github.io/flask-babel/#configuration), `lazy_gettext` поддерживает строки, определённые во время импорта, в шаблонах Jinja доступны `_()`, `{% trans %}` и фильтры форматирования, а `force_locale` временно переключает локаль — например, чтобы отправить письмо на другом языке.
* **Стабильность и бесплатность.** Обе библиотеки распространяются под лицензией BSD (см. [лицензию Babel](https://babel.pocoo.org/en/latest/license.html)). Babel работает в любой программе на Python; [текущий релиз Flask-Babel — 4.0.0](https://github.com/python-babel/flask-babel/releases/tag/v4.0.0).

## Что Babel и Flask-Babel оставляют на вашу долю

Вот небольшое приложение на Flask-Babel:

```python title="app.py"
from datetime import date
from flask import Flask, request
from flask_babel import Babel, gettext, ngettext, format_currency, format_date


def select_locale():
    return request.accept_languages.best_match(["en", "es", "pl"])


app = Flask(__name__)
babel = Babel(app, locale_selector=select_locale)


@app.route("/inbox/<int:count>")
def inbox(count):
    return {
        "title": gettext("Inbox"),
        "unread": ngettext("You have %(num)d unread message.", "You have %(num)d unread messages.", count),
        "price": format_currency(1234.5, "EUR"),
        "date": format_date(date(2026, 10, 16), format="long"),
    }
```

`pybabel extract`, `pybabel init -l pl` и `pybabel compile` создают польский каталог, в котором все `msgstr` пустые. С Flask-Babel 4.0.0 запрос с заголовком `Accept-Language: pl` после этого вернул:

```json title="Output"
{
  "date": "16 października 2026",
  "price": "1 234,50 €",
  "title": "Inbox",
  "unread": "You have 5 unread messages."
}
```

Babel форматирует дату и цену для польского языка, но все строки остаются на английском, причём без какого-либо предупреждения. Каждая строка ждёт, пока кто-нибудь заполнит её запись в PO-файле, включая все три формы множественного числа для польского, а затем — запуска `pybabel compile` и повторного развёртывания. И так для каждой новой или изменённой строки в каждом языке.

## Перевод каталогов Babel с помощью General Translation

Если Flask-Babel вас устраивает, оставьте его, а запись каталогов поручите CLI General Translation. Один раз создайте английский каталог и обновляйте его после каждого извлечения строк — так исходные строки будут лежать в том же дереве каталогов, что и переводы:

```bash
pybabel extract -F babel.cfg -k lazy_gettext -o messages.pot .
pybabel init -i messages.pot -d translations -l en     # один раз
pybabel update -i messages.pot -d translations -l en   # после каждого извлечения
```

Затем укажите его в `gt.config.json`. Эта конфигурация проверена на `gt` 2.26.5:

```json title="gt.config.json"
{
  "defaultLocale": "en",
  "locales": ["es", "pl", "pt_BR"],
  "customMapping": { "pt_BR": { "code": "pt-BR" } },
  "files": {
    "pot": {
      "include": ["translations/[locale]/LC_MESSAGES/messages.po"],
      "transformationFormat": "PO"
    }
  }
}
```

Ключ `pot` считывает файлы PO и POT, а `"transformationFormat": "PO"` записывает переведённые файлы `.po` (см. [справочник по формату PO / POT](/docs/cli/reference/formats/po-pot-files)). [`customMapping`](/docs/cli/reference/config#custom-mapping) сопоставляет каталог Babel `pt_BR` со стандартным кодом локали `pt-BR`. Настройте [CLI](/docs/cli/quickstart). Если у вас уже есть переводы, импортируйте их с помощью [`npx gt upload`](/docs/cli/reference/commands/upload), прежде чем генерировать новые. Затем выполните [`npx gt translate`](/docs/cli/reference/commands/translate), а после этого — `pybabel compile -d translations`.

General Translation передаёт каждую запись вместе с её `msgctxt`, комментариями переводчика, ссылками на исходный код и флагами в качестве контекста. Для записей с формами множественного числа он прописывает заголовок `Plural-Forms` целевого языка и заполняет все слоты `msgstr[n]` (например, для польского — все три), а также проверяет, что заполнители вроде `%(num)d` остаются нетронутыми. Для неизменённых записей при следующем запуске используются прежние переводы. Glossary и пользовательские промпты в [контекстной группе](/docs/platform/dashboard/guides/defining-context-for-translations) обеспечивают единообразие терминологии в ваших каталогах и во всём остальном продукте, а рецензенты могут [редактировать любую запись](/docs/platform/dashboard/guides/reviewing-translations) в панели управления. Запускайте CLI в CI, чтобы при каждом развёртывании поставлялись актуальные каталоги. Если позже вы внесёте локальные изменения, сохраните их с помощью [`npx gt save-local`](/docs/cli/reference/commands/save-local), прежде чем снова запускать генерацию.

## Babel и Flask-Babel в сравнении с General Translation: краткий обзор

| Возможность                                   | Babel и Flask-Babel                                               | General Translation                                                              |
| --------------------------------------------- | ----------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| Как вы пишете строки                          | Вызовы `gettext` и Jinja `{% trans %}`, извлекаемые в PO-файлы    | Вызовы и шаблоны остаются прежними; переводятся извлечённые каталоги             |
| Переводит ваш контент                         | Нет                                                               | Да, с помощью [`npx gt translate`](/docs/cli/reference/commands/translate)       |
| Формы множественного числа                    | `pybabel init` создаёт слоты, а заполнять каждый из них нужно вам | Генерирует все слоты PO для целевого языка                                       |
| Форматирование дат, чисел и денежных значений | Да, на основе CLDR                                                | Сохраняет форматирование Babel                                                   |
| Шаблоны Jinja                                 | Да                                                                | Переводит сообщения, извлечённые из ваших существующих шаблонов                  |
| Фреймворки                                    | Babel — где угодно; Flask-Babel — для Flask                       | CLI для PO-каталогов из Flask и других приложений на gettext                     |
| Лицензия                                      | BSD                                                               | CLI под лицензией MIT                                                            |
| Стоимость                                     | Бесплатно                                                         | [Оплата перевода по факту использования](https://generaltranslation.com/pricing) |

## Что и когда использовать

Оставьте текущий процесс перевода, если переводчики или TMS уже поставляют нужные вам каталоги. Подключите General Translation, если хотите, чтобы новые и изменённые сообщения переводились прямо во время разработки — с терминологией и инструментами проверки, общими для всех проектов вашей команды. Flask-Babel по-прежнему отвечает за Jinja, локали запросов, даты и валюты, а код вашего приложения не меняется.

## Ключевые выводы

* Babel форматирует даты, числа и валюты для любой локали и управляет каталогами gettext, а Flask-Babel встраивает его во Flask, однако ни тот, ни другой не переводит ваши строки.
* CLI General Translation переводит PO-файлы Babel с помощью ключа `pot`, параметра `"transformationFormat": "PO"` и `customMapping` для каталогов вроде `pt_BR`, заполняя все формы множественного числа для каждого языка.
* Оставьте рендеринг и форматирование на Flask-Babel, импортируйте существующие переводы и добавьте General Translation между этапами извлечения и компиляции.
